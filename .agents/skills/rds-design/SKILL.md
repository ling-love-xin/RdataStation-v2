# RdataStation 设计规范

> 本规范是"设计品味"层——技术规范见 `gpui-kit-dev` skill，布局结构见 `rds-layout` skill。

## 间距基准（4px 网格）

所有间距必须是 4 的倍数（Tailwind 风格）：

| 变量 | 值 | 用途 |
|---|---|---|
| `gap_0p5` | 2px | 最小间距（icon 与文字、紧凑行内） |
| `gap_1` | 4px | 基础间距（控件内部、紧凑列表） |
| `gap_2` | 8px | 标准间距（控件之间、表单字段） |
| `gap_3` | 12px | 中等间距（分组之间、卡片内边距） |
| `gap_4` | 16px | 大间距（区块之间、对话框内边距） |
| `gap_6` | 24px | 超大间距（页面级分隔） |

**禁止**：`gap_1p5`（6px）、`gap_2p5`（10px）、`pt_2p5`（10px）等非 4 倍数的间距。

**换算**：
- `gap_1p5` → 改成 `gap_1`（4px）或 `gap_2`（8px）
- `gap_2p5` → 改成 `gap_2`（8px）或 `gap_3`（12px）

## 字号层级

| 层级 | 字号 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| 标题 | 14px | Semibold | `foreground` | 面板标题、对话框标题 |
| 正文 | 13px | Regular | `foreground` | 主要内容、列表项 |
| 辅助 | 12px | Regular | `muted_foreground` | 说明文字、次要信息 |
| 状态栏 | 11px | Regular | `muted_foreground` | 状态栏、徽标文字 |

## 视觉层级

**四级层级**，从高到低：

1. **激活/选中**（最高）：品牌色背景或左侧 2px 高亮条 + 高对比文字
2. **可交互**（中高）：hover 时背景色变化 10-15%
3. **静态信息**（中）：普通对比度，无 hover 反馈
4. **辅助/弱化**（最低）：`muted_foreground` 颜色，低对比度

**原则**：一屏之内，视觉焦点不超过 2 个（当前任务 + 当前选中项）。

## 交互反馈

| 状态 | 视觉变化 | 说明 |
|---|---|---|
| hover | 背景色变化 10-15% | 可点击元素才有 |
| 选中 | 背景色变化 20-25% + 左侧 2px 高亮条 | 当前激活项 |
| disabled | 透明度 50% + 禁止点击 | 不可用状态 |
| focus | 1px 外边框（主题色） | 键盘焦点 |
| pressed | 背景色加深 5% | 按压反馈 |

## 组件统一规范

| 组件 | 规范 |
|---|---|
| 工具栏高度 | 36px（含上下 padding） |
| 按钮高度 | 28px（小）/ 32px（标准） |
| 输入框高度 | 32px |
| Tab 高度 | 32px |
| 面板内边距 | 12px（左右） |

## 设计审计 Checklist

提交 UI 改动前，逐项检查：

### 间距
- [ ] 所有间距都是 4 的倍数？（没有 6px、10px）
- [ ] 卡片内边距统一（12px 或 16px）？
- [ ] 控件之间间距统一（8px）？

### 字号
- [ ] 标题/正文/辅助文字层级正确？
- [ ] 没有字号混乱（如 11px 正文、14px 辅助）？

### 视觉层级
- [ ] 一屏之内视觉焦点不超过 2 个？
- [ ] 选中态和 hover 态有明显区分？
- [ ] 辅助文字用 `muted_foreground`？

### 组件统一
- [ ] 工具栏高度统一（36px）？
- [ ] Tab 样式统一（字体大小、padding、关闭按钮位置）？
- [ ] 空态用 `empty::Empty` 组件？
- [ ] 状态徽标用 `badge::Badge` 组件？

### 交互反馈
- [ ] 可点击元素有 hover 反馈？
- [ ] 选中态有明确视觉标识？
- [ ] disabled 态有明确视觉变化？

## 常见反模式（禁止）

1. **手搓间距**：`div().p(7px)` 这种魔法数字，必须用标准 `gap_2` / `gap_3`
2. **字号混乱**：同一个页面出现 4 种以上字号
3. **视觉噪声**：一屏之内 5 个以上"高亮"元素，不知道该看哪个
4. **交互反馈缺失**：列表项 hover 没反应，选中态和普通态一样
5. **组件不一致**：同样是"工具栏"，左边 32px 右边 36px

## AI UI 反模式（额外禁止）

参考 impeccable 检测的 AI 生成 UI 特征：

6. **紫色渐变**——AI 最爱，不要用
7. **卡片嵌套卡片**——所有东西都包卡片，没有层级
8. **bounce/elastic 缓动**——过时，用 ease_out
9. **彩色背景上的灰色文字**——对比度不够
10. **纯黑/纯灰**——应该带色调（偏冷或偏暖）
11. **所有东西都包卡片**——用间距分组，不要用卡片
12. **过度阴影**——用边框区分，不要用大阴影

## 文案规范（ux-writing）

### 按钮文案
- 动词开头，说清楚做什么（「保存」「连接」「执行」）
- 不要用模糊词（「确认」「好」「OK」）
- 危险操作要明确（「删除」而不是「确定」）

### 错误消息
- 告诉用户发生了什么（人话）
- 告诉用户怎么解决（下一步）
- 技术细节放在详情里（折叠）

**坏例子**：`连接失败：E0061`
**好例子**：`连接失败：无法连接到 localhost:5432，请检查 PostgreSQL 是否运行`

### 空态文案
- 说清楚为什么空
- 引导用户下一步做什么
- 给一个按钮（主操作）

**坏例子**：`暂无数据`
**好例子**：`还没有连接。点击「新建连接」开始。`

## 字体系统（typography）

- **UI 字体**：系统默认（San Francisco on macOS / Segoe UI on Windows）
- **代码字体**：等宽字体（JetBrains Mono / Fira Code）
- **避免**：Inter（AI 最爱）、Arial（太老）

## 设计审计工作流

参考 impeccable 的命令式流程：

- **audit**：提交前跑 Checklist（间距/字号/颜色/组件统一）
- **critique**：新功能评审（视觉层级/交互反馈/空态/错误消息）
- **polish**：发布前打磨（间距统一/组件样式统一/动效一致/对比度达标）
- **harden**：边界情况（空数据/加载中/失败重试/长文本截断）

## 图标系统规范

- **图标库**：Lucide Icons（gpui-kit 自带，3000+ 个图标）
- **尺寸档位**：12px（XSmall）/ 14px（Small）/ 16px（Medium）/ 24px（Large）
- **图标与文字间距**：4px（`gap_1`）
- **图标颜色**：默认跟随文字色，辅助用 `muted_foreground`
- **状态图标**：用语义色（success / warning / danger / info）

### 常用图标速查

**数据库类型**：
- MySQL/PostgreSQL/Oracle → `Database`
- SQLite → `HardDrive`
- DuckDB/ClickHouse → `DatabaseZap`
- MongoDB → `Braces`
- Redis → `MemoryStick`

**操作按钮**：
- 新建/添加 → `Plus`
- 删除 → `Delete`
- 关闭 → `Close`
- 确认/勾选 → `Check`
- 刷新 → `RotateCw`

**导航**：
- 下拉展开 → `ChevronDown`
- 右箭头 → `ChevronRight`
- 查看/预览 → `Eye`
- 外部链接 → `ExternalLink`

**状态提示**：
- 信息 → `Info`
- 成功 → `CircleCheck`
- 警告 → `TriangleAlert`
- 错误 → `CircleX`
- 加载中 → `Loader`

**禁止**：手搓 SVG 图标、图标尺寸混用、图标颜色混乱

## 数据可视化规范

- **图表颜色顺序**：chart_1 → chart_2 → chart_3 → chart_4 → chart_5
- **上涨**：chart_bullish（绿色）
- **下跌**：chart_bearish（红色）
- **图例**：小圆点 + 文字，间距 8px，文字 `muted_foreground`

## 窗口缩放适配

- **Dock 最小宽度**：200px
- **窗口 < 800px**：右 Dock 自动收起
- **Dock < 200px**：隐藏文字标签，只显示图标
- **活动栏**：永远显示图标，不显示文字标签

## 错误状态视觉设计

- **空态**：`empty::Empty` 组件（大图标 + 标题 + 描述 + 按钮）
- **加载中**：`skeleton::Skeleton` 骨架屏
- **加载失败**：错误图标 + 错误消息 + 重试按钮
- **连接失败提示条**：红色背景（danger 10% 透明度）+ 左侧竖条 + 消息 + 重试按钮
