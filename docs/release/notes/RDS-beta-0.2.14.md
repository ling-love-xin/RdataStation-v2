# RDS beta 0.2.14

> 2026-11-26 · 相对 `RDS-beta-0.2.13` 的 124 个提交 · beta：本版只出 Windows 包

## 本次重点

- **分析引擎升到 DuckDB 2.0.1**：crate 从 `1.10506.1` 升到 `1.20001.0`，`arrow` 同批升到 60.2.0。2.0 新建的库是 `storage version 69`，**1.5 客户端读不了**——产品已拍板不做 1.5 兼容、不做旧库探测/只读挂载。
- **引擎收成「一个分析实例 + 每编辑器一条会话」**：原先「联邦一条内存库 + 加速每源一条连接」的多实例结构退役。项目分析库（读写）、全局分析库（只读）、各个挂上的源都在同一个实例里；`rds_tmp` 实例级共享，`TEMP` 表按会话隔离。`tmp_q_ JOIN 源表` 这类「两份实例之间没有 JOIN」的老问题从能力缺失变成会话边界问题。
- **结果集面板继续按 DBeaver 收口**：列头常显下拉三角 + 右键分组、行号槽的数组全列开关、数组列三级展开（类型档 / 铺平子行 / 值查看器集合树）、「复制列名」选项对话框、刷新钮的自动刷新下拉与自定义配置、右栏页签条的最小化钮与 MRU、单元格右键「面板」子菜单、查找边输边过滤加 250ms 防抖。
- **数据对象面板源段收口**：出「底座」行（项目分析库 / 全局分析库，不允许卸载），源行行尾只留一个动作位（挂载 / 卸载），叶子行零按钮；挂不上但已登记的连接改为「在这条连接上选表」。
- **资产库补全局引用**：项目引用全局表时只登记一条引用资产并按版本 pin，选中的版本可固化成项目内的独立表；全局实例可删、来源链与分发谱系可查、表型资产补齐动作判据与回收站闭环。
- **工作台首页拆开**：欢迎页承接新建连接 / 打开项目 / 最近使用，新的统计看板面板挂在中央组、由状态栏入口唤起（可在设置里关掉）。

## 分析引擎

- DuckDB `1.5.6` → `2.0.1`（`duckdb 1.20001.0` / `libduckdb-sys 1.20001.0`），`arrow 58.4.0 → 60.2.0`，`comfy-table 7.1 → 8.0.1`；动态库资产按 2.0 的发布名换包。
- 真机复核到的三条行为变化写进文档并落到代码：源表清单不再在 `ATTACH` 时定型（源库新表不重挂也能查）、`SET search_path` 单值可用、appender 不认 `search_path`。
- 新临时表实际建进 `rds_tmp`，靠 `search_path` 让裸名照旧解析；`rds_tmp` 的清理只由用户手动触发。
- 临时结果建表即登记进分析实例登记册；切项目时刷新底座。
- 联邦挂载前先核对别名归属，被别的源占着就判失败并点名；加速档别名按源唯一，实例记「连接 → 实际别名」。
- 语句超时从设置读，被中断的语句提示改成可读文案，不再是底层错误原文。

## 结果集面板

- 列头对齐 DBeaver：常显下拉三角、右键分组菜单、hover 底色。
- 行号槽按下有「数组展开」三角，一行内所有数组列一起开合，尺寸对齐 DBeaver。
- 数组列分三刀收口：类型档 + 收起态显示、展开态子行铺平（子行排除）、值查看器里的集合树。
- 「复制列名」多列时弹 DBeaver 的「选项」对话框，三行改为可编辑输入框。
- 刷新钮补「自动刷新」下拉，带「自定义…」配置对话框与定时重跑。
- 右栏页签条补最小化钮与页签区右键菜单，页签按 MRU 排出。
- 单元格右键补「面板」子菜单（与 DBeaver 的第三处挂载点对齐）。
- 结果内查找「边输边过滤」按 DBeaver 加 250ms 防抖，右键可切换该能力。
- 对象格悬停底色改按 DBeaver 的 blend 公式算。
- 侧栏按 DBeaver 注册序、状态栏按 `createStatusBar0` 组序重排。
- 新增结果集独立预览窗口（`examples/preview`），在大栈线程里跑，界面语言跟随设置。

## 数据对象面板

- 源段排位定档：会话 → 底座 → 候选。
- 源段出「底座」行（analytics / `rds_global`），不允许卸载。
- 源行行尾只留一个动作位（挂载 / 卸载），叶子行零按钮。
- 已登记但没挂上的连接，展开时走「在这条连接上选表」，不再直接报错。
- 同一连接被多个文档各登记一次时不再写第二行。

## 资产库

- 全局引用资产与按版本固化（引用登记迁移 `038`）：项目只登记引用并按版本 pin，固化选中的版本会新建一条项目内独立表，原引用保留。
- 引用资产追加版本时补父版本链；全局引用资产不允许改名，只能改项目侧别名。
- 全局版本登记与保留守卫；全局实例补删除入口，只读项目也允许删。
- 来源链浏览与分发谱系：详情里多一行「上游」，只记一跳，链路由读取侧拼。
- 表型资产还原前预检分析库里的表是否还在；表型资产补齐动作判据与回收站闭环。
- 工具条补「分组」「标签」两个维度，面板头去掉重复标题。

## 工作台与首页

- 欢迎页承接「新建连接 / 打开项目 / 最近使用」，「回家」入口可回到欢迎页。
- 新增统计看板面板（四张概览卡 + 刷新），挂中央组、默认不激活，由状态栏入口唤起；设置里有 `layout.dashboard_enabled` 开关。
- 旧 `EditorPanel` 摘掉概览取数与卡片出口；草稿冲突 Diff 状态上移到 `Shared`。

## 面板与导航骨架

- 分组头抽成 `tree::GroupHeader` 原语（草稿箱×4 + 导航×1 一起迁），分组行估高跟着它走 22。
- 分组头底色通栏（行级左内距下沉到行根）；分组改名只留原格就地编辑。
- 面板第一行紧贴标签条（删掉面板根自己的顶内距）；Dock 自绘面板头不再吃 8px 内容内距。
- 草稿箱搜索 / 替换 / 包含 / 排除四行同一档；面板内搜索框统一「无边框 + input 底」。
- 树里计数统一纯文本；恢复右键「编辑分组…」入口（描述可一起改）。

## 标题栏与组件库

- 标题栏项目下拉菜单：菜单定宽，长文案不再溢出；归档项反映状态并把图标槽让给对勾；只读说明改成说明行；删掉重复入口。
- 组件库私有 patch：菜单项禁用语义进无障碍节点，分隔线不再冒充菜单项。

## 已知问题

- beta 只出 Windows 包；Linux / macOS 需要等定版标签。
- 未签名、未公证：Windows SmartScreen 会拦一次。
- 驱动能力靠插件：Oracle / SQL Server 需要装对应的驱动插件包，且两版 Oracle 互斥（默认装 Rust 版）。
- 主题包是 opt-in，需要在外观设置里手动选择才会启用。
- 文件型资产的「全局引用」后置，本版只支持表型引用。
- 整项目导出、文件引用、全局版本回退 UI 后置。
- clippy 存量告警仍在千条量级，CI 因此不设 `-- -D warnings` 硬门禁；清理单独排期。
