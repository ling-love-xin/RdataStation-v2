# RDS beta 0.2.13

> 2026-11-25 · 相对 `RDS-beta-0.2.12` 的 213 个提交 · beta：本版只出 Windows 包

## 本次重点

- **界面能整体切英文**：外观设置里选 English，工作台壳层、设置、编辑器、结果集、洞察、分析资源库、数据库导航、草稿箱、项目、通知、Mock 都跟随切换，词表从 1089 条扩到 1661 条。
- **数据对象面板重做**：按「源 / 表 / 文件」三段重排；源段改成三级树（别名 → schema → 表 / 视图），行上按钮全部收进右键菜单；一页只画 200 张叶子、列举挪到后台，大库不再卡。
- **结果集面板继续对齐 DBeaver**：矩形选区（正文拖拽、任意格起拖、行号槽整行、列头整列、交角全选）、方向键与 `Home` / `End` 挪焦点格、结果内查找改成覆盖网格的浮层、对象格单击出非模态信息浮层。
- **面板工具栏统一**：11 处面板的工具栏迁进同一个容器，底色与下界取主题，主题键 141 → 143。
- **项目中心退役**：项目操作并入全局设置「项目」页，并补上真正的「切换项目」语义——有项目时也能新建或打开别的项目。
- **Notebook 能收键盘输入了**：`input()` 走内核 stdin 通道，`getpass()` 自动遮挡；内核事件由 60ms 轮询改成事件唤醒。

## 界面语言

- 外观设置切换语言立即生效，两个窗口一起重绘；组件库自带的确认 / 取消、占位、分页等文案也跟随（此前恒为英文）。
- 覆盖到位的区域：连接对话框、设置页、工作台壳层、编辑器（含对话框与签名帮助）、结果集、洞察、分析资源库、数据库导航、草稿箱、项目、通知、Mock，以及枚举显示名与缓存的画像标签。
- 未覆盖的主要是错误与诊断类长文案（全仓复核后任意长度未登记 83 条），这些仍显示中文原文。

## 数据对象面板

- 三段口径固定为「源 / 表 / 文件」：源段收已注册的分析源与已挂载的文件库，表段收库里的表 / 视图，文件段收登记过的文件。
- 源段改三级树：连接别名 → schema → 表 / 视图；叶子行带 SQL 引用名与「查」入口，行上的按钮全部收进右键菜单（洞察、作为 Mock 结构来源、导出、属性、版本…）。
- 源行叶子按页画（一页 200 张）并挪到后台线程列举，展开一个几百张表的库不再顶住界面。
- 工作集按文档记忆并落盘，重开面板顺序仍是加入先后。
- 三个新出口：归档到分析库（表型资产登记）、载入内存（在分析库里建可查的临时对象）、存为快照（文件）。
- 单行清理：删一张临时表不必再「全部清理」。
- 网络连接按加速会话判「挂没挂」，未挂的连接不给展开指示。

## 结果集面板

- 矩形选区一整套：正文拖拽选矩形、可从任意格起拖、行号槽按下选整行、列头按下选整列、左上交角点击全选；状态行「已选 N 格」按矩形规模算。
- 键位：方向键与 `Home` / `End` 只挪焦点格不改选区；`PAGE_UP` / `PAGE_DOWN` 整页翻。
- 结果内查找改成覆盖网格的浮层（对齐 DBeaver 的 FindReplaceOverlay），查找不再是状态栏里的一个小框。
- 对象格（当前格所在对象）单击出非模态信息浮层，文本取来源 SQL 原文，保留血缘行；图标改 `file-code`，对象名用主题绿。
- 计算页按列分组聚合，工具条带「−」，六项顺序定案；分组页改成 DBeaver 那种「页内嵌结果集」形态。
- 右栏五页（值详情 / 引用 / 列浏览器 / 分组 / 计算）与筛选列浏览器页顶的 filterPanel 对齐；页签条支持双击最大化与拖拽重排。
- 工具栏收口 + 结果标签右键菜单（两批）。
- 修掉一处崩溃：筛选 SQL 预览按字节切片会 panic。

## 编辑器与 Notebook

- 内核 stdin 输入行：单元格等输入时出现输入框，回车提交并清空；`getpass()` 依据 `password` 标志遮挡回显。
- 中断兜底：Windows 上 ipykernel 不支持控制通道中断，改用关闭内核兜底；删掉等待输入的单元会撤等待态并中断执行。
- 撤销等待态时清空输入值，输入不会带上一条请求的内容（含密码漏进下一条请求）。
- 事件泵由 60ms 轮询改为事件唤醒，空转开销消失。

## 项目与工作台

- 项目中心退役：原覆盖层并入全局设置「项目」页，动作投回主窗口。
- 真正的切换语义：已有项目时也能新建 / 打开别的项目，切换后清单自动跟上；示例项目入口同样走切换。
- 版本台账支持行内删除（两段式确认），设置概览显示归档状态；设置面板与标题栏菜单的写动作统一走 toast 反馈。
- 资产身份改用 `resource_id`，不再按名字认人。
- 标签页状态槽、脏点唯一化、关闭前询问、侧栏可关，文件类型图标补齐。
- 版本信息弹窗补到 14 项（语义 / 排版 / 引擎 / 渲染 / Mock）。

## 主题与面板骨架

- 新增 `border.variant` / `toolbar.background`，补 `list.highlight.foreground`，键表 141 → 143。
- 等宽字体族不再写字面量，改走 `theme.mono_font_family`。

## 性能

- 数据对象面板不再每帧整表克隆。
- 源行展开的列举挪到后台线程，叶子按页渲染（一页 200 张）。
- 内核事件改事件唤醒（见上）。
- 数据对象导出改后台写盘。

## 已知问题

- beta 只出 Windows 包；Linux / macOS 需要等定版标签。
- 未签名、未公证：Windows SmartScreen 会拦一次。
- 驱动能力靠插件：Oracle / SQL Server 需要装对应的驱动插件包，且两版 Oracle 互斥（默认装 Rust 版）。
- 主题包是 opt-in，需要在外观设置里手动选择才会启用。
- 英文覆盖还剩错误与诊断类长文案（任意长度未登记 83 条），这些仍显示中文，等产品口径定下来再补。
- clippy 存量告警（千条量级，本轮 1060 处 `-->`）尚未清零，CI 因此不设 `-- -D warnings` 硬门禁；清理单独排期。
