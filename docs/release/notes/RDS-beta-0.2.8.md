# RDS beta 0.2.8

> 2026-11-09 · 相对 `RDS-beta-0.2.7` 的 338 个提交 · beta：本版只出 Windows 包

## 本次重点

- **渲染内核换代**：升到 gpui-kit 0.9.0 并启用 gpui-fast 渲染路径，界面尺寸与配色统一到新的 widget 档。
- **分析模式能日常用了**：Python 单元接上语言服务（补全、悬停、逐单元诊断），内核改为按 Jupyter kernelspec 启动。
- **结果集表格对齐 DBeaver**：列宽自适应与持久化、列隐藏/冻结、多列分组、右栏可拖宽、日期与布尔列就地编辑。
- **插件系统闭环补齐**：安装 / 卸载 / 重载、必装依赖对账、随包与加载期校验和、覆盖安装失败回滚。
- **新增「资产库」面板**：归档、取回、版本历史与对比、回收站、索引修复、标签分组。

## 编辑器与分析模式

- Python 单元：补全、悬停、诊断都进单元；普通 `.py` 文件支持「转到定义」。
- 分析单元创建面收敛为 **Python / Markdown / SQL**（R、Julia 退出创建面，已有单元仍可打开）。
- 内核按 Jupyter kernelspec 启动：内置环境优先（`ks:` 且 ready 时直接用），否则按 PATH 找解释器。
- Python 语言服务器改走 console script 启动（jedi-language-server 没有 `__main__`，原来的 `-m` 起不来）。
- SQL 单元接上目录补全；逐单元诊断在编辑时就地提示。
- 脚本执行超时可配置（设置项 `editor.env_timeout_ms`，随请求进执行线程）。
- 事务内的单条语句有墙钟超时：到点放弃事务、断连再重连，不再无限等。
- 书签常显书签列（可用设置关掉）；书签与折叠说明显示在行号栏，悬停看说明；跳到书签后自动展开该行说明。
- 结构块折叠时末行一起收起（对齐 VS Code 的折叠范围）。
- 右键菜单补「执行 / 执行全部」。
- 执行的 SQL 血缘记进历史，SQL 预览弹层显示来源行。
- 结果区上下分栏的高度随会话持久化；切换连接会立刻刷新单元诊断，不必重开文件。

## 结果集

- 列宽自适应：双击列头分隔线按内容算宽；新列按类型给默认宽，不再一律 128px。
- 列宽跨会话记住；列的隐藏 / 冻结状态落盘。
- 分组页：多列分组、排序口径、只看重复行，并新增「清空分组列」。
- 右栏：值详情 / 分组 / 执行 SQL / 计算四页统一页内工具条；宽度可拖且记住；布局方向可切换。
- 值详情支持「保存值」（对齐 DBeaver 的「保存至文件…」）。
- 筛选区按 DBeaver 列序重排；输入框改成多行：常态 1 行、展开 5 行。
- 日期列用日历选择器、布尔列用双态按钮，选中即提交（与原编辑通道同一条路径）。
- hex 转储可以翻页；二进制里的图片可直接预览；列浏览器支持多选批量动作。
- 分页与行号跳转接线完成。
- 标签条补齐图标、关闭、tooltip、拖拽重排；工具栏收成纯图标 + 切换态 + 竖分隔，高度降到 32px 档。
- 配色槽对齐 DBeaver：斑马纹、脏格、冲突格、本地行四色分明。

## 导航

- 归属域改成固定矩形胶囊，悬停高亮落到底框。
- 连接行不再挂错误摘要（错误留给状态与详情，行本身保持干净）。
- 行尾操作组改为浮层，不再压住名称；连接 / 目录 / 列行都有完整名悬停卡；名称设最小宽，注释副标先让位。
- 分组折叠入口移到面板头工具栏，作用域是当前认领的分组；「全折叠」只收本组；分组批量图标与归属域徽标右对齐。
- 窄画布下导航树外壳可横向滚动、右对齐恢复，并随面板拖拽跟随。

## 洞察（Insight / EDA）

- 列卡片按 YData 版式重排：一列一行、折叠统计块、分位条、16 柱直方图、极值双小表。
- 空集合改用标准空态组件；信任横幅区分「内容已变化」与常规提示。
- 信任门加了内容指纹（迁移 027）：`git pull` 带进的新规则不会再被静默放行。
- 源库全量档加护栏：超过 100 万行直接拒拉并给取样引导，不做静默截断。
- 修复：EDA 点击闪退（无障碍重复 id，两轮根治）、双栏联动死循环导致的 panic、`mini_stats` 竞态、慢查询未登记。
- 大表渐进渲染；五张概要卡可互相跳转；弹窗按钮条统一。

## 数据生成（Mock）

- 列管理区宽度自适应，属性弹窗重排；表配置 Tab 收口（列区、生成状态并入动作行、全局通知、分栏修复）。
- 修复草稿箱文件名不一致、列编辑产出类型不同步。

## 插件与驱动

- 面板补上「安装 / 导入插件包」「卸载（带确认）」「重载」入口。
- 安装前对账必装依赖；依赖随登记同事务落库，反向依赖检查真正生效。
- 安装期校验随包 checksums，加载期再复核一遍：装好之后被改也能拦住。
- 安装改为「暂存目录整体换入」，热插拔不会扫到半成品；覆盖安装失败时恢复旧插件运行，不把已启用插件留成停用态。
- 坏包留在列表里可见、可卸载，但拒绝启用；失败的插件可以点重试加载；缺依赖的报错文案不再出现 `Plugin '' missing dependency '@'` 这种残句。
- 贡献点注册表（三表合并 + 跨插件冲突在加载期拒绝）；面板行显示插件贡献了多少贡献点。
- 热插拔清单变化会发 `PluginChanged`；面板订阅生命周期事件，重试成功后补登记。
- 面板列表透出真实运行状态（此前 sidecar / frontend 一律被写成「已停用」）。

## 资产库（新面板）

- 归档、取回、版本历史与版本对比、回收站、索引修复、标签分组、重命名与移动（多选时「移动…」作用于整集）。
- 草稿箱行右键接上「归档为存档…」，归档会保留在对话框里选的分组。
- 只读项目里分发按钮置灰。

## 依赖与构建

- gpui-kit `0.9.0`，并启用 gpui-fast 渲染内核。
- DuckDB 升到 v1.5.6（`duckdb` crate `1.10506.1`）。
- sqlglot-rust 升到 `0.11.1`，方言转译能力在设置里开关。
- 另有 12 个补丁版本依赖批量升级。
