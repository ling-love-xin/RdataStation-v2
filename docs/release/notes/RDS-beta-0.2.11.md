# RDS beta 0.2.11

> 2026-11-20 · 相对 `RDS-beta-0.2.10` 的 217 个提交 · beta：本版只出 Windows 包

## 本次重点

- **数据对象面板按口径重做**：清单拆成「挂载源 / 持久表 / 文件 / 临时表」四段，挂载源那一行能展开列出它下面的表与视图（表与视图用不同图标、非 main 的 schema 挂在行尾、名字可一键复制）；`.duckdb` / `.sqlite` 库文件能直接挂成只读源，数据文件则以视图进「文件」段。
- **连接配置中心成型**：左栏三域计数、类型目录置顶、页头统计条、按名称搜索与按类型筛选、「列表 ⇄ 表单」两种形态；密钥来源可选三档，切档时全量重加密。
- **连接级策略能压过环境策略**：环境上的 DML 需确认 / 审计 / 超时与行数上限，可按连接单独覆盖；PROD 连接在编辑器状态栏挂徽标，schema 白黑名单直接决定导航里内省哪些 schema。
- **结果集右栏对齐 DBeaver**：右栏换成「已启用集合」——六页可逐页关闭、竖条只切页不再收起整栏；筛选设置分成两页签并可显式保存 / 重置；结果内查找栏带大小写 / 正则 / 全词三档与「仅显示匹配行」。
- **外观与启动**：外观设置新增「窗口材质」（Mica / Mica Alt）；配了主密码的档，启动时先出解锁窗再进主界面；设置页补 SQL 格式化开关与实时预览。

## 数据对象面板

- 清单按口径分四段：挂载源、持久表、文件、临时表；资产里的表型条目不再混进自建表清单。
- 挂载源行可展开，子行按表 / 视图区分，带 schema 行尾与复制名字；展开过的源在刷新后保持展开。
- 加载入口按文件形态分派：库文件挂成只读源（回执写「挂载」），数据文件加为视图（回执写「视图」）；连库线经持久开关走联邦。
- 通道文案统一取自一处定义，不再出现「→ → 联邦」这种叠箭头；顶部筛选 chip 由六个收成五个。

## 连接与配置中心

- 配置中心页外壳落地：左栏类型目录置顶、暂存列表沉底，三域各带计数；页头一条统计条，列表可按名称搜索、按类型筛选。
- 「列表 ⇄ 表单」两态可切换；Tab 收敛为「常规 / 网络 / 高级」，能力矩阵与驱动属性并入高级页尾。
- 密钥来源三档：可逐连接选档，切档时把该档下的连接全量重新加密。
- 地址字段成为唯一真相源，URI 改为只读派生，不再两处各写一份。
- 网络配置改成两层模型并支持链式展开；无驱动的类型在侧栏常驻「N 个类型暂无驱动 + 安装驱动」，点进去直达插件管理页。
- 作用域选「仅项目」却没选项目时，保存前就拦下来；窗口变窄时对话框宽度跟着夹取，按钮不会被顶出屏幕。
- 连接首次打开时六条目录查询并发发出，且整个模块共用同一个运行时，不再每次开窗重建线程池。

## 结果集面板

- 右栏六页（结果 / 计算 / 分组 / 值 / 列 / 引用）可逐页开关，关闭按钮收在页签内侧；关空后重新展开会恢复默认页集合。
- 筛选设置扩成两页签，列约束页的「可见 / 冻结」真能切换，列序支持四个移动按钮与排序；筛选条上的 ✕ 表示删除全部过滤与排序。
- 筛选历史下拉、状态历史的分裂按钮（前进 / 后退）、列头菜单尾部的保存 / 重置 / 全清 / 编辑筛选设置都补齐。
- 结果内查找栏接上实际查找：三档口径（大小写 / 正则 / 全词）加「仅显示匹配行」。
- 计算页统计项补到九项，带右键菜单、默认集与 Reset，启用集合跨会话记住；分组页正文改成表，可上移 / 下移 / 移除分组列、可选「不排序」、可只看重复行。
- 列浏览器列出列注释第二行、可复制列名、可生成 DDL；引用页接上外键清单，能按当前行值另开一个结果集。
- 状态行补「段大小」输入框与「计算行数」动作；段大小、右栏页签集合、状态栏命令显隐、分组排序口径都会记住。
- 表格打磨：列竖分隔线、表头底色与列边界线、单元格 6px 内距、行号加粗、整行选中铺色。

## 外观与启动

- 外观设置新增「窗口材质」：Mica 与 Mica Alt 两档，只作用在标题栏、状态栏、页签栏与侧栏，其余区域保持纯色。
- 主密码档启动先出解锁窗，解锁后才进主界面。

## 稳定性与修复

- 「边打边筛」此前只改了界面没接上订阅，现在逐键过滤真的生效；整行选中与网格事件也重新挂上，不再点空白处就失效。
- 右栏被全部关掉后再展开，恢复默认页集合而不是空栏。
- 值页的「保存值到文件」在整行（NULL）与行号槽上按条件置灰；筛选框空态提示改用 DBeaver 同一句文案。
- 侧栏、统计页、布尔格、工具栏上的选择型按钮补上按下态，能看出当前是按下还是未按。

## 已知问题

- beta 只出 Windows 包；Linux / macOS 需要等定版标签。
- 未签名、未公证：Windows SmartScreen 会拦一次，macOS 需手动放行。
- 驱动能力靠插件：Oracle / SQL Server 需要装对应的驱动插件包，且两版 Oracle 互斥（默认装 Rust 版）。
- 主题包是 opt-in，需要在外观设置里手动选择才会启用。
- 窗口材质只覆盖标题栏、状态栏、页签栏与侧栏，不同壁纸与主题下观感差异较大，尚未逐主题核验。
- clippy 存量告警（千条量级）尚未清零，CI 因此不设 `-- -D warnings` 硬门禁；清理单独排期。
