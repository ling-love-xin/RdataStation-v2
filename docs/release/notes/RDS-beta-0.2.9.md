# RDS beta 0.2.9

> 2026-11-14 · 相对 `RDS-beta-0.2.8` 的 129 个提交 · beta：本版只出 Windows 包

## 本次重点

- **插件管理页成型**：新增驱动登记总表、批量启用 / 停用、「重试全部出错」、每行可查看详情；停用被依赖的插件会在入口就被拦住并说明原因。
- **Oracle 与 SQL Server 有了原生 Rust 驱动插件**：Oracle 支持分页重查，SQL Server 补登录提示并逐行消费结果集。
- **内核驱动收口**：内核自带的 sqlx 驱动退役，每族只留一条官方驱动；新增 sqlx-rust 双驱动 sidecar（MySQL + PostgreSQL 同一进程），默认驱动换成官方实现。
- **主题包可换**：外观设置里能切主题包，切换即时重装主题与产品 token；随包 8 套明暗方案（含青花 / 朱砂 / 墨金三套中国风）。
- **换驱动包不用重启宿主**：插件载荷更新后自动重启该插件；重启前先核随包校验和，坏载荷不上线。

## 插件与驱动

- 管理页：驱动登记总表、批量启用 / 停用、「重试全部出错」、登记明细每行可查看插件详情；筛选与驱动登记状态一并加厚。
- 依赖守卫铺到每条入口：启用前校验依赖已安装且已启用；停用与卸载也不能再绕过；被依赖的插件停用按钮置灰并写明原因；详情栏依赖提示覆盖停用场景，依赖项可直接跳转。
- 校验和一套口径：安装脚本自动生成 checksums（没有外部文件时不写空键）、随包校验覆盖 `driver_jars` 外部文件、加载期再复核一次。
- 载荷更新自动重启：换驱动二进制不用重启宿主；插件上还有活动会话时不擅自重启。
- 操作留痕：安装 / 启用 / 停用 / 卸载 / 重载 / 缺驱动被拒全部写库（迁移 030），插件管理页新增「操作记录」栏，能力 Tab 显示「来源 + 最近同步」，历史面板可按驱动过滤，留痕可导出 JSON 排障。
- 宿主内新增「重算校验」：换过包被哈希挡住时可以自助收口。
- 驱动 id 冲突在面板上显式报告，冲突卡点旁可直接停用插件。
- 打包侧新增 `pack.ps1` 打 zip 发布包（与安装同一套 checksums）；`install.ps1` 改用 robocopy 复制，安装目录不再带开发残留。

## 驱动

- Oracle / SQL Server 原生 Rust 驱动插件上线；元数据列按真实类型取值，修掉导航面崩溃；两版 Oracle 安装互斥，安装脚本默认只装 Rust 版。
- 内核 sqlx 实现退役：驱动表里的内核 sqlx 两行下线，每族只留一条官方驱动；`crates/driver-sql` 抽出纯数据层（元数据 SQL、PostgreSQL wire 解码、码表），内核改为 re-export。
- sqlx-rust 双驱动 sidecar：一个进程供多个驱动；非 UTF-8 的服务端错误消息补了可读提示。
- 能力字典新增 9 个元数据面能力位，6 个驱动按实测声明；驱动声明落 drivers 表，管理页补齐展示事实。
- 新增 TableFacts 汇总事实通道：sidecar 直出索引数与行数。
- 例程源码接上 `meta.routine_source`，不再永远是空。

## 连接与属性

- 切 schema 真正影响执行：MySQL 会话重放、引擎用真连接 id、解绑后恢复默认。
- LAN 关 TLS 的开关按各客户端库真实默认重推（含 PostgreSQL 原生驱动）。
- 旧草稿载入时一并清掉快照里的旧地址；切换连接类型会清掉旧库 URI 与凭据。
- 无可用驱动时的提示改成可操作的插件指引，不再只报「没有驱动」。
- 属性门控改到驱动级：驱动明确给不出的维度先判门控再决定是否发请求，取数失败不再被吞成「0 条」；属性分区新增不可用态（置灰 + 原因）。
- 连接对话框 Header 的「驱动」标签改为「驱动类型」，标签列按最长标签加宽。

## 主题与外观

- 主题包按目录加载（opt-in），随包 8 套（每套 140 键）明暗方案，含青花 / 朱砂 / 墨金三套中国风。
- 外观设置接入主题包，切换即时重装主题与产品 token。
- 中性按钮 hover 色从按钮自身派生，并补了分层强度自检。

## 资产库

- 业务断言、效力状态与资产谱系：断言接入表单、语义搜索、详情与主动校验。
- 资产履历落库与版本时间线；取回凭据贯通——取回、改、再归档回原档并升版，全程可回溯。
- 归档写入事务化、本体 staging 原子替换、永久删除带关联清理；作业通道失败可感知，worker 不会被单个 panic 带走。

## 稳定性

- 插件宿主请求级 panic 隔离：单条请求炸掉不再打死 sidecar。
- 全局系统初始化加互斥门，避免并发重复打开 `analytics.duckdb`。
- 插件启动首轮扫描先于窗口首帧完成，首屏不再出现「未登记」的空窗。
- 目录先消失的插件登记行按 `install_path` 兜底清理；卸载时清掉待重载标记与扫描快照。

## 内部

- workbench 三个大文件拆成目录模块（`view`、`plugin_tab`、`left_tabs`）。
- 插件扫描不再每次 tick 重新解析清单，并顺带把 `ScanEntry.version` 填实。

## 已知问题

- beta 只出 Windows 包；Linux / macOS 需要等定版标签。
- 未签名、未公证：Windows SmartScreen 会拦一次，macOS 需手动放行。
- 驱动能力靠插件：Oracle / SQL Server 需要装对应的驱动插件包，且两版 Oracle 互斥（默认装 Rust 版）。
- 主题包是 opt-in，需要在外观设置里手动选择才会启用。
