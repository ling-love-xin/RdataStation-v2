# RDS beta 0.2.10

> 2026-11-17 · 相对 `RDS-beta-0.2.9` 的 209 个提交 · beta：本版只出 Windows 包

## 本次重点

- **结果集能接着分析**：结果集右键「分析此结果集」，先在默认物化成 `tmp_q_` 临时表，再可落成项目表（`res_` 前缀 + 中文描述 + 时间戳）；洞察产物也能再分析一次。
- **分析内核收成三档**：源库直连 / 本地加速 / 联邦共用一套开会话出口，挂载计划、源翻译与物化各自独立，三档都有真跑用例兜着。
- **多源取样一次采完**：一个任务里逐源各取一份，各落一张 `tmp_i_`，取齐再算画像；界面上是选择器多选 + 一个面板内的来源标签页。
- **右 dock 新增「数据对象」面板**：按 DuckDB 容器分组，能搜索、能按段筛选，行内直接设主源 / 重挂 / 关会话，还能加源、刷新、把对象送进洞察。
- **来源选择器重写**：三分法入口 + 懒加载树 + 跨根搜索 + 行首类型图标，大列表（>60 行）切虚拟视口，库再大也不卡。
- **资产库补上表型资产**：本体列、整表升级到全局、分发回执、全局按版本铺表、回收站履历与版本时间线，详情页按原型逐轮对平。
- **DuckDB 扩展有据可查**：三处装扩展收敛成一条通道并登记到 `global.sqlite`，留痕分清 install 与 load，插件管理页把扩展摊成三方对照。

## 分析内核与联邦

- 分析内核三档收口：通道与连接引用类型先定型（含单测），挂载计划与源翻译独立成段，`open` 一条出口给三档；联邦档开会话改走公共内核。
- 挂载计划带别名与说明，预组装源逐条对账。
- 物化按执行面分派，新增第四条执行面（进程内存单例）；临时表按仓库规范命名，并补了清理入口。
- 结果集默认物化为 `tmp_q_` 临时表，可取数、可二次分析；再进一步落成项目表，跨实例搬运原语把数据搬到位。
- 全局表挂到 `analytics.duckdb`，全局库也能当会话源（短命联邦会话 + 只读挂载）。
- 联邦执行前先弹确认卡写明扫描量，不提供采样（采样只归洞察）。
- 会话快照能枚举占用者；持久表清单与删除的原语落地。

## 多源取样与洞察

- 多源取样：`SampleSet` + 每源各取一份，逐源建 `tmp_i_`，一次全取再算画像。
- 界面：来源选择器多选，取样结果在一个面板里按来源分标签页。
- 洞察产物成为新的资产档，可直接再分析。

## 来源选择器与数据对象面板

- 来源选择器拆成目录模块：行模型（`NodeId` / `NodeKind` / `Row`）、树态（展开 / 搜索 / 选中 / 最近使用）、三分法分组、数据库根懒加载树，三个根共用一套行渲染。
- 跨根搜索有档位与排序；行首按类型给图标，打开即展开首根。
- 虚拟视口只在超过 60 行时启用。
- 数据对象面板：工作集与行内加入、加源入口、按 DuckDB 容器分组、业务身份标签跟在名字后面、行内会话动作（设主源 / 重挂 / 关会话）、按名字搜索、按段筛选、段头可收起、空态用标准组件；面板头部显示进程库占用，底部显示会话挂载数。
- 已加载的外部文件、联邦会话源、资产持久表都进同一张清单；面板启动预载并给工作集设软上限。
- 资产库清单改用只读连接，不再顺手建库。

## 资产库

- 表型资产有本体列，可从数据对象直接打开、直接分析；整表能升级到全局并留下分发回执；全局按版本铺表，读取面按登记行反查。
- 跨项目搬运每一跳都留下来源线索；覆盖分发失败时能把旧内容搬回原位。
- 回收站迁入与还原各记一条履历事件；全局历史版本的表也按保留策略裁剪。
- 版本区从列表改成可点的竖排选中式时间线，报出「几份可还原」，副本已裁剪会标出来。
- 详情页：标题条钉在顶部不随内容滚动、分区标题下沿一条分隔线、头部版本徽标与预览头对齐、本体路径与分析库表名可复制可悬停看全、补创建时间与「谁在用」、表型资产摆「重建定义」。
- 标签对话框清掉重复与空语句，改动那行不再是灰的；属性弹窗改用 `DescriptionList`（草稿箱文件属性弹窗同款）。
- 存档种类收成两档，迁移清单只剩一处。

## 插件与驱动

- 驱动 id 做族归一，补上归属列与建连族回退。
- 插件管理页把 DuckDB 扩展摊成三方对照；没登记的扩展留了两条出口（认领 / 重新扫描）。

## DuckDB 扩展

- 三处装扩展收敛成一条通道，装完登记到 `global.sqlite`，留痕区分 install 与 load。
- 扩展清单补 `loaded_files`，耦合表能认出已加载的文件视图。

## 主题与外观

- RDS Dark 表头文字对比度 3.47:1 → 4.73:1（只改文字色，表头底不变）。
- `gen_theme_preview` 支持 `--theme` / `--out`，任意主题包都能出预览，按当前模式取明暗、不认主题名。

## 稳定性与性能

- 来源选择器大列表切虚拟视口，滚动与展开不再全量重排。
- 脚本内容表多于一行时报错，不再静默取首行；脚本提升到全局前先挡住体积。
- 结果集分析走全量桥接，不再截断。

## 内部与测试

- workbench 三个大文件继续拆目录模块（`view` / `plugin_tab` / `left_tabs`）；来源选择器拆成模块。
- 驱动下拉断言对齐「短名 · 归属」标签（`sqlx · 内置` / `rusqlite · 内置` / `Official · 内置`），此前是滞后断言。
- 新增并发窗口探针（mock 落库与项目分析库）与分析内核三档真跑用例。
- 扩展指纹校验（`verify`）从孤立的源文件接进编译面：按现状回填指纹并记一条留痕，目前还没有界面入口。
- 仓库侧：`__pycache__` 与 `*.pyc` 进 gitignore；业务向说明移入 `docs/business/README.md`。

## 已知问题

- beta 只出 Windows 包；Linux / macOS 需要等定版标签。
- 未签名、未公证：Windows SmartScreen 会拦一次，macOS 需手动放行。
- 驱动能力靠插件：Oracle / SQL Server 需要装对应的驱动插件包，且两版 Oracle 互斥（默认装 Rust 版）。
- 主题包是 opt-in，需要在外观设置里手动选择才会启用。
- clippy 存量告警（约 1040 条）尚未清零，CI 因此不设 `-- -D warnings` 硬门禁；清理单独排期。
