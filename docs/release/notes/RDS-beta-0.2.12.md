# RDS beta 0.2.12

> 2026-11-23 · 相对 `RDS-beta-0.2.11` 的 112 个提交 · beta：本版只出 Windows 包

## 本次重点

- **数据对象面板多了「源库表」一段**：已连接的库不用先挂载，展开连接就按 catalog → schema 逐层列出它下面的表与视图（远端内省只在展开时发生），叶子行带所在 `catalog.schema` 与「选用」按钮。
- **工作集回到多选**：再点一次同一个对象就是移除，顺序按加入先后保留；攒过 8 个会提示「首次取样会明显变慢」，但不禁用。
- **面板会自己跟上现实**：新建结果集、留下洞察样本、挂载文件、连接上下线、资产与项目切换之后，1 秒内自动重取清单，不用手动刷新。
- **结果集面板继续对齐 DBeaver**：筛选存档落盘、右键菜单补齐三段、31 条键位接线、右栏六页可逐页开关。
- **底层换代**：gpui-kit 0.10.0（配 gpui-fast 0.1.17 / gpui-pre 0.3.12）、SQL 排版引擎换 lax-sql 0.3.0、通知中心重做。

## 数据对象面板

- 新增「源库表」段，排在「已挂载源」之后：一级行是**已连接**的库（零 I/O，直接取宿主快照），行尾写「驱动 · host」；展开后逐层 introspect（catalog → schema → 表 / 视图），按（catalog、schema、名字）排序。
- 表叶子行：缩进 + 表图标 + 名称 + 所在 `catalog.schema` + 「选用 / 已选」按钮；连接本身不算数据对象，不能直接选。
- 空态分开说：连接展开后没东西是「这个连接里没有可列的表 / 视图（目录为空或没有权限）」，挂载源空是「没有可列的表（挂载成功但目录为空）」。
- 工作集恢复多选：同一个对象再点一次即移除，按加入先后保序；tray 与主按钮按个数换文案——1 个是「洞察此对象」，N 个是「洞察这 N 个对象」。
- 选中的源库表先按驱动方言拼成取样来源再递交，与其它对象去重；一个都转不进洞察时直接说「选中的对象都转不进洞察：<原因>」，不给人开一个空面板。
- 段头写明三条口径：每组只显示最新版本、洞察产物（`tmp_i_`）不进本清单、源库表要展开连接才列（远端内省有代价）。

## 结果集面板

- 筛选存档可落盘：同一会话内切换结果集不再丢筛选；筛选条列序对齐 DBeaver（历史下拉前移、组间加分隔线）；`ALT+SHIFT+F` 直接打开筛选设置浮层。
- 右键菜单补齐 layout / filters / edit 三段，新增「在结果中查找…」「从上一行复制」「从下一行复制」「修改单元格」「重置单元格」，灰项按行状态判可用。
- 31 条键位接线：`ENTER` 进内联编辑、`` CTRL+` `` 网格⇄文本切换、`CTRL+S` 提交 / `CTRL+R` 撤销、`ALT+INSERT` 新增行、`CTRL+ALT+N` 取下段、`CTRL+G` 行号跳转、`ALT+SHIFT+H` 隐藏列、`F7` 右栏整组开关等；`ESC` 收起结果集内四个浮层。
- 右栏六页（结果 / 计算 / 分组 / 值 / 列 / 引用）可逐页开关，关空后重新展开会恢复默认页集合；状态行补选中统计三项，斑马线跟随主题、行号槽可复制行号。
- 「获取全部数据」改成真循环（此前名字与行为不符），并与导出互斥矩阵闭合。

## 编辑器与内核

- Jupyter 内核事件携带执行归属 `msg_id`，杜绝跨单元串台。
- 内核事件收口规则下沉为纯函数，事件路径可单测。

- 「关于」弹窗显示构建期版本标识。

## 通知中心

- 重做：相对时间、节流落盘、替换式合并、单条已读。

## 已知问题

- beta 只出 Windows 包；Linux / macOS 需要等定版标签。
- 未签名、未公证：Windows SmartScreen 会拦一次，macOS 需手动放行。
- 驱动能力靠插件：Oracle / SQL Server 需要装对应的驱动插件包，且两版 Oracle 互斥（默认装 Rust 版）。
- 主题包是 opt-in，需要在外观设置里手动选择才会启用。
- 窗口材质只覆盖标题栏、状态栏、页签栏与侧栏，尚未逐主题核验。
- 右栏六页没有 `FocusHandle`：`CTRL+SHIFT+F2..F6` 只激活不切焦点、`CTRL+SHIFT+7`、「打开单页把焦点交给该页」三项仍未接。
- 面板可见性与结果集偏好尚未跨会话落盘。
- 上游键位仍未接：`SHIFT+F11`、`F11` / `CTRL+F11`、`ALT+SHIFT+ARROW`（移列）、`TAB`、`CTRL+BACKSPACE`、`ALT+SPACE`、`CTRL+SHIFT+1`、`CTRL+2`、`SHIFT+ENTER`；`ESC`（`cell.reset`）结构性不可行（组件 `DataTable` 自带 `escape → Cancel`）。
- clippy 存量告警（千条量级）尚未清零，CI 因此不设 `-- -D warnings` 硬门禁；清理单独排期。
