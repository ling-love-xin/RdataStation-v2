## 0. 背景与取舍基线

- 模块定位（用户确认）：数据分析平台，**非团队协作工具**；需承载同一项目的**版本变化**与**分析过程留痕可追溯**。
- 现有连接模块已收尾（M3 主线完成），以下增量全部为"轻增强"：不新增 Tab、不改对话框高度、不增加存储负担主路径。

## 1. 生命周期与留痕（v2 核心增量 · 待评审 #A）

### 1.1 连接变更历史（connection_audit）

| 项 | 方案 |
| --- | --- |
| 动机 | 现有 `updated_at` 只能答"最后改过一次"，答不了"改过几次、每次是什么"。对"留痕可追溯"，连接配置变化也是分析过程的一部分 |
| 落点 | 轻量审计表 `connection_audit(id, connection_id, action, ts, summary)`；保存 / GP_ 同步时写一条 |
| 摘要 | 记录动作（create/edit/sync/test）与可读摘要（如"主机 192.168.1.40 → 127.0.0.1；测试通过 8.4.0 · 12ms"） |
| UI | 高级 Tab「生命周期与留痕 → 变更历史」时间线；当前版本徽标；「查看全部变更 →」入口 |
| 约束 | 不进主连接表；不与凭据混存；不记密码明文 |
| 风险 | 低频写入，存储可忽略；注意 GP_ 同步动作也须落一条（同步本身可追溯） |

### 1.2 分析足迹入口（跨模块协作）

| 项 | 方案 |
| --- | --- |
| 动机 | 追溯的不只是配置，而是"这条连接做过什么分析"（查询 / 结果快照 / 洞察） |
| 落点 | **只做入口，不复制内容**；数据来自现有 history_store / analytics_resource（零 UI 造数据原则不变） |
| UI | 高级 Tab「生命周期与留痕 → 分析足迹」：最近查询 / 结果快照 / 洞察各带「打开 →」跳转 |
| 归属 | 入口在连接模块（M3），数据在历史层（跨模块协作，不新增表） |

### 1.3 快照同步状态（仅 GP_ 显示）

| 项 | 方案 |
| --- | --- |
| 现状 | 只有「从全局定义同步」按钮，无状态提示，同步前不知道落后多少 |
| 增量 | 编辑 GP_ 时显示同步徽标：「与全局一致 / 落后 N 次变更 / 独立」；同步保留快照 ID / 创建时间 / 分组关系 |
| 实现提示 | 落后计数可依据 connection_audit（全局侧变更时间 > 快照最后同步时间） |

## 2. 环境策略 5+1（待评审 #B）

> 用户明确：**敏感列脱敏不做**（成本 / 边界）。最终为 5 类主策略 + 1 类增强。

| # | 策略 | 取值 | 性质 |
| --- | --- | --- | --- |
| ① | 访问级别 | 只读 / 读写 | 防御 |
| ② | 查询行数上限 | 数字（0=无限制） | 防御 |
| ③ | 查询超时 | 秒 | 防御 |
| ④ | DDL 操作 | 阻断 / 允许 | 防御 |
| ⑤ | 数据导出 | 阻断 / 允许 | 防御 |
| ⑥ | 查询留痕 | 强制记录 / 仅本地 | **追溯**（对应定位） |

- 落库：`environment_policies`（环境默认值）；连接级覆盖走 `advanced_options.policy_overrides` 并标记「已覆盖」。
- 表单 UI：环境管理窗右栏策略分组；每行策略 + 取值分段 + 说明。

## 3. 管理窗 UX（待评审 #C）

### 3.1 DBeaver 式 master-detail

三个管理窗（认证 / 网络 / 环境）从「列表 + 子弹窗表单」改为 **左档案列表（可搜索）+ 右即选即编表单**：

| 元素 | 方案 |
| --- | --- |
| 左栏 | 搜索框 + 档案列表（类型徽标 + 名称 + 作用域短码 G/P）+ 底部「＋ 新建」 |
| 右栏 | 选中条目即时显示表单，分组卡片（基本信息 / 凭据 / 目标 / 策略）；保存 / 删除固定表单底部 |
| 删除守卫 | 保留；被引用 → 守卫弹窗列引用方（含项目名），提供强制删除 |

### 3.2 认证管理左栏分类

按认证类型分组显示分类标签：`密码 password / 密钥 ssh_key / 代理密码 proxy_pwd / 令牌 token`。

### 3.3 网络档案：认证二选一 + 测试

| 项 | 方案 |
| --- | --- |
| 认证方式 | segmented「引用配置 / 手动输入」二选一：引用（复用、一处改全量生效）或本档案内直接输入用户名/密码（独立保存，同样 AES 加密） |
| 测试（单跳） | 「🔌 测试隧道」：成功显示连通 / 本地转发端口 / 耗时；失败显示具体原因（含引用认证的密钥路径检查） |
| 测试（chain） | 「🔌 测试整条链」：逐跳探测，失败定位到具体跳（后续跳标记「未到达 · 链在此中断」）；与 tunnel 守卫语义一致（结束即释放） |

### 3.4 chain 拓扑显示

- 主对话框网络 Tab：恢复拓扑链「本机客户端 → 跳板 → 目标库 · TLS」（v1 形态，决策 #72 撤内联协议链后以档案形态回归展示）。
- 网络管理窗 chain 条目：拓扑图 + 下方可编辑跳板序列（增删跳）。
