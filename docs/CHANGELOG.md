# 变更记录（CHANGELOG）

> 本文件是**按版本的变更索引**：一条一句话，写「用户能感觉到什么」。
> 逐项取证、设计理由与有意差异在 `docs/architecture/`；对外发布正文在 `docs/release/notes/<标签名>.md`。
> 更早版本只留标签，正文见 GitHub Release 页。

## 0.2.13 · 2026-11-25

> 相对 `RDS-beta-0.2.12` 的 213 个提交。主线：全仓界面英文覆盖、数据对象面板重做、结果集面板继续对齐 DBeaver（矩形选区与 D10–D14 各批）。
> 同期并入面板工具栏统一、项目中心退役、Notebook 内核输入行、主题键扩到 143。

### 界面语言

- 外观设置切语言立即生效：工作台壳层、设置、编辑器、结果集、洞察、分析资源库、数据库导航、草稿箱、项目、通知、Mock 全部跟随；组件库内置文案（确认 / 取消 / 占位 / 分页等）也跟随，此前恒为英文。
- 词表 1089 → 1661 条（zh / en 键集一致，差集 0）。
- 枚举显示名与缓存的画像标签走 `tr_dyn`，不再冻结在首次访问时。

### 数据对象面板

- 三段固定：源 / 表 / 文件；未登记库表可就地「登记为资产」（不搬数据）。
- 源段三级树：别名 → schema → 表 / 视图；叶子行带 SQL 引用名与「查」入口。
- 行上按钮全部收进右键菜单：洞察、作为 Mock 结构来源、导出、属性、版本（用 vN 分析）、卸载 / 重新挂载。
- 源行叶子按页画（一页 200 张），列举挪到后台线程，大库不再顶住界面。
- 工作集按文档记忆并落盘；面板不再每帧整表克隆。
- 新出口：归档到分析库、载入内存、存为快照（文件侧）、单行清理。
- 网络连接按加速会话判「挂没挂」，未挂的连接不给展开指示。

### 结果集面板

- 矩形选区：正文拖拽选矩形、可从任意格起拖、行号槽按下整行、列头按下整列、左上交角点击全选；「已选 N 格」按矩形规模。
- 键位：方向键与 `Home` / `End` 只挪焦点格不改选区；`PAGE_UP` / `PAGE_DOWN` 整页翻。
- 结果内查找改为覆盖网格的浮层（对齐 DBeaver FindReplaceOverlay），250ms 防抖。
- 对象格单击出非模态信息浮层（文本取来源 SQL 原文、保留血缘行），图标 `file-code`、对象名主题绿。
- 计算页按列分组聚合 + 工具条「−」+ 六项顺序；分组页改内嵌结果集形态。
- 右栏五页对齐 DBeaver，列浏览器页顶外置 filterPanel；页签条双击最大化 + 拖拽重排。
- 工具栏收口、结果标签右键菜单补齐。
- 修掉筛选 SQL 预览按字节切片 panic。

### 编辑器与 Notebook

- 内核 stdin 输入行：等输入时出输入框，回车提交并清空；`getpass()` 按 `password` 标志遮挡。
- Windows 上 ipykernel 不支持控制通道中断 → 关闭内核兜底；删除等待输入的单元会撤等待态并中断。
- 撤销等待态时清空输入值，避免上一条请求的值（含密码）漏进下一条。
- 事件泵由 60ms 轮询改为事件唤醒。

### 项目与工作台

- 项目中心退役，并入全局设置「项目」页；补真正的切换语义（有项目时也能新建 / 打开）。
- 版本台账行内删除（两段式确认），设置概览显示归档状态；写动作统一走 toast。
- 资产身份改用 `resource_id`。
- 标签页：状态槽入内、脏点唯一化、关闭前询问、侧栏可关、文件类型图标。
- 版本信息弹窗补到 14 项。

### 主题与面板骨架

- 面板工具栏统一容器 `PanelToolbar`，11 处面板迁入；底色 / 下界取 `toolbar.background` / `border.variant`。
- 主题键 141 → 143；等宽字体族改走 `theme.mono_font_family`。

### 依赖与构建

- vendor 私有 patch 第二轮瘦身：删零调用的 `add_cursor_above_line`，登记 `request_close` / `prefix` 内嵌 / `title_suffix` 去重三处。

## 0.2.12 · 2026-11-23

> 相对 `RDS-beta-0.2.11` 的 112 个提交。主线：结果集面板对齐 DBeaver 结果集视图（本版推进到第 83 批）。
> 同期并入数据对象面板 P0 三条、gpui-kit 0.10.0 升级、通知中心重做、SQL 排版引擎换 lax-sql、内核事件归属修复。

### 数据对象面板

- 新增「源库表」段：已连接的库不用先挂载，展开连接就按 catalog → schema 列出表与视图，叶子行带所在 `catalog.schema` 与「选用」按钮。
- 工作集回到多选：同键再点即移除、按加入先后保序；超过 8 个提示首次取样会变慢，但不拦。
- 清单自己跟上现实：结果集、洞察样本、挂载文件、连接状态、资产与项目切换后 1 秒内自动重取。

### 结果集面板 · 筛选与工具栏

- 筛选存档可落盘：同一会话内切换结果集不再丢筛选。
- 筛选条列序对齐 DBeaver（历史下拉前移、组间加分隔线）。
- 右键「显示过滤器面板」接入；`ALT+SHIFT+F` 直接打开筛选设置浮层。
- 列头菜单补「复制列名」。

### 结果集面板 · 右键菜单

- 补齐 layout / filters / edit 三段，段序按 DBeaver 的 `fillContextMenu` 归一。
- 新增「在结果中查找…」「从上一行复制」「从下一行复制」「修改单元格」「重置单元格」。
- 灰项能力：行级按钮按行状态判可用态，「修改」钮按当前格所在行的删除态置灰。
- 记录视图里「修改」钮不再静默无响应（已置灰）。

### 结果集面板 · 键位（31 条，总表见 `docs/architecture/editor/result-panel.md` §0.1）

- 编辑：`ENTER` 进入内联编辑、`` CTRL+` `` 网格⇄文本双向切换、`CTRL+S` 提交待提交变更、`CTRL+R` 撤销全部未提交变更。
- 行级：`ALT+INSERT` 新增行、`CTRL+ALT+INSERT` 复制当前行、`ALT+DELETE` 删除当前行、`CTRL+D` / `CTRL+ALT+D` 从上一行 / 下一行复制值。
- 取数：`CTRL+ALT+N` 取下段、`CTRL+SHIFT+=` 取全部（先弹确认）、`CTRL+G` 行号跳转、`CTRL+SHIFT+G` 按名 / 按序号跳列。
- 选择：`CTRL+ALT+C` 选中当前列、`CTRL+ALT+R` 选中当前行。
- 列：`ALT+SHIFT+H` 隐藏当前列、`ALT+SHIFT+T` 显示全部隐藏列、`ALT+SHIFT+C` 复制列名。
- 面板：`CTRL+ALT+SHIFT+T` 在筛选框与结果呈现之间双向切焦点、`F7` / `CTRL+7` 右栏整组开关、`CTRL+ALT+F2..F6` 右栏单页开关（值详情 / 引用 / 列浏览器 / 分组 / 计算）。
- `ESC` 收起结果集内四个浮层（筛选设置 / 跳列 / SQL 预览 / 取全部确认）；网格自身 `ESC` 仍是「先清选区」。

### 结果集面板 · 视觉与状态

- 斑马线定案 A（跟随主题）+ 行号槽可「复制行号」。
- 状态行补选中统计三项。
- 状态栏「修改单元格」钮接线，并按记录视图 / 无当前属性置灰。
- 「获取全部数据」改成真循环（此前名字与行为不符），并与导出互斥矩阵闭合。

### 编辑器与内核

- Jupyter 内核事件携带执行归属 `msg_id`，杜绝跨单元串台。
- 内核事件收口规则下沉为纯函数（`orchestrate`），事件路径可单测。

### 项目与工作台

- 新建项目对话框：字段级行内校验 + 记住上次新建位置。
- 构建期版本标识 + 「关于」弹窗（宿主注入构建标识）。

### 通知中心

- 重做：相对时间、节流落盘、替换式合并、单条已读。

### SQL

- 排版引擎换 lax-sql 0.3.0，设置项 12 项，真实语料对拍零非幂等。

### 依赖与构建

- gpui-kit 0.10.0 + gpui-fast 0.1.17 + gpui-pre 0.3.12 + sqlglot 0.11.2 + rustls-webpki 0.103.17（vendor 私有 patch 三方合并重打，8 处冲突已解）。
- 主题键表 140 → 141（新增 `list.highlight.foreground`）。
- 帧语义随 0.1.17 变化：断言渲染结果前必须 `window.refresh()`。

### 文档

- `result-panel.md` 重组：新增 §0 速查（键位总表 / 右栏六页 / 功能域导航 / 结构性缺口）、§20 有意差异汇总、§21 遗留汇总；正文编号保持不动。
- `result-panel-handoff.md` 前置 §0 速查（三份权威源 / 锁定状态 / 六节导航 / 引用口径），文件地图校正为 43 个源文件。
- 引用体检：正文 611 处交叉引用逐条与标题编号对表，修正 1 处自指错号（§9.44.5 → §9.44.3）。

### 已知问题（本版没做的）

- 右栏六页没有 `FocusHandle`：`CTRL+SHIFT+F2..F6`（只激活不切焦点）、`CTRL+SHIFT+7`、「打开单页把焦点交给该页」三项仍未接。
- 面板可见性与结果集偏好未跨会话落盘（要动 `crates/settings`，该 crate 在并行线手上）。
- zoom（`ALT+0` / `ALT+9`）与配色 / 密度 / 间距 / 字号属目视类，本版未统一处理。
- 上游键位仍未接：`SHIFT+F11`、`F11` / `CTRL+F11`、`ALT+SHIFT+ARROW`（移列）、`TAB`、`CTRL+BACKSPACE`、`ALT+SPACE`、`CTRL+SHIFT+1`、`CTRL+2`、`SHIFT+ENTER`；`ESC`（`cell.reset`）结构性不可行（组件 `DataTable` 自带 `escape → Cancel`）。
- 模型层缺口：外部值编辑器与写回通道、`SET_NULL` / `SET_DEFAULT`、列级只读模型、列级筛选约束、多区域选区、结果集整体 undo 栈、取全部的取消 / 超时兜底。
