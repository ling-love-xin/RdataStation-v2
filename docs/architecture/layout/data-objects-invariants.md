# 数据对象模块铁律

**本文是「数据对象」模块规则的唯一出处。** 代码行为与本文不一致时，先改本文、再改代码；
不允许代码在无记载的情况下偏离。变更走文末「变更记录」。

适用范围：`crates/workbench/src/panels/data_objects_tab.rs`、
`crates/workbench/src/components/data_objects/`、`crates/workbench/src/components/data_objects_load.rs`
（面板本体与加源），以及为它提供对象的三处数据源：分析库表（`crates/analytics_resource`）、
结果集临时表（`crates/engine` / `crates/editor`）、文件（`crates/engine::duckdb::file_view`）。

---

## A. 定位

1. **唯一职责**：挑分析对象，交给下游用（SQL 编辑器 / 洞察 / mock / 导出）。它不是资产库的第二个入口。
2. **可选中即可查**：凡出现在面板里的对象，都必须能在 SQL 编辑器里直接查到。每行带「执行通道 + 实际引用名」，
   不靠用户猜怎么写 SQL。
3. **只有三类对象**：源 / 表 / 文件。**分组与对象类别一一对应**：清单只有三段，
   业务身份（资产 / 未登记 / 结果集 / 全局 / 自建 / 联邦 / 加速 / 文件库）一律是行内小标，
   不再单独成段。不设第四类，也不加「其他资产（不可分析）」段。

| 对象 | 执行通道 | SQL 里的引用名 |
|---|---|---|
| 临时表 `tmp_q_*` | 进程单例（表本就在里面） | `tmp_q_xxx` |
| 项目分析库持久表 | 短命会话，项目库作文件源只读挂载，别名 `analytics` | `analytics.main.<表>` |
| 全局分析库表 | 同上，别名 `global` | `global.main.<表>` |
| 源库表 | 源库直连（或加速/联邦挂载后） | 按连接口径 |
| 文件（已归档 / 加源） | 进程单例里的 `f_*` 视图，或文件源挂载 | `f_xxx` |

依据：`engine/src/analysis/channel.rs`（四条执行面）、`analysis/global.rs`（全局库方案 B：短命会话 + 只读挂载）、
`analysis/mount.rs`（别名规则）、`analysis/persistent.rs::list_persistent_tables`（列清单不需要挂载）。

## B. 源

4. 源 = 挂到分析实例上的外部来源（连接、URL、数据库文件）+ **恒有**的全局分析库与项目分析库；
   分组与数据库导航栏同口径。**源段按连接成树**：连接行是树根，展开才列 catalog / schema / 表。
   - **没有挂载的源不可展开**：未挂载 = 没有可列的表，行上只给「挂载」（入口在右键，行内不再摆按钮），
     行首不给展开指示。
   - 源段收的是**已注册成分析源的连接**（`use_duckdb_fed`）；**注册过但这一刻没连上的照样列**，
     行上写「未连接」，不给展开、不给选用（等它连上）。没有注册的连接不进面板——
     那是数据库导航栏的对象，不是分析源；会话级加源在切项目后随之消失。
   - SQLite / `.duckdb` 这类**文件库也归源段**：未挂载给「挂载」，挂上后（catalog 进实例）才展开选表。
     挂没挂只看**本体路径在不在 `loaded_files`**（能连上 ≠ 已 ATTACH）；挂上之后这个路径由连接行代表，
     不再给同一路径单出一行「文件库」（两行同名同源，用户分不清该点哪个）。
5. 加源 = 对分析实例做外部追加。只接三类：库表（标记所属连接）、能直接读的文件（外部 / 草稿）、数据库文件。
6. 加源两档 scope：**项目级**（写进项目配置，重开自动重挂）、**会话级**（只活本次，切项目清）。UI 必须显式让用户选。
   - 库表：两档是同一件事 —— 把所属连接标记成联邦源（`set_use_duckdb_fed` 按项目存，本身就是项目级）。
   - 文件：**会话级 = `f_*` 按需视图**（切项目清）；**项目级 = 归档成 `copy` 快照**（生成资产、跟着项目走、只读带版本）。
     不另造「项目级持久源清单」：源清单是资源模块的职责，再造一份就是两份真相（2026-11-23 拍板）。
7. 凭据只引用既有连接，源配置里不另存；缺扩展（httpfs 等）给「去插件管理」的路，禁止静默失败。

## C. 表

8. 表段 = **库里现有的表**，三种身份同段、靠小标区分：资产当前版本（表型，`资产 vN`）、
   库里有但未登记的表（`未登记`，全局那份写 `未登记 · 全局`）、临时结果集（`结果集`）。
   段内次序：资产 → 未登记 → 结果集（正在用的在上）。
9. 未登记的表**留在表段**，标「未登记」；右键「登记为资产」后小标变 `资产 vN`，不搬行。
   不再单列「未登记」段（2026-11-24 合并：业务身份不是形态）。
10. 「登记为资产」= 给**已存在的表**写一条资产行：不搬数据、不涨内容版本；若这张表已是某资产的当前版本，
    直接定位到那条资产，不造第二条。
11. 「升级为资产」= 写成项目分析库的持久表 + 登记成表型资产，两步不可分（只写表不登记 = 半截状态，禁止）。
    只对临时结果集（`tmp_q_`）开放。
12. 临时表只收结果集 `tmp_q_`；洞察取样 `tmp_i_`、mock 产物**不进面板**（抽取的样，不是全量）。
    临时表**不单独成段**：落在表段，小标「结果集」、状态列写「会话级」（寿命靠状态字，不靠段）。
13. 资产一律只读、带版本；分析只取当前版本。`res_` / `tmp_` / `f_` 只是内部标识，不是显示名。

## D. 文件

14. 进文件分组的门槛只有一个：`structured`（= 能不能被 DuckDB 当表读；唯一来源
    `resource_host::is_structured_payload` → `engine::duckdb::file_reader_function`）。
    csv / parquet / excel / json 进；sql / py / md 等一律不进。
15. 取数模式只有两种，复用归档既有的 `payload_mode`，不造第三种：
    - `copy` = **快照**：读只读副本，随版本冻结，外部怎么改都不影响结果；
    - `reference` = **按需**：读源位置，源变了结果就变。
16. 外部文件默认按需（`f_*` 视图不物化）；想固定就归档成 `copy`。
    「由用户确定」= 归档时选 copy / reference，或对外部文件点「归档为快照」。
17. 快照读的是**当前版本副本**；要用某一历史版本的数据，走文件行上的「用 vN 分析」二级入口，
    不把历史版本平铺进清单。
18. 数据库文件（`.db` / `.duckdb`）归**源**不归文件：以「挂载库」形态出现并展开其中的表
    （`file_view::is_database_file` / `load_database_global`）。
19. 草稿里的结构化文件**可以「加源」直接按需参与分析**（2026-11-18 口径），不强制先归档；归档后自动变快照。

## E. 与其他模块的交互（一律右键）

20. **洞察**：与数据库导航栏同一套取样口径（`SampleSource`），不另起第二套。
21. **mock**：只输出对象结构（schema），产物不进面板。
22. **草稿 / 导出**：同一条导出通道，两个目的地——草稿 = `{项目}/scratchpad/`（项目内可见目录，
    `scratchpad::MODULE_DIR_NAME`），导出 = 系统文件对话框任选路径。两者都不登记资产。
23. **资源**：归档 = 生成资产，是让对象"有身份"的唯一路。
24. 导出格式只收 DuckDB 原生：csv / parquet / json。xlsx 需插件，不做。
25. 写盘类动作（导出 / 保存草稿 / 落库）一律走 worker + 状态栏回执，不在渲染或事件路径上写库。

## F. 生命周期与清场

26. 切项目要清：会话级加源（连接 + 文件视图）、`tmp_q_` 结果集、`project_host` 清场漏掉的 `f_*` 视图。
27. 不清：项目分析库 / 全局分析库里的表、任何资产（含全局资产）、项目级加源。
28. 属于全局的不能被清——全局库里只放资产，没有临时表。

## G. 表达与渲染

29. 显示名不带 `tmp_` / `res_` / `f_` 前缀；但面板必须显示**实际引用名**（`f_*` 会把中文折成下划线），
    否则第 2 条落不了地。
30. 同一张表可能在源段与表段各出现一次，必须用小标区分（源段 `库表`、表段 `资产 vN`），不许靠名字猜。
31. 非结构化资产不得表述为"能力缺失 / 不可分析"，要写清原因：**这类文件不是数据**。
32. 面板多选 = 工作集，只做"勾选下发"，不改变对象本体；软上限 8 只提示不硬拦。
33. 视图纪律照旧：渲染期零 I/O、禁裸色值、禁手搓控件（走 gpui-kit）、改状态后 `window.refresh()`。
