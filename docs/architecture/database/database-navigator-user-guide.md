## 1. 这个面板能做什么

在左侧 Dock「数据源」面板里：

- **组织**数据源：自定义**分组**（可多对多、可排序）、**标签**（多值、可检索）；
- **浏览**数据源：连接下逐级展开 schema → 表 / 视图 / 过程 → 列；
- **连接 / 断开**运行时连接（断开**不删**元数据缓存）；
- **筛选 / 搜索**：按归属域、名称、标签定位；
- 双击对象打开**属性面板**（靠右停靠）。

不在本面板内：连接的**定义与编辑**（弹「新建 / 编辑数据源连接」对话框，属 M3）、分析资产（属 M6 资源分析）。

## 2. 入口

| 入口 | 位置 | 行为 |
| --- | --- | --- |
| 打开面板 | 左活动栏「数据库导航」图标 | 左 Dock 展开为数据源面板 |
| 新建数据源 | 面板头 `＋`（空态也有「新建连接」按钮） | 打开新建数据源对话框 |
| 新建分组 | 面板头 `🗂＋` | 面板内新建分组（默认名「新建分组」，可重命名） |
| 编辑连接 | 连接行 hover 出的 `✎`，或右键「编辑连接…」 | 打开对话框并回读该连接 |
| 聚焦搜索 | `Ctrl+F`（任意位置） | 切到数据源面板 + 展开左 Dock + 聚焦搜索框 |

## 3. 界面导览

```
┌ 左侧 Dock（起步 240px，可拖拽调宽）──────────────┐
│ 数据源              [＋][🗂＋][⟳][断开][⋯]      │  ← 面板头
├ 筛选 ──────────────────────────────────────────┤
│ [🔍 筛选数据源 / 标签…]          [筛选 ▾]       │  ← 搜索（当前：名称 + 标签）
│ [全部] 项目  全局  共享                          │  ← 归属域筛选
├ 树主体（可滚动）───────────────────────────────┤
│ ▾ 核心库              3/5          ⇥            │  ← 分组头：健康度 + 计数 + 全折叠
│     ▾ ▣ 生产 PG                       GP        │  ← 连接行
│       ▾ 📁 analytics                            │
│         ▾ ▦ 表                      23          │
│           ▾ orders                  1.2M       │  ← 选中
│               order_id   PK  bigint             │
│         ▸ 👁 视图 / ƒ 过程 / ≡ 序列             │
│     ▸ ▢ 本地 MySQL                    P         │
│ ▾ 未分组              1/1                        │
│     ▸ ▣ 测试 SQLite                   G         │
├ 底部状态 ──────────────────────────────────────┤
│ 3 已连接 · 2 离线 · 缓存 12 分钟前（不自动删除） │
└─────────────────────────────────────────────────┘
```

> `▣` = 徽标（**彩色**：已连接；形状随数据库类型）；`▢` = 同形状但**灰色**（未连接）。

### 3.1 连接行怎么读

```
[徽标]  名称 …………………………………  [标签 ≤2 +N]  [GP]   [+  ✎  连接/断开]
  ↑      ↑                                ↑        ↑      ↑
色=状态  超长自动省略                      可选      归属域列  hover / 选中才显
形=类型（内叠 2 字母）
```

- **徽标**：**颜色 = 状态**，**形状 = 数据库类型**（内叠 2 字母确认，如 `PG` / `MY`）。
- **归属域列**：`P` 项目 / `G` 全局 / `GP` 共享；右对齐成列，可关闭显示（见 §7）。
- **标签**：默认不显示；开启后最多显示 2 个，超出显示 `+N`（见 §7）。
- **行尾操作**：鼠标悬停或选中该行时才出现（`+` 加标签 / `✎` 编辑 / 连接·断开）；右键菜单始终是完整入口。

### 3.2 状态颜色

| 颜色 | 状态 | 含义 |
| --- | --- | --- |
| 绿 `success` | 已连接 | 运行时可查 |
| 蓝 `info` | 连接中 | 建连 / 预热进行中（呼吸效果） |
| 灰 `muted` | 未连接 | 记录存在，运行时未连 |
| 红 `danger` | 失败 | 最近一次连接失败 |

### 3.3 类型形状

| 类型 | 形状 | 字母 | 类型 | 形状 | 字母 |
| --- | --- | --- | --- | --- | --- |
| PostgreSQL | 数据库堆叠 | `PG` | SQL Server | 服务器 | `MS` |
| MySQL | 圆柱 | `MY` | Oracle | 六边形 | `OR` |
| MariaDB | 圆盘堆 | `MA` | ClickHouse | 柱状图 | `CH` |
| SQLite | 文件 | `SQ` | MongoDB | 叶 | `MG` |
| DuckDB | 层叠 | `DK` | Redis | 花括号 | `RD` |

> 形状用于快速扫视，**字母是权威识别**（灰显时也不依赖颜色）。

### 3.4 分组头

`色条 + 名称 + 健康度（已连接/总数）+ 计数 + 全折叠`。

- 健康度有失败时显示为 `0/1 · 1 失败`（红色）。
- 最右 `⇥` 一键**折叠 / 展开全部**同层分组。

## 4. 典型流程

### 4.1 连接与浏览

1. 单击连接行：**选中**（并展开 / 折叠）。
2. 首次展开会后台加载 schema 树，行上显示加载态；大 schema 每批 200 条，行尾「加载更多」。
3. 双击对象节点：打开**属性面板**（列 / 约束 / 索引 / 外键 / DDL 子 Tab）。
4. 断开：右键 →「断开」，或选中后按住 hover 点「断开」。**缓存保留**，可离线浏览对象树。

### 4.2 新建 / 编辑数据源

- 面板头 `＋` → 打开「新建数据源连接」对话框（与编辑区入口同一条链路）。
- 编辑：连接行 hover 出 `✎`，或右键「编辑连接…」。
- 保存后导航列表自动刷新（无需重启）。

### 4.3 归组（可多对多）

1. 右键连接 →「**分组 / 标签…**」（或行尾 `+`）→ 行内展开组织编辑器。
2. 勾选 / 取消分组（一个连接可属**多个**分组）。
3. 「未分组」是固定分组，收纳不属于任何自定义分组的连接，不可删除。
4. 空分组自动隐藏。

### 4.4 打标签（可多值）

- 同一入口（右键「分组 / 标签…」或 `+`）里的标签输入框，逗号分隔多个标签。
- 标签用于**筛选与搜索**，不占树结构。
- 想让标签显示在连接行上：见 §7。

### 4.5 筛选与搜索

| 方式 | 行为 |
| --- | --- |
| 归属域筛选 | `全部 / 项目 / 全局 / 共享` —— 只按存储域过滤 |
| 搜索框 | 按**名称 + 标签**做大小写不敏感子串匹配；命中自动展开祖先链 |

> **尚未支持**：`scope:` / `type:` / `driver:` / `tag:` 结构化语法与「筛选 ▾」弹层（类型 / 驱动 / 标签组合筛选），规划中。

### 4.6 刷新元数据

| 粒度 | 入口 |
| --- | --- |
| 当前选中连接 | 面板头 `⟳`（未选中连接时不可用） |
| 某个节点（连接 / 表） | 右键 →「刷新元数据」 |
| 全部 | 面板头 `⋯` →「刷新全部元数据」 |

刷新只清内存层并重新拉取；**不删磁盘缓存**。

### 4.7 属性面板

- 打开：双击对象 / 连接，或选中后按 `F4`；也可右键「查看属性」。
- 位置：占据编辑区**右侧**，分隔条可拖拽，**宽度会被记住**。
- 连接属性目前显示：`名称` / `归属域` / `驱动`；表 / 视图显示 `限定名` / `类型` / `列数` / `归属域` 等 + 子实体 Tab。

## 5. 分组与标签的分工（重要）

| | 分组 | 标签 |
| --- | --- | --- |
| 作用 | **结构**：在树上组织 | **筛选**：横切检索 |
| 关系 | 连接 ↔ 分组 **多对多** | 连接 → 标签 **多值** |
| 是否进树 | 是（树一级） | **否** |
| 是否可排序 | 可（组内手动排序优先，未排按名称） | 不需要 |

一句话：**要"放在哪"用分组，要"找得到"用标签。**

## 6. 快捷键

焦点需在数据源面板内（单击连接行会自动聚焦面板）：

| 按键 | 行为 |
| --- | --- |
| `Ctrl+F` | 聚焦导航搜索框（任意位置可用，会自动切到本面板） |
| `↑` / `↓` | 在可见节点间上下移动选中 |
| `→` / `←` | 展开 / 折叠当前节点 |
| `Enter` / `F4` | 打开当前节点的属性面板 |
| `Esc` | 清空搜索（在搜索框内时） |

## 7. 显示开关（面板头 `⋯`）

| 菜单项 | 默认 | 说明 |
| --- | --- | --- |
| 刷新全部元数据 | — | 刷新所有已展开连接的元数据（不删缓存） |
| **显示标签** | 关 | 开启后连接行显示「≤2 个标签 chip + `+N`」 |
| **显示归属域** | 开 | 关闭后连接行不显示 `P/G/GP` 列 |
| 缓存管理… | — | 查看各连接缓存占用，逐条 / 全部清理（**唯一删除缓存的入口**） |

另外，「设置 → 数据源导航」里有：

- **来源标识**：`短码`（`P/G/GP`）⇄ `文字`（项目 / 全局 / 共享）；
- **缓存管理…** 入口。

> 以上开关都写入 `settings.json` 长期生效。

## 8. 常见问题与排查

**Q1：为什么看不到项目里的连接？**
本面板按**归属域**可见性合并：全局连接始终可见；`P_` / `GP_` 连接需**当前项目已打开**。应用启动即绑定当前项目（无"未打开项目"状态）。

**Q2：断开连接后对象树还在？**
是预期行为。**元数据缓存永不自动删除**——断开只关运行时连接，缓存保留，离线也能浏览，重连秒开。要清理请走 `⋯` →「缓存管理…」。

**Q3：为什么连接行显示的是 `mysql_native` 这类内部名字？**
不会。连接行显示的是**类型徽标**（形状 + `PG`/`MY` 等字母）。驱动的完整名称 / id 在**属性面板**与徽标 tooltip 里（tooltip 尚未接入，见下）。

**Q4：我想知道某条连接到底用的是哪个驱动实现？**
见属性面板「驱动」行。目前显示驱动 id（如 `mysql_native`）；显示为友好名（如 `PostgreSQL (Official)`）与类型行是后续项。

**Q5：连接行右边怎么没有按钮？**
行尾操作（`+` / `✎` / 连接·断开）**悬停或选中该行才出现**，以降低视觉密度。右键菜单任何时候都是完整入口。

**Q6：搜索为什么搜不到"PostgreSQL"或某个驱动？**
当前搜索只匹配**名称 + 标签**。`type:` / `driver:` 结构化语法与 facet 弹层在规划中。

**Q7：同一个连接在多个分组里重复出现？**
当前行为：「连接可属多个分组」会在每个分组各出现一次。**"主组全亮 + 其它组引用样式"**（避免重复撑高树）在规划中。

**Q8：某个节点一直加载失败？**
该节点会标记错误并可重试（右键「刷新元数据」）。常见原因：网络不可达、账号权限不足、库/表已被删除。

## 9. 验收清单（可勾选）

**读取与呈现**
- [ ] 面板头五个入口齐全：`＋` / `🗂＋` / `⟳` / `断开` / `⋯`
- [ ] 归属域筛选 `全部 / 项目 / 全局 / 共享` 能正确过滤（且行内短码列随之变化）
- [ ] 连接行 = 徽标 + 名称 + 归属域列；**没有**驱动 id 文本、**没有**行内 🗂
- [ ] 徽标为**双通道**：颜色反映状态、形状反映类型（含 `PG`/`MY`/`SQ`/`DK` 等字母）
- [ ] 长名称自动省略，不挤压右侧元素
- [ ] 归属域列**右对齐成列**（多行对齐一致）
- [ ] 分组头显示**健康度**（已连接/总数）与计数，`⇥` 可一键折叠全部

**交互**
- [ ] 单击连接行：选中 + 聚焦面板；再次单击展开 / 折叠
- [ ] 双击连接：打开属性面板；双击对象：打开属性面板
- [ ] 悬停 / 选中连接行：右侧浮出 `+` / `✎` / 连接·断开；移开消失
- [ ] 右键连接：「连接/断开 · 编辑连接… · 查看属性 · 分组 / 标签… · 复制名称 · 刷新元数据」
- [ ] 右键分组：重命名 / 新建 / 删除（未分组仅「新建分组」）；删除带二次确认
- [ ] `+` 与右键「分组 / 标签…」都能打开行内组织编辑器

**显示开关**
- [ ] `⋯ → 显示标签`：开启后行内出现标签 chip（≤2 + `+N`）；重启后保持
- [ ] `⋯ → 显示归属域`：关闭后 `P/G/GP` 列消失；重启后保持
- [ ] 设置 → 数据源导航 → 来源标识：短码 ⇄ 文字即时切换

**缓存与连接**
- [ ] 断开连接后对象树仍可浏览（缓存保留）
- [ ] `⋯ → 缓存管理…` 可查看占用并逐条 / 全部清理
- [ ] 连通性：真实端点连接后状态徽标转为**绿色**

**键盘**
- [ ] `Ctrl+F` 聚焦搜索；`↑↓` 移动；`→←` 展开 / 折叠；`Enter` / `F4` 打开属性

**原型一致性**
- [ ] 与 `database-navigator-prototype.html` 对照：徽标双通道、归属域列、分组头健康度、before/after 密度对比
