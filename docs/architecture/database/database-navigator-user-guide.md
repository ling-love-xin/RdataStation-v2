## 1. 这个面板能做什么

在左侧 Dock「数据源」面板里：

- **组织**数据源：自定义**分组**（可多对多、可排序）、**标签**（多值、可检索）；
- **浏览**数据源：连接下逐级展开对象树——层级**随数据库类型**变化（详见 §3.5），最终到表 / 视图 / 过程 → 列；
- **连接 / 断开**运行时连接（断开**不删**元数据缓存）；
- **筛选 / 搜索**：按归属域、类型 / 驱动 / 标签（facet）、名称、标签定位；
- 双击对象打开**属性面板**（靠右停靠）。

不在本面板内：连接的**定义与编辑**（弹「新建 / 编辑数据源连接」对话框，属 M3）、分析资产（属 M6 资源分析）。

```
┌ 左侧 Dock（起步 240px，可拖拽调宽）──────────────┐
│ 数据源              [＋][🗂＋][⟳][断开][⋯]      │  ← 面板头
├ 筛选 ────────────────────────────────────────┤
│ [🔍 筛选数据源 / 标签…]        [筛选 ▾ 2]     │  ← 搜索（名称 + 标签 + facet token）+ facet 弹层
│ [全部] 项目  全局  共享                          │  ← 归属域筛选
├ 树主体（可滚动）───────────────────────────────┤
│ ▾ 核心库              3/5          ⇥            │  ← 分组头：健康度 + 计数 + 全折叠
│     ▾ ▣ 生产 PG                       GP        │  ← 连接行
│       ▾ 📁 analytics                            │
│         ▾ ▦ 表                      23          │
│           ▾ orders                  1.2M       │  ← 选中
│               order_id   PK  bigint             │
│         ▸ 👁 视图 / ƒ 过程 / ≡ 序列             │
│     ▸ ▢ 本地 MySQL                    P         │
│ ▾ 未分组              1/1                        │
│     ▸ ▣ 测试 SQLite                   G         │
├ 底部状态 ──────────────────────────────────────┤
│ 3 已连接 · 2 离线 · 缓存 12 分钟前（不自动删除） │
└─────────────────────────────────────────────────┘
```

> `▣` = 徽标（**彩色**：已连接；形状随数据库类型）；`▢` = 同形状但**灰色**（未连接）。

### 3.1 连接行怎么读

```
[徽标]  名称 …………………………………  [GP]   [+  ✎]
  ↑      ↑                             ↑      ↑
色=状态  超长自动省略                   归属域列  hover / 选中才显
形=类型（内叠 2 字母）
        [标签 ≤2 +N]   ← 可选，显示在名称下一行
```

- **徽标**：**颜色 = 状态**，**形状 = 数据库类型**（内叠 2 字母确认，如 `PG` / `MY`）。
- **归属域列**：`P` 项目 / `G` 全局 / `GP` 共享；右对齐成列，可关闭显示（见 §7）。
- **标签**：默认不显示；开启后显示在**名称下一行**，最多 2 个，超出显示 `+N`（见 §7）。
- **行尾操作**：鼠标悬停或选中该行时才出现，只有 `+`（加标签）与 `✎`（编辑）；**连接 / 断开只在右键菜单**，不占行内。

### 3.2 状态颜色

| 颜色 | 状态 | 含义 |
| --- | --- | --- |
| 绿 `success` | 已连接 | 运行时可查 |
| 蓝 `info` | 连接中 | 建连 / 预热进行中（呼吸效果） |
| 灰 `muted` | 未连接 | 记录存在，运行时未连 |
| 红 `danger` | 失败 | 最近一次连接失败 |

### 3.3 类型形状

| 类型 | 形状 | 字母 | 类型 | 形状 | 字母 |
| --- | --- | --- | --- | --- | --- |
| PostgreSQL | 数据库堆叠 | `PG` | SQL Server | 服务器 | `MS` |
| MySQL | 圆柱 | `MY` | Oracle | 六边形 | `OR` |
| MariaDB | 圆盘堆 | `MA` | ClickHouse | 柱状图 | `CH` |
| SQLite | 文件 | `SQ` | MongoDB | 叶 | `MG` |
| DuckDB | 层叠 | `DK` | Redis | 花括号 | `RD` |

> 形状用于快速扫视，**字母是权威识别**（灰显时也不依赖颜色）。

### 3.4 分组头

`色条 + 名称 + 健康度（已连接/总数）+ 计数 + 全折叠`。

- 健康度有失败时显示为 `0/1 · 1 失败`（红色）。
- 最右 `⇥` 一键**折叠 / 展开全部**同层分组。

### 3.5 对象树层级（随数据库类型变化）

数据库类型不同，层的名字与数量也不同，导航树按实际能力渲染：

| 数据库 | 层级（自连接向下） |
| --- | --- |
| MySQL | `数据库（database）→ 表 / 视图 / 存储过程 → 列` |
| PostgreSQL | `数据库 → Schema（如 public）→ 表 / 视图 / 存储过程 → 列` |
| SQLite | `main → 表 / 视图 / 存储过程 → 列` |
| DuckDB | `main → 表 / 视图 / 存储过程 → 列` |

- **为什么 MySQL 没有 Schema 层**：MySQL 的 `database` 就是 `schema`，若再加一层会出现与数据库同名的重复节点；因此直接以数据库为容器。
- **只显示有对象的类别**：某层下若无视图 / 存储过程 / 序列 / 触发器，则对应文件夹不出现（标题带数量）。例程可双击看**源码**（属性面板「源码」分区）；**序列 / 触发器目前仅 PostgreSQL 有内省**（MySQL / SQLite / DuckDB 暂不提供）。
- **系统库暂不过滤**：`information_schema` / `mysql` / `sys`、`pg_toast` 等会照常列出，自定义显示数据库 / Schema 在后续版本提供。
- **PostgreSQL 只列当前库**：一条 PG 连接只绑定一个数据库，`information_schema` 仅暴露**当前库**的 schema / 表。因此连接下只显示当前数据库（不再列出无法展开的兄弟库）。跨库浏览（DBeaver 式：展开时另开一条连接）留待后续。

## 4. 典型流程

### 4.1 连接与浏览

1. 单击连接行：**选中**（并展开 / 折叠）。
2. **首次展开会自动建连**（未连接时先连再加载）；schema 树在后台加载，行上显示加载态；大 schema 每批 200 条，行尾「加载更多」。
3. 双击对象节点：打开**属性面板**（属性网格 + 列 / 索引 / 约束分区，堆叠呈现；暂无子 Tab）。
4. 断开：右键 →「断开」（行内不提供连接 / 断开按钮）。**缓存保留**，可离线浏览对象树。

### 4.2 新建 / 编辑数据源

- 面板头 `＋` → 打开「新建数据源连接」对话框（与编辑区入口同一条链路）。
- 编辑：连接行 hover 出 `✎`，或右键「编辑连接…」。
- 保存后导航列表自动刷新（无需重启）。

### 4.3 归组（可多对多）

1. 右键连接 →「**移动到分组…**」→ 行内展开归组编辑器（多选切换 + 新建分组）。
2. 勾选 / 取消分组（一个连接可属**多个**分组）。
3. 「未分组」是固定分组，收纳不属于任何自定义分组的连接，不可删除。
4. 空分组自动隐藏。

**主组**：一个连接属多组时，只在**主组**全亮呈现，其它组显为 `∈ 主组名` 引用行（点击跳回主组）。

- 指定：右键连接 →「**设为主组 ▸**」→ 选一个分组（仅在该连接已归组时出现）。
- 回退：选「**自动（按分组排序）**」或不指定时，取排序最前的那个分组。

### 4.4 打标签（可多值）

- 行尾 `+` → 行内**标签**编辑器（只做标签），逗号分隔多个标签。
- 标签用于**筛选与搜索**，不占树结构。
- 想让标签显示在连接行上：见 §7。

### 4.5 筛选与搜索

| 方式 | 行为 |
| --- | --- |
| 归属域筛选 | `全部 / 项目 / 全局 / 共享` —— 只按存储域过滤 |
| **筛选 ▾ N** | 面板头下方搜索框右侧；展开后含**类型 / 驱动 / 标签**三个子菜单（单选）；`N` = 已生效的附加筛选项数；首项「清除筛选」一键清空（含归属域） |
| 搜索框 | 按**名称 + 标签**做大小写不敏感子串匹配；命中自动展开祖先链 |
| 搜索 facet 语法 | `scope:global` / `source:p` / `type:postgres` / `driver:postgres_native` / `tag:prod` —— 作为**额外约束叠加**到 facet 与搜索上（AND）；未识别的 token 当普通文字处理 |

> facet（归属域 + 类型 / 驱动 / 标签）会**记住**（存 `settings.json`，跨项目），下次打开仍生效；用「清除筛选」重置。

### 4.6 刷新元数据

| 粒度 | 入口 |
| --- | --- |
| 当前选中连接 | 面板头 `⟳`（未选中连接时不可用） |
| 某个节点（连接 / 表） | 右键 →「刷新元数据」 |
| 全部 | 面板头 `⋯` →「刷新全部元数据」 |

刷新只清内存层并重新拉取；**不删磁盘缓存**。

### 4.7 属性面板

- 打开：双击对象 / 连接，或选中后按 `F4`；也可右键「查看属性」。
- 位置：占据编辑区**右侧**，分隔条可拖拽，**宽度会被记住**。
- 覆盖对象：连接 / Catalog / Schema / 表 / 视图 / 列 / 例程 / 序列 / 触发器。
- 内容：上部**属性网格**（键值行，如 `名称` / `归属域` / `驱动` / `限定名` / `类型`），下部**子实体分区**——表的 `列 (n)` / `索引 (n)` / `约束 (n)`、例程的 `源码`；**堆叠呈现、仅非空时显示**。
- 目前**没有子 Tab 切换**；表 / 视图仍无 DDL 与独立外键分区（后续再做）。

### 4.8 模块入口（右键，通用项）

右键菜单**底部固定两项**，**所有节点都有**（连接 / 数据库 / Schema / 文件夹 / 表 / 视图 / 列 / 例程…），与节点类型、连接状态无关：

| 菜单项 | 行为 |
| --- | --- |
| **在 SQL 编辑器中打开** | 把该节点所属连接设为编辑区当前连接（清空导航树 / 结果残留），并聚焦中央编辑区 |
| **查看洞察** | 展开右 Dock 并切到「洞察」面板 |

**表 / 视图**额外多一项（夹在两者之间）：

| 菜单项 | 行为 |
| --- | --- |
| **生成 Mock 数据** | 展开右 Dock 并切到「Mock 生成」面板 |

> 说明：Mock / 洞察面板目前为占位（M7 / M8 待实现）；SQL 编辑区当前仅在连接启用 DuckDB 联邦（`use_duckdb_fed`）时显示可执行区域。

### 4.9 测试连接与生成 SQL

**测试连接**（连接右键）：与对话框「测试连接」**同源**（同一套凭据注入 / 隧道 / 驱动属性规则），但是**独立会话**——建连探测后立即释放，不注册连接池、不写库。结果以面板提示给出（成功含版本与耗时）。

**生成 SQL**（表 / 视图右键 →「生成 SQL ▸」）：生成 `INSERT` / `UPDATE` / `DELETE` 模板，**注入编辑区但不自动执行**。

- 列信息由后台任务取（命中 L2 则不发查询）；
- 值统一为 `NULL` 占位，标识符不加引号（跨方言中性），由你自行替换 / 引号化；
- `UPDATE` / `DELETE` 的 `WHERE` 取主键；**无主键时退化为 `WHERE 1 = 0`** 并附注释提醒（避免误伤全表）；
- 复合主键用 `AND` 串联。

### 4.10 复制 / 共享 / 删除连接

| 动作 | 入口 | 行为 |
| --- | --- | --- |
| **复制为模板** | 连接右键 →「复制连接（模板）…」 | 行内输入新名（默认「原名 副本」）→ 回车提交。拷贝配置与档案引用，**不带密码**；同名（全局或当前项目任一可见）会被拦下。共享连接（`GP`）本身即副本，不提供该项 |
| **共享至项目** | 连接右键（仅 `G`） | 在当前项目创建 `GP` 快照（独立副本，**含凭据密文**）；已共享会提示。后续全局侧变更需显式同步 |
| **取消共享** | 连接右键（仅 `GP`） | 删除项目侧快照，**全局定义保留** |
| **删除连接** | 连接右键 →「删除连接」 | 二次确认后物理删除；**元数据缓存保留**（可在「缓存管理」清理），运行时连接一并断开 |

### 4.11 拖拽表 / 视图到编辑器

把树里的**表 / 视图**行拖到中央编辑区，即可把它的**限定名**送进 SQL 草稿（不需要先右键复制再粘贴）。

| 拖到哪里 | 结果 |
| --- | --- |
| **SQL 区**（虚线描边容器，拖入时高亮） | 插到**光标处**；若你选中了一段文本，则替换该选区 |
| **编辑区其它位置** | 追加到草稿末尾（兜底，拖到哪儿都不会“没反应”） |

两者都会**把焦点交给 SQL 区**，方便接着写；插入的文本带一个尾随空格，连续拖多个表不会粘成一个标识符。

拖拽时鼠标旁边跟一个小幽灵：类型色点 + **表名**（与树里刚抓住的那一行一致）。

> 两个注意点（都是当前已知限制，不是 bug）：
> 1. SQL 区目前**只在启用 DuckDB 联邦的连接下显示**。其它连接拖进去仍会写入草稿，但你看不到它——此时面板会出一条通知告诉你“已送入 SQL 草稿”。
> 2. 插到**光标处**只在 SQL 区**已聚焦**时生效。没点过 SQL 区时光标停在 0，直接插入会把表名顶到你已有语句的前面，所以这种情况一律改为**追加到末尾**。

## 5. 分组与标签的分工（重要）

| | 分组 | 标签 |
| --- | --- | --- |
| 作用 | **结构**：在树上组织 | **筛选**：横切检索 |
| 关系 | 连接 ↔ 分组 **多对多** | 连接 → 标签 **多值** |
| 是否进树 | 是（树一级） | **否** |
| 是否可排序 | 可（组内手动排序优先，未排按名称） | 不需要 |
| 多组归属 | 可多组（**一个主组全亮 + 其它组引用行**） | 不适用 |

一句话：**要"放在哪"用分组，要"找得到"用标签。**

## 7. 显示开关（面板头 `⋯`）

| 菜单项 | 默认 | 说明 |
| --- | --- | --- |
| 刷新全部元数据 | — | 刷新所有已展开连接的元数据（不删缓存） |
| **显示标签** | 关 | 开启后在**名称下一行**显示「≤2 个标签 chip + `+N`」 |

- **来源标识**：`短码`（`P/G/GP`）⇄ `文字`（项目 / 全局 / 共享）；
- **缓存管理…** 入口。

- **建连超时**：`5s / 15s / 30s / 60s`（超时自动重试一次）；

> 以上开关都写入 `settings.json` 长期生效。

## 8. 常见问题与排查

**Q1：为什么看不到项目里的连接？**
本面板按**归属域**可见性合并：全局连接始终可见；`P_` / `GP_` 连接需**当前项目已打开**。应用启动即绑定当前项目（无"未打开项目"状态）。

**Q2：断开连接后对象树还在？**
是预期行为。**元数据缓存永不自动删除**——断开只关运行时连接，缓存保留，离线也能浏览，重连秒开。要清理请走 `⋯` →「缓存管理…」。

**Q3：为什么连接行显示的是 `mysql_native` 这类内部名字？**
不会。连接行显示的是**类型徽标**（形状 + `PG`/`MY` 等字母）。驱动的完整名称 / id 在**属性面板**与徽标 **hover 卡**（悬停 300ms）里。

**Q4：我想知道某条连接到底用的是哪个驱动实现？**
见属性面板「驱动」行（显示友好名 + id，如 `PostgreSQL (Official) · postgres_native`）与「数据库类型」行。

**Q5：连接行右边怎么没有按钮？**
行尾操作（`+` / `✎` / 连接·断开）**悬停或选中该行才出现**，以降低视觉密度。右键菜单任何时候都是完整入口。

**Q6：搜索为什么搜不到「PostgreSQL」或某个驱动？**
搜索默认只匹配**名称 + 标签**（自由文本）；要按类型 / 驱动 / 归属域筛选，用搜索框右侧的 **「筛选 ▾」** 弹层，或输入结构化 token（如 `type:postgres` / `driver:postgres_native`）。

**Q7：同一个连接在多个分组里重复出现？**
不会。连接只在**主组**（分组排序最前的那个）全亮呈现；其它所属分组里显示为**引用行**（淡色名称 + `∈ 主组名`，点击跳回主组）。

**Q8：某个节点一直加载失败？**
该节点会标记错误并可重试（右键「刷新元数据」）。常见原因：网络不可达、账号权限不足、库/表已被删除。

**Q9：点「连接」后状态不对 / 对象树加载不出来？**
先确认不是「LAN 建连慢」：连接超时可在「设置 → 连接默认值 → 建连超时」加大（默认 15s，失败会自动重试一次）。若目标是 LAN / 本机且未配 SSL 档案，可在同一处选「关 TLS」（默认）以规避 sqlx 默认 TLS 握手卡顿；公网 / 需要 TLS 的库请选「保留 TLS」。

**Q10：重启后原本展开的连接下出现「未连接 · 右键「连接」或再次展开」，或以前报 `CONN_NOT_FOUND`？**
展开态会记住（跨重启），**运行时连接不会**。所以重启后展开的连接默认不加载，只给提示；**右键「连接」或再次点展开（自动建连）** 即可加载。以前直接报 `CONN_NOT_FOUND` 属于老版本行为，现已改为提示。
