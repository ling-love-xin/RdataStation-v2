方案 A + v6：归属域是事实，不是分区

  • 去掉「项目 / 全局」标签页；归属域降级为筛选 facet + 条件行内短码
  • 命名：「来源 / 作用域」统一改称归属域（避免与「分组」中文语感混淆）
  • 一级结构位让给自定义分组（用户意图），归属域只作事实属性
  • 搜索补充 scope:global / source:p / type:postgres / driver:postgres_native / tag:prod（与面板 facet 叠加 AND）
  • 「筛选 ▾」弹层：类型 / 驱动 / 标签每节单选，可叠加；N = 已生效附加项数，可「清除筛选」
P项目连接 G全局连接 GP项目共享（全局快照）

分组（结构）与标签（检索）

  • 路线 1 分工：分组 = 结构（树一级，手工维护、可排序）；标签 = 筛选（扁平多值，永不进树）
  • 分组多对多；同一连接只在一个主组全亮，其它组以 ∈ 主组 引用行出现（右键 设为主组 ▸ 单选，支持「自动」回退）
  • 分组头 = 色条 + 名称 + 健康度（已连接/总数） + 计数 + 全折叠
  • 「未分组」固定；支持手动排序（顺序落 navigator_ungrouped_order）
  • 归组入口：右键「移动到分组…」或把连接行拖到分组头；标签另可用行尾 + 快捷编辑（v7，hover 显）
  • 排序：把连接行拖到同容器内另一行 = 插到该行之前（整容器重写 0..n）；Alt+↑/↓ 同样移一位
  • 分组排序：拖分组头到分组头 = 插到它之前（拖到「未分组」头 = 排到最后）；右键「上移 / 下移分组」
  • 名称 / 描述：右键「编辑分组…」，新建分组同样走表单（避免默认名再改名）
  • 落库：connection_groups + connection_group_members（含 is_primary 主组标记）+ connection_tags + navigator_ungrouped_order

属性面板（靠右停靠）

  • 占用编辑区右侧的编辑面板位（默认约 392px，可拖拽调宽，宽度会被记住）
  • 顶部 Tab：属性 / 数据；属性网格 + 子实体 Tab（列/约束/索引/外键/DDL）
  • 入口：双击对象 / 右键「查看属性」/ F4
  • 事实的唯一权威位：数据库类型 / 驱动（显示名 + id）/ 归属域 / 地址 / 运行状态

缓存策略（永不自动删除）

  • 元数据缓存（L2 SQLite）与状态缓存（分组/展开态）都不删除
  • 断开 / 刷新 / 删除连接均保留缓存，可离线浏览、重连秒开
  • 唯一删除路径：设置内「缓存管理 → 清理」（设置 + 面板头两处入口）
  • 预热采用方案 C（仅 databases/schemas）

范围边界

  • 本面板只管理数据源与其对象树
  • DuckDB 分析表 / 分析资源（M6）不在本面板，归「资源分析」

主题

  • 配色取自 assets/themes/rds-theme.json，代码零裸 hex
  • 新增通用 token search.match.background（与草稿箱共用）
