面板结构

  • 面板头：标题「数据源」+ 新建 / 刷新 / 全部折叠 / 更多
  • 搜索：本地筛选（连接 / 表 / 列），.* 正则、Aa 大小写
  • 树主体：分组 → 连接 → catalog/schema → 类别文件夹 → 表 → 列
  • 底部状态：已连接数 / 离线数 / 缓存新鲜度

连接节点状态与徽标

已连接 未连接（已保存） 连接 / 内省中 连接失败
GP全局 + 项目共享 P仅项目 G仅全局
PGPostgreSQL MYMySQL SQSQLite DUDuckDB

关键交互

  • 单击节点：选中（右侧属性面板联动）
  • 双击表 / 视图：中央编辑区打开只读数据预览
  • 右键：查看数据 / 新建查询 / 复制名 / 生成 SQL / Mock / 刷新
  • 连接节点右键：连接 / 断开 / 编辑 / 复制 / 测试 / 删除
  • 展开状态按连接持久化，重开面板即恢复
