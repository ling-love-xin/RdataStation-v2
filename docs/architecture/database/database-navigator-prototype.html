三个正交概念 + 标签

  • 来源短码：P 项目 / G 全局 / GP 共享
  • 标签页：项目 / 全局，按来源过滤视图
  • 分组：项目级用户自定义，多对多（同一连接可出现在多个分组）
  • 标签：连接上的多值标记，用于检索/过滤
  • 来源短码可切换为文字（设置内开关，偏好存 settings.json）
P项目连接 G全局连接 GP项目共享（全局快照）

分组与标签

  • 分组 = 名称 + 描述 + 成员；多对多，可拖拽归组、组内外排序、折叠计数
  • 连接右键「分组 ▸」多选、「标签 ▸」多值
  • 分组栏简单配色：统一左侧 2px 色条（不做 per-group 自定义色）
  • 「未分组」支持手动排序
  • 落库：connection_groups + connection_group_members + connection_tags（均为独立表）

属性面板（靠右停靠）

  • 占用编辑区右侧的编辑面板位（默认约 392px，可拖拽调宽，宽度会被记住）
  • 顶部 Tab：属性 / 数据；属性网格 + 子实体 Tab（列/约束/索引/外键/触发器/DDL）
  • 入口：双击对象 / 右键「查看属性」/ F4；关闭后回到编辑区 tab

缓存策略（永不自动删除）

  • 元数据缓存（L2 SQLite）与状态缓存（分组/展开态）都不删除
  • 断开 / 刷新 / 删除连接均保留缓存，可离线浏览、重连秒开
  • 唯一删除路径：设置内「缓存管理 → 清理」（可单连接/全量；设置 + 面板头「更多」两处入口）
  • 预热采用方案 C（仅 databases/schemas），不预取表

范围边界

  • 本面板只管理数据源与其对象树
  • DuckDB 分析表 / 分析资源（M6）不在本面板，归「资源分析」
