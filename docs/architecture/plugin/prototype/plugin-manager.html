本稿演示了什么

从 Zed 借来的骨架

  • 单页承载 + 搜索框 + 三档筛选 + 分类 chips
  • 固定操作位的卡片：名称/版本/chips 在三行内闭合
  • 按钮语义按状态分支，而不是一组常驻按钮

RDS 的差异与取舍

  • 驱动轨与界面扩展放进同一张列表；分类用贡献点而非插件类型
  • 右侧详情承载贡献点、权限、项目引用、运行状态四区
  • 左 Dock 保留 240px 快速启停，中央页负责搜索 / 安装 / 详情

刻意没画 / 未实现

  • 插件市场、下载量、评分与远程索引
  • 签名信任链（signature.json）、发布流程
  • 扩展宿主运行时与命令执行的真正接线（P4）
