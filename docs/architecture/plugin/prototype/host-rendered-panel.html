宿主渲染的六个面

  • 设置行：configuration 贡献点（tableBoard.topN，作用域 project）—— 控件是宿主的，值进 settings
  • 列表与占比条：views 贡献点；条是宿主画的，插件只给了 ratio 这个数
  • 面板头「⋯」菜单：宿主菜单 + 插件贡献的「表大小看板设置…」
  • 行右键菜单：宿主自己的项 + 插件项（分组标题 = 插件名，用户永远知道哪条来自插件）
  • 进度与取消：withProgress —— 宿主渲染进度条，取消由宿主把信号发给扩展宿主
  • 空态 / 欢迎 / 占位：未连接时给欢迎内容；被卸载时给「项目引用了它」的占位与两个出路

崩溃隔离的形状

  • 勾「模拟扩展宿主崩溃」：面板变灰 + 横幅 + 自动重启；中央那张表一直能选能滚
  • 插件在另一个进程里，所以它的死法不会带走宿主（D1 买的就是这个）
  • 代价：跨进程往返与激活延迟 —— 所以才有 activationEvents 懒激活
