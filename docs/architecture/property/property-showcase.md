# RdataStation · 属性面板 —— 一页看懂

> 选中导航里的表 / 视图 / 列 / 连接，右侧面板把它的元信息摊开：列、索引、约束、DDL 一张页签一张纸；暂不支持的能力（权限 / 依赖）**先画出来、置灰标注**，不静默消失。
> **DBeaver 式 tab · 描述驱动 · 权限灰置 · 数据全来自实时内省。**
>
> 本页是**可贴版**（适合贴进 PR / wiki）；视觉版见 [`property-showcase.html`](property-showcase.html)（自包含、明暗双主题、离线可开，可在对象间切换看页签联动）；可交互原型见 [`property-prototype.html`](property-prototype.html)。

## 一句话

**双击对象 → 右侧面板 → 一张页签一张纸。**

它不是一个"把字段平铺出来的列表"：页签集合是**注册表数据**（对象类型 → 页集合），渲染只遍历描述；列 / 索引 / 约束 / DDL 各归其位；权限、依赖这类驱动还没实现的能力**先绘制、置灰**——用户能看到"这能力存在，只是暂不可用"。

### 它替你做到的事

| 你关心的 | 它给什么 |
| --- | --- |
| 一张表到底长什么样 | **五张纸**：通用（列数 / 归属域）、列（#/类型/可空/主键/外键/默认值）、索引、约束、DDL——各归其位，不再一锅烩 |
| 视图 / 列 / 连接有什么可看 | 页签随类型伸缩：视图没有索引约束、列只有通用、连接只给基础信息——**页签集合是数据不是分支** |
| 权限 / 依赖现在能用吗 | **灰置占位**：页签可见、可点、内容区明确说明"驱动能力未实现"；驱动补齐能力位后注册表翻为可用，**渲染零改动** |
| DDL 是原文还是重打的 | **能取源就取源**：MySQL / SQLite / DuckDB 直接读数据库保存的原文（`SHOW CREATE` / `sqlite_master.sql` / `duckdb_tables().sql`）；取不到才由列/约束/索引合成，合成版标注来源 |
| 数据可信吗 | **零 UI 造数据**：网格与分区全部来自 `MetadataService` 实时内省，面板侧只有「键 → 显示名」映射 |
| 快速连着点会不会闪 | **过期结果丢弃**：连续打开多个对象，先返回的旧结果按请求 key 丢弃，不会用旧数据覆盖新对象 |

## 1. 三个高光

### ① 描述驱动：页签是数据，不是 match 分支

旧实现是 `match kind` 硬编码分区；新实现是**注册表**（`PropertyRegistry::pages_for(kind)`）——表注册 7 页、视图注册 4 页、列注册 1 页，渲染方不写分支。好处：

- **加能力不加代码**：驱动补内省能力位 → 注册表翻 `Supported` → 页签自动亮起，渲染零改动；
- **灰置是状态不是特例**：权限 / 依赖页先以 `Unsupported` 入册，页面照常绘制、置灰标注；
- **类型扩充只改一处**：将来新增对象类型（如物化视图），注册一张页集合即可。

### ② DBeaver 式 tab：一张纸一件事

面板头部 = 对象名 + 类型；tab 条 = 该类型注册的页集合；内容区 = 当前页。无数据的分区（如表无索引）显示「（无）」，**不摆空表头**——DBeaver 用户零学习成本。

### ③ 能力先绘制、后激活

权限 / 依赖是典型"想看但驱动还没做"的能力。方案不是藏起来，而是：

```
页签绘制（可见） → 置灰（不可用） → 驱动实现能力位 → 翻转为可用（渲染零改动）
```

用户能感知产品路线图，开发能按驱动逐项补齐，界面不做静默降级。

## 3. 真机验证（2026-10-03）

SQLite 与 DuckDB（本地文件库，当前环境不依赖外部端点）全链路验证通过：测试连接 → 真实连接 → 导航加载（Catalog / 文件夹 / 表 / 视图 / 列，含 cache-aside 二次加载）→ 属性面板（表 / 视图 / 列 / 连接）→ 注册表灰置。详情与断言口径见 [`property-test-report-2026-10-03.md`](property-test-report-2026-10-03.md)。

## 4. 它的边界

| 不做的事 | 说明 |
| --- | --- |
| 不编辑元数据 | 属性面板只读；改名 / 建索引 / 授权等操作不在本模块范围 |
| 不替代编辑器 | 表数据浏览 / SQL 编辑走编辑区，属性面板只给「这是什么」 |
| 不预言驱动能力 | 驱动没实现的能力一律灰置，绝不拿目录信息硬凑（如权限清单） |
