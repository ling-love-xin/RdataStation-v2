RdataStation · M4 属性面板

一张页签一张纸

选中导航里的表 / 视图 / 列 / 连接，右侧面板把元信息摊开成页签：列、索引、约束、DDL 各归其位；权限 / 依赖这类驱动尚未实现的能力，先绘制、置灰标注——不静默消失。

DBeaver 式 tab描述驱动 权限灰置数据来自实时内省零 UI 造数据

①描述驱动：页签是数据，不是 match 分支

注册表定页签

PropertyRegistry::pages_for(kind) 决定页集合——表 7 页、视图 4 页、列 1 页；渲染方只遍历描述，不写对象分支。

加能力不加代码

驱动补内省能力位 → 注册表翻 Supported → 页签自动亮起，渲染零改动。

灰置是状态不是特例

权限 / 依赖以 Unsupported 入册，页面照常绘制、置灰标注——用户看得到产品路线图。

④它不做的事

不编辑元数据

属性面板只读；改名 / 建索引 / 授权走编辑区与命令。

不替代编辑器

表数据浏览 / SQL 编辑在编辑区；面板只回答「这是什么」。

不预言驱动能力

驱动没实现的能力一律灰置，绝不拿目录信息硬凑权限清单。
