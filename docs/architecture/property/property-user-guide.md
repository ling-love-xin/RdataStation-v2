# 属性面板 · 用户指南

> 面向使用 RdataStation 的开发者；对应实现见 `property-module-spec.md`，界面规格见 `property-prototype-design.md`。
> 适用范围：M4 数据库导航（连接 / Catalog / Schema / 表 / 视图 / 列 / 例程 / 序列 / 触发器）。

## 1. 打开属性面板

| 方式 | 操作 |
| --- | --- |
| 双击 | 在导航树中**双击**对象（表 / 视图 / 列 / 连接等） |
| 快捷键 | 选中对象后按 `F4` |
| 搜索 | Quick Open（`Ctrl+P`）中选中对象后执行「ShowProperties」命令 |
| 列表 | 搜索结果行单击目标对象 |

面板打开后停靠在编辑区右侧；再次打开其他对象会**就地切换内容**（页签状态保留在面板内）。

## 2. 面板构成

```
[对象名 | 类型 | 状态]   ← 头部
[通用 | 列 | 索引 | 约束 | DDL | 权限 | 依赖]  ← 页签（随对象类型变化）
└── 内容区（当前页签内容）
```

- **页签集合由对象类型决定**：表 = 通用 / 列 / 索引 / 约束 / DDL / 权限 / 依赖；视图 = 通用 / 列 / DDL / 权限；连接 = 通用 / 权限；列、序列、触发器 = 通用（触发器另有「关联表」）。
- **通用**：对象核心元信息（名称、类型、归属域、限定名；表另含列数；列含所属表 / 类型 / 可空 / 主键 / 外键 / 引用 / 默认值 / 注释）。
- **列 / 索引 / 约束**：分区表格（表头弱化 + 数据行）；无数据时显示「（无）」，不摆空表头。
- **DDL**：建表语句。**优先取源版**（数据库保存的原文），源版取不到时由内省结果合成——合成版标注来源，仅作参考。
- **权限 / 依赖**：见下节灰置规则。

## 3. 灰置页签（权限 / 依赖）

「权限」「依赖」目前为**占位状态**（驱动内省能力未实现）：页签可见但样式置灰，点击后内容区显示——

> 「权限」查看与操作暂不支持（驱动能力未实现）

这不是缺陷，而是**能力先绘制、后激活**的设计：驱动补上权限 / 依赖内省后，页签自动变为可用，无需改产品版本。

## 4. 常见问题

| 问题 | 说明 |
| --- | --- |
| 切换对象后内容未变 | 快速连续打开多个对象时，过期请求结果会被丢弃（以最后一次打开为准）；等待当前加载完成后仍异常，刷新元数据后重试 |
| DDL 与数据库原文不一致 | 合成 DDL 是目录信息重建，字符序 / 注释可能与原文有差异；需要精确原文的库（MySQL / SQLite / DuckDB）优先取源版 |
| 面板宽度 | 可拖拽调整（默认 280px），关闭面板时自动记住宽度 |
| 加载中 / 报错 | 内容区会显示「加载中…」或错误信息；报错多为连接或驱动不支持，检查状态栏连接状态 |

## 5. 支持与限制

- 支持的连接类型：内置驱动（mysql / postgres / sqlite / duckdb 等）均可打开属性面板；无独立 Schema 层的库（SQLite / DuckDB）自动省略 Schema 层。
- 暂不支持：权限 / 依赖（灰置）、大宽表的列折叠（规划中）。
