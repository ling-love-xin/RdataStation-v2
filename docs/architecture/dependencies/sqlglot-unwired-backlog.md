# sqlglot 能力接线状态与压后项（决策侧记）

日期：2026-11-08　分支：`chore/deps-patch-batch-2026-11`　上游：`sqlglot-rust 0.11.1`

本文件记的是**「已经能调，但暂时不接进产品」**的那几项，以及它们各自的**触发条件**。
出口本身的清单与实测行为见 `sqlglot-rust-0.11.1-upgrade-report.md` §8；这里只做决策记录，
避免以后有人翻到 `crates/sql/src/analysis.rs` 里一个没人调的函数，误以为是漏接线。

## 1. 一句话结论

**能力已经释放，接线按 UI 需求走。** 为了凑「全部已接线」而给每项硬找 UI 位，只会造出没人用的入口；
真正值得先投的基建（表列快照）已经在 2026-11-08 落地，剩余项等对应界面立项再接。

## 3. 压后项逐条

### 3.1 列级血缘 `lineage_of_column`

- **能做什么**：给一个输出列名，返回 `[{name, source, depth}]` 的逐跳血缘（`SUM(amount) AS total`
  → `total` / `amount` / `orders.amount`）。
- **为什么不接**：产品侧**没有血缘视图**。函数出口在，数据能算，但摆不到任何界面上；
  硬接只能塞进悬停，把一行提示撑成三段，反而稀释 hover 的信息量。
- **触发条件**：血缘面板（列来源图 / ETL 影响分析）立项时直接接，数据形状已经现成。
- **成本**：面板落地后 ≈ 1 天（组装 `TypedTable` 已有通路，只需渲染）。
- **前置**：无额外前置（`TypedTable` 已由目录快照提供）。

### 3.2 AST 差异 `diff_summaries`

- **能做什么**：两段 SQL 的结构化差异（增/删/改/移，带 `Keep` 判定）。
- **为什么不接**：`insight` 里的 compare 是「多表结果对比」，不是「SQL 版本 diff」；
  仓库里没有「草稿 vs 已保存」「存档版本对比」这类承载点。
- **触发条件**：① 存档/版本的改动预览；② 结果集对比界面要做「查询语句也变了」的提示。
- **成本**：极低（纯字符串拼提示，≈ 半天），难的是**产品场景**而不是代码。

### 3.3 本地计划 `plan_summary`

- **能做什么**：sqlglot 自建的算子图（`Scan/Filter/Join/...`）+ mermaid 文本。
- **为什么不接**：**它不是源库的 EXPLAIN**。摆给普通用户看会被理解成「数据库真实执行计划」，
  是明确的**误导**；DDL 上游还直接报不支持。
- **触发条件**：只允许进「调试 / 诊断」面板，并且界面上必须写清「sqlglot 自建计划，非源库执行计划」。
- **成本**：低（数据现成），但**文案责任**大于代码成本；没有调试面板就不做。

### 3.4 `builder` 的 ~50 个构造器

- **为什么不接**：现在 `crates/sql/src/builder.rs` 主要用手写结构体字面量；
  这正是「0.11 给 `CreateTableStatement` 加两个字段，我们就要改两处」的根因。
- **触发条件**：下一次要动 `builder.rs` 时顺手迁（不是独立任务）。
- **成本**：中（≈ 半天），收益是**下次升级不再被字段增删打断**。

### 3.5 方言动态注册（`DialectPlugin`）

- **为什么不接**：上游 30 种方言，我们固定用 11 种（4 个内置驱动 + 转译目标），
  没有「用户装插件带新方言」的产品形态。
- **触发条件**：插件系统要支持自定义方言时再看。
- **成本**：未知（要先定插件边界），当前不做。

## 4. 边界（写清楚，别被误解成 DuckDB 专属）

- 本文所有需要元数据的能力（类型标注、血缘）用的是 **`Catalog` 目录快照**：
  `WorkbenchCompletion` L1 缓存 → `editor_catalog::pump`（1s 一拍）→ `EditorShared::set_catalog_snapshot`
  → 各消费点读同一份。
- 这份快照来自**文档绑定的那条连接**，因此对 MySQL / PostgreSQL / SQLite / Oracle / SQL Server /
  DuckDB 等**每个源库**都一致生效；DuckDB 分析模式只是其中一种场景。
- 未绑定连接 / 目录未载好 → 如实退化（不给类型、不给列列表），不跨连接猜。
- 已知局限：pump 只推**活动文档**，非活动文档最坏晚一拍（见 `crates/editor/src/ports/editor_catalog.rs`
  的边界说明）。
