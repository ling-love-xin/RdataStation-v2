升级到全局§13.3

本块现状：没有前置确认对话框。项目行右键「升级到全局…」点一下直接入队，状态栏只给一句「正在升级到全局…」； 只有撞名才开窗（17 块的覆盖 / 改名 / 取消）。目标名一律取显示名，代码里没有「先改名再升级」的入口。 变体 C 是本轮提的一个可选方案，规格里并没有这张框（§13.3 只在冲突时要求询问改名）——摆出来只为拍板，不当规格落差看。

为什么把它归到「方案」而不是「落差」：§13.3 只写了「表名默认取显示名，冲突时询问改名」，并没有要求升级前先弹一张确认框——那是本轮提的加法。实现选了「不确认、撞名才问」，与规格并不矛盾，只是能让用户在入队前先看到「形态 / 目标实例 / 版本」这三件会变的事。要不要加，得先定「升级前能不能改名」：不改名，就只能接受改名入口出现在冲突处置里。
