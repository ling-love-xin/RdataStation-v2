怎么用这一套
① 要改视觉（间距 / 颜色 / 行高 / 徽标形状）→ 改 _shared/proto.css 一处，19 页同时生效；
② 要改某一块的布局或文案 → 只改那一页的 HTML，不会牵动别块；
③ 要加新状态 → 在那页里新加一个 .variant 小节，页内并排即可，不用造状态位；
④ 页脚「本块样式 + 落地代码」告诉你这块在 crates/analytics_resource/ 落到哪，评审结论可直接指到文件。
三种状态显影手法：proto.css 里本来就有 .open / .on 的（弹层、菜单、横幅、撤销条、重叠表）直接加；没有独立开关的（对话框、右键菜单、状态行、编辑区 tab、详情态）用 page.css 的 .proto-on，它只做 display 与定位还原，不改任何视觉。
