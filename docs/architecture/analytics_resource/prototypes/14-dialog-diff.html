两种形态共用同一个 diff 结果、只换渲染：切换不重新算 diff（否则两边行号会漂）。超长行一律省略号 + tooltip，不折行（折行会让左右列错位）。59 行的文本在这个宽度下按 max-height:340px 内滚。
