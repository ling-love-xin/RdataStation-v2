「切换不重算」这条对：两个按钮都只调 state.set_mode(...) + window.refresh()，DiffState 在开窗前建好、两份视图共用同一份解析结果。但实现不自绘左右两列——是组件在 Split 模式下把每行拆成左右两格，缺行一侧留空格对齐，行号也跟着变成两列（左旧右新）。
原型没画而实现有的：文件头（dau_report.sql@3 + +1 −1，左边一个折叠箭头，可把整个文件收起来）、@@ hunk 行、上下文折叠行（两个 hunk 之间隔得多时，中间那段收成「展开 N 行」）、行号 gutter 可拖选（拖动选一段行再 Ctrl+C 复制原文）、键盘上下 + Shift 扩展 + Ctrl+A 全选、悬停整行高亮（hover_highlight(Line)）、语法高亮（syntax_highlight(true)，按扩展名着色；本页示意没着色）。交互靠组件自带，示意里只画了前三样。

C打不开的那些情况不开空窗，直接在面板上给一句
资产库：无法对比版本：该文件不是文本（可能是二进制），无法对比

四种情况不弹窗，都走面板通知条（不是版本动作回执、也不是空壳对话框）：副本已被保留策略裁掉（「该版本的内容副本不在（已被保留策略裁剪），无法对比」）/ 本体缺失或没有本体路径（分析表档：「该存档没有本体路径（可能是分析表档）」、缺失：「本体不在位」）/ 不是 UTF-8 文本 / 单侧超过 512 KB（「文件过大，请用编辑器查看差异」）。另外 patch 解析不出内容时（两侧其实一样、或数据异常）open_version_diff_dialog 直接返回，连窗都不开。

本块样式：.dlg（1024px）/ .dlg-head / .dlg-body / .dlg-foot；diff 区在本页用内联样式画（两列 32px 行号 gutter + 14px 符号列 + 内容列），不再依赖旧的 .diffview / .drow / .dno / .dc / .difftool / .mode-sw——那些 CSS 是照「共用一列行号 + 分段控件」画的旧账。
diff 区不是自绘：Diff::new(&state).line_number(true).syntax_highlight(true).hover_highlight(Line).max_h(rems(28.0))，滚动由组件内部负责（含横向 ScrollableMask）。soft_wrap 默认 false → 不折行、横向滚动；原型写的「超长行一律省略号 + tooltip」并不成立。
