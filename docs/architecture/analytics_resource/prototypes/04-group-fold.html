按 group_header.rs 核：计数只写数字（format!("{count}")，没有「项」这个单位；聚合头数的是当前可见行总数）。色条取 primary（与 list_active_border 明暗同值，口径统一），宽 ui::GROUP_BAR_WIDTH（2px）、高 0.875rem=14px、圆头；展开指示走 tree::disclosure_slot() + disclosure_icon(!collapsed, muted) 的 10px 槽。
「全部分组」自己也能折（collapsed 里放 __all__，折了整块只剩这一行）。缩进只有两档：depth == 0 不缩、depth > 0 给 pl_2（8px），不套树的 TREE_BASE_PADDING + depth × TREE_INDENT。
真分组（不是「全部分组」/「未分组」）的头上有右键菜单：重命名… / 设为|取消归档默认分组 / 删除分组 / 新建分组…；两个虚拟头没有菜单，也不接拖拽落点。折叠状态按项目分桶写 resources.collapsed_groups。
计数与徽标在实现里都是纯文本（text_xs + 主题色，没有底色块 / 描边 / 圆点；计数不带单位）——上图给计数画了胶囊底，是设计意图、实现尚未跟上；`rds-design` 要求状态徽标走 badge::Badge，这条记在设计稿里当欠债。

「默认」只影响下一次归档的预选值，不碰已有存档的归属；语义取显式设置（不是「跟随上次」）。标记文案是常量 DEFAULT_GROUP_MARKER = "默认"，画在名称之后、计数之前，是事实提示不是控件——设 / 取消走头上右键菜单里那一项（唯一入口）。
