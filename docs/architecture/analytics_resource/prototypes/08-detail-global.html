全局行只看、只分发：动作收敛为一条 「分发到本项目…」（ghost 按钮 + 按钮下方一句说明）。全局共享层是 只读 的，分发到项目后才能在项目侧编辑。 不摆的分区：组织（没有项目分组归属）、标签（全局不带本地标签、也不许打标）、危险区（不能删）；版本区还在（有「历史」行），但不挂「查看全部…」入口（没有本地版本链可翻）。 跨项目唯一法定路径 = 项目 → 全局 → 项目；项目 ↔ 项目禁止直传；promoted_from（草稿→归档）与 scope（项目→全局）是两层升级，不混用。
