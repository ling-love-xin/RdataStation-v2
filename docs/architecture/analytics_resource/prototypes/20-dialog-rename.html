重命名 / 编辑别名对话框§3.1 / §3.2

宽 384px（24rem）· 两个字段共用一个形状：一个输入 + 一行说明 + 保存 / 取消。只改显示名与别名，文件不动—— resources/ 下的文件名与路径不在这条路上（要改文件名得先取回再归档，§1 原则 2）。 三处入口同一条链路：行右键「重命名…」、F2、详情头部点名字；别名只在详情头部点别名。

实现口径（dialogs/rename.rs）：闸门是纯函数 rename_gate（带单测）——显示名走 name_hint 查空名，别名不走（空 = 清除是合法动作）；Unchanged 只让保存置灰、不显示错误色。说明文字每帧从输入值重算，改回去提示自然消失。 实现只在保存按钮与 Enter（on_ok）两处过闸，没有第三处重复校验。宽度常量： ui::NAME_DIALOG_WIDTH = 24rem。
