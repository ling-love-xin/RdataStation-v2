E规格没定的两处【待确认】——拍板前不进代码
① 纯文件档 影响 今天它们会落进「脚本内容表」分支然后读失败；要么明确拒绝并置灰，要么定一套二进制承载。§13 没写。 ② 分发后改名 影响 没改名入口时，同名的两份永远撞；只能先撞进冲突框再改名（多一次往返）。
