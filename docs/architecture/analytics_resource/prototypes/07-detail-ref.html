引用型归档模式的三个硬口径：① 本体留源位置，只存元数据（地址 + 指纹 + 版本）；② 打开前懒校验，指纹变了不打开，先摆失效条；③ 移入回收站只删登记记录，源文件不动，之后可从回收站还原登记行。

本块样式：.warnstrip / .dhead / .locknote / .kv.blk / .tags + .tagc / .btn-s + .btn-xs。 组织区「移动…」与 06 页 C 变体是同一颗按钮（同一套宿主动作），这里只摆按钮、不重复画菜单——引用型同属项目行，分组归属与移动语义和 File 型一致。 落地代码：crates/analytics_resource/src/detail_view/（引用只读提示已由 alert_line 覆盖）；TableRef 只保留读取兼容，不新增能力。
