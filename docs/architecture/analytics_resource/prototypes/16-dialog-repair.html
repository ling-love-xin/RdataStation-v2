本体已经不存在，删掉记录后这个存档就彻底没了（不含回收站）。

`window.open_alert_dialog`：标题「删除这条登记记录？」，正文「本体已经不存在，删掉记录后这个存档就彻底没了（不含回收站）。」，带取消。 按钮文案是一处欠债：这一处只设了 `title` / `description` / `show_cancel`，没设 `ok_text` / `ok_variant` / `cancel_text`，所以确认按钮是组件库默认的「OK」（Primary 变体），取消是「Cancel」。本仓组件库的语言（`gpui_kit::component::set_locale` → `rust_i18n`，fallback 为 en）与业务文案的 `shared::i18n` 是两套，而且前者从未被设置过，所以中文界面里这里会冒出英文按钮。修法两条：本处显式 `ok_text("删除记录")` + `ok_variant(Danger)` + `cancel_text("取消")`；或在 app 启动时把组件库 locale 跟着设置里的语言一起设（一处修，全仓受益）。
「补登为存档」与「接受当前内容」都没有确认框——两者都可解释（补登只是把文件认领进来；接受当前内容会把旧内容变成「只留元数据」的一版，但回执里明说「旧内容不可得」），所以没做二次确认，与「删除记录」的处理刻意不同。另注意「接受当前内容」虽无确认框，按钮却是普通 small（不是 ghost），危险度靠文案与回执兜（「旧内容不可得，那一版只留元数据」）。
