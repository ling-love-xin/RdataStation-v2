三种 kind：本体在哪，决定复现强度

文档形 = 文件 表格形 = 分析表 链接形 = 引用
已归档强（内容冻结，重跑同解） 分析表中（定义冻结，数据可重建）
引用弱（只记当时指向哪） 内容已变指纹不匹配
  • 强度徽标是行内唯一色块；kind 图标只靠形状区分（三者同色，避免与强度语义撞色）
  • 版本徽标 v3 在 v1 时省略（减少噪声）；TableRef 无指纹 → 不显示版本
  • 行内字段优先级：显示名 > 复现强度徽标 > 版本徽标 > 相对时间 > 大小；放不下的一律省略号 + 悬浮 tooltip（行 tooltip 带全字段）
  • 文件型行尾 = 大小与相对时间合并为一个 muted 字段；分析表型 =「行数 × 列数」；引用型 =「无指纹」

只读是常态（三重强制）

  • 应用守卫：写入路径落在 resources/ 直接拒绝 → 提示「这是归档本体，请先取回」
  • 编辑器：以只读模式打开（专门的「分析资源锁定」只读来源），内容预览区也带锁标记
  • 文件系统：只读属性（辅助手段，Windows / 网络盘不可靠，失败只警告）
  • 面板上不提供「编辑存档」入口：有入口就一定有用户点了才发现不能存
  • 要改 → 右键「取回（检出）…」→ 草稿工作副本 → 再次归档生成新版本

右键菜单项与条件（§3.2）

  • 打开（只读）Enter · 等效双击：文件 → 编辑器只读；分析表 → 结果表格；引用 → 先校验存在性
  • 取回（检出）… / 版本历史… ：仅单选可用（多选时灰显）
  • 重命名显示名 F2 · 打标签… · 移动到分组：多选时变成「批量打标签 / 批量移动」
  • 在系统中显示 · 复制路径：单选，调 opener
  • 分隔线以下为破坏性项：移入回收站（多选可用，二次确认并显示数量，底部出现撤销条）

异常入口与索引修复

  • 状态行 缺失 W / 索引异常 V 非 0 时该段高亮可点 → 打开「索引修复」对话框
  • 本体缺失：行灰显 + 删除线 + danger 点；详情面板出横幅与修复入口
  • 指纹不匹配：行内 warning 徽标「内容已变」；TableRef 未校验：详情面板顶部警告条 + 「立即校验」
  • 三分组处置：有文件无记录 → 补登为存档；有记录无文件 → 从回收站还原 / 删除记录；指纹不匹配 → 接受当前内容 / 从历史还原
