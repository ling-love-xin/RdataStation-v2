设计要点 图标体系：Lucide（gpui-kit IconName 同源），工具栏 14px、结果栏 12px；文字随语义保留（模式名 / 环境名不纯图标化） 环境选择器：工具栏常驻（与 SQL 模式连接选择器同位），显示当前解释器 + 版本 切换语义：环境 = 变量空间 → 旧结果 stale 降级：缺解释器 → 运行 不亮 + 状态栏说明 输出：表格/结构化，复用结果集（§2.4） 状态栏：编辑面板专属（非软件全局状态栏）——左=环境/文件类型/LSP；右=英文微标+数据（Ln/Col/Ch/Row/UTF-8/LF/Spaces/大小），VSCode 式可点击重设 内核能力：缩进（TabSize）与列编辑（ColumnarPoint/多光标）原生支持；编码/换行重设 需外层转换层（内核只 Unicode/LF，菜单项已降级标注）
