当前：SQL 模式
可交互（点击即生效）
  • 顶栏：明暗主题切换（全部颜色走 CSS 变量）· 三模式切换（各视图状态各自保留）
  • 执行族（执行 ▾）：当前语句 / 选区（无选区回退）/ 全部（3 条语句逐条） / 批量（逐条独立，失败不中断）/ 在新结果标签中执行；主按钮 执行 执行当前语句，执行中变 ■ 中断
  • 编辑区：点击任意行可切换「当前语句」（整段浅底 + 左侧竖条联动，Ln/Col 与语句数同步重算）——切到第 12 行 INSERT 可演示写拒绝
  • 执行位置（通道）：三通道互斥切换；生产 PG 连接下「DuckDB 本地加速」置灰并给原因、联邦无源也置灰；联邦选中后展开外部源列表（2 个假源可勾选）
  • 通道后果：① 结果集标签出现通道徽标 + 血缘摘要；② 状态栏新增「通道」字段（源库 / 加速 / 联邦 · 快照）；③ 加速 / 联邦下事务区变「TX 不支持（本地副本）」；④ 加速 / 联邦下执行含 INSERT 的语句 → 被拒绝（错误卡 + 危险点 + 状态栏提示）
  • 结果区：筛选输入 = 本地即时过滤；勾选 ▢ 下发源库 后回车筛选 → 拼 WHERE 产生新结果集（血缘 原查询 + WHERE，原结果保留）；⚗ 分析 ▾（计数 / 分组统计 / 自定义分析 SQL…）也产生新结果集（血缘 t1 + 分析 SQL）；结果 N 切换 / ✕ 关闭（上限 5 个，淘汰最旧）· 行点击多选 · 拖拽分隔条（双击复位）
  • 切通道即失效：旧结果集标签整体标灰（可切回回看）+ 结果区顶部提示条「通道已切换，旧结果来自 <旧通道>」
  • 分析：全部运行（逐单元 执行中 → 完成并清除 stale；遇源库写单元 → 该单元被拒并继续，不中断）· 单元 ▶ / 执行中 ■ 中断 · 重启会话 · 清空输出 · 会话选择器可切会话与通道（切通道 → 输出清空 + 全标 stale + 提示条「通道已切换，N 个单元已过期」）· 输出区 ▾ 展开 / ▴ 收起（192 ↔ 384px）· 单元 ⋮（上移 / 下移 / 复制 / 删除 真实生效）· 单元之间 + 代码 / + 文本
  • 写限制判据 = 是否作用于源库对象：INSERT / UPDATE / DELETE / 非 TEMP 的 CREATE TABLE·DROP·ALTER 在加速 / 联邦通道下被拒（SQL 模式与笔记单元共用同一判据）；CREATE TEMP TABLE、临时视图、SELECT … INTO TEMP 是分析会话的“变量”，不落源库，任何通道都允许。对照：单元 3（临时表 → 成功）vs 单元 4（UPDATE → 加速 / 联邦下被拒）
  • 旧结果标灰规则 = 切通道那一刻：切换通道时把已有结果标灰 + 结果区顶部提示条（可关）；跨通道新建的结果（如 DuckDB 分析结果固定走加速通道）不标灰，只以通道徽标 + 血缘摘要标注来源
  • 工作台：左活动栏图标切换 · 右活动栏收起 / 展开历史面板 · 左树搜索过滤与行选中
静态示意（点击只在右下角提示）
  • SQL 工具栏：⋯ 更多 ▾ 菜单展开（执行计划 / 方言转译… / 校验语法 / 保存为片段 / 复制为 INSERT）· ⇤ 格式化 · ⟲ 历史 · 导出 ▾ · ⟳ 刷新 · ＋ 注册新源… · 补全弹层（分组 / 徽标 / detail / 元数据来源行）· 结果分页 · 列头排序 · 错误卡的「复制」
