# SQL 编辑器模块 · 使用手册

> 面向**使用者与验收人员**：编辑器怎么用、每个按钮做什么、出问题怎么排查。
> 设计与实现看 `editor-architecture.md`（权威）与 `editor-prototype-design.md`（视觉规格）。
>
> **能力期次标注**：本文写的是**已落地**能力——Phase 1a（内核 / 文本 / SQL 编辑体验 / 最小执行）与
> Phase 1b（执行闭环：中断超时 · 事务 · 历史 · 筛选下发 · 导出 · 补全 · 格式化/转译/执行计划 · 通道三档 · 结果集分段）均已接。
> `Phase 1c`（分析模式单元）**尚未接线**，相关段落只描述入口形态、不按它验收。
> 已知边界的权威清单在 `editor-architecture.md` §12.2（本文只在对应位置标一句「未做」）。

## 1. 这个模块能做什么

一份文档、一个内核、**三档能力**——档位由「扩展名 / 上次显式选过的模式」决定，能力跟着档位走：

| 模式 | 判定 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| **SQL** | 后缀 `.sql` / `.mysql` / `.pgsql` / `.psql` / `.ddl` / `.tsql` | 高亮 · 折叠 · 补全 · 格式化 · 转译 · 执行 · 事务 · 结果集全套 | — |
| **文本** | 其它后缀 / 没有后缀 | 纯记事本：编辑 / 查找替换 / 行注释 / 折叠 | **不解析 SQL**：不上色、不格式化、不执行（按 `Ctrl+Enter` 会明确说明原因） |
| **分析** | 后缀 `.rdsnote` / `.sqlnote` | 骨架已在（模式判定与切换代价已算清） | `Phase 1c` 未接：单元 / 输出 / 会话尚未落地 |

**「执行入口唯一」**：所有执行动作最终都落到同一条执行端口；结果只进 `ResultStore`（结果单权威），
视图只是投影——所以「刷新 / 换标签 / 复制」看到的永远是同一份数据。

## 2. 入口

| 入口 | 位置 | 打开后 |
| --- | --- | --- |
| 启动 | 应用打开即有一份**未命名 SQL 文档**（若上次退出时有文档，恢复**最近更新的那一份**：光标 / 选区 / 模式 / 连接 / 通道一起来） | 直接可写可执行 |
| 新建 | Quick Open（`Ctrl+P`）→ 命令组「新建查询 / 新建笔记 / 新建文件」 | 未命名文档，模式按命令给定（查询 = SQL） |
| 打开文件 | `Ctrl+O`（系统文件对话框）；「打开菜单」里同样走这条路 | 按后缀判模式；同路径已打开**只激活不重读**（不冲掉未保存修改） |
| 数据库导航 | 右键对象 →「在 SQL 编辑器中打开」/「查看数据」（**打开即执行**）/「生成 SQL」；拖对象到编辑区 | 复用条件很窄：未命名 + 内容空 + 同一连接；带 SQL 时**追加不覆盖** |
| 草稿箱（M5） | 双击草稿行 / `Enter` / 右键「打开」 | 打开该草稿；该草稿记过连接绑定则**预选**那个连接（已被删除的连接不预选） |
| 历史面板 | 右 Dock「历史」→ 条目「重放」 | 在编辑器打开那条 SQL，**不替你执行**（历史里什么都有，包括写语句） |
| 资产库（M6） | 存档本体「打开」 | 以**编辑器只读**打开：可看不可改，改它要先去取回 |

## 3. 界面导览

### 3.1 工具栏（按语义三层）

```
[SQL ▾] │ ▶ 执行 ▾  │ ⇤ 格式化  ⋯ 更多 ▾              │ 源清单 ▾  执行位置：源库 ▾  连接 ▾
  模式       执行级        文档级                              会话级
```

> **分层即门控**：执行级 / 文档级 / 会话级这三栏**只在 SQL 档出现**——文本档是纯记事本，不该看到执行按钮；
> 分析档的执行属单元级（`Phase 1c`，未接）。`源清单 ▾` 只在联邦档出现。
> 工具条右边永远有模式指示器：切档不需要先去别处找。

| 控件 | 说明 |
| --- | --- |
| `[模式 ▾]` | 三档切换。**需要确认的切换一定先弹框**（说清内容怎么变 / 代价是什么），不会静默换档 |
| `▶ 执行`（分体按钮） | 主按钮 = **选区优先 → 当前语句**（与 `Ctrl+Enter` 同一条路）；菜单 = 执行当前语句 / 执行选区 / 执行全部 / 批量执行（逐条独立）/ 在新结果标签中执行 |
| `⇤ 格式化` | 只格式化「选区或整篇」，**区间外一个字节不动**；走内核撤销栈，`Ctrl+Z` 能撤回（**只在 SQL 档出现**） |
| `⋯ 更多 ▾` | 执行计划 · 转译为 ▸（十个目标）· 插入模板 ▸（模板库里的片段；没模板就不摆） |
| `执行位置 ▾` | 源库 / 本地加速 / 联邦。不可用的档**保留形态但置灰 + 行尾给原因**（只报第一条过不去的）；本地那两档多一项「重新挂载源库（刷新表清单）」 |
| `连接 ▾` | 本文档绑定哪条连接（首项「跟随当前连接」）。选一条会先自动建连，**建连失败就不绑定**并留原因。绑定随会话跨重启 |

### 3.2 编辑区

- 行号、SQL 语义着色（关键字 / 字符串 / 数字 / 注释 / 函数 / 类型…；表名列名**不上色**）、
  括号折叠（`(…)` / `CASE…END` / `BEGIN…END`；**同行闭合的不折**，`LOOP` / `WHILE` 暂不折）、
  出错词下划诊断、悬停定义。
- 查找替换用**内核自带**的浮层（`Ctrl+F` / `Ctrl+H`），不是自绘。
- 大文件档位：> 50 MB 关重能力（补全 / 折叠）；≥ 200 MB 只读 + 不整份读进内存（面板给提示卡）；高亮在 > 1 MB 时降级。
- 拖一个草稿文件到文本区 → 内容**插到光标处**（有选区则替换），状态栏提示「已插入 …」。

### 3.3 结果区（有结果或执行中才占位）

| 段 | 内容 |
| --- | --- |
| ⑤ 结果集标签条 | `结果 N`（失败项带红点）。上限 5 份，超出淘汰**最旧的未选中**那份；非当前通道的结果缀 `·旧`（切通道后旧结果**保留**） |
| ⑥ 工具栏 | 左段：`行数` / `影响 N 行` / `失败` │ `耗时` │ **来源摘要**（原查询 / 下发筛选 / 排序下发 / 取下一段 / 执行计划 / 本地分析）│ `连接名` │ 已筛选提示；右段：`⌕ 筛选`（含 `▢ 下发源库` 开关与 ✕ 清除）· 复制 TSV · `⟳ 刷新` · `取下一段`（只在还有下一段时出现）· `⤓ 导出 ▾` · `⚗ 分析 ▾` |
| 网格 | 首列 `#` 行号槽（钉左）；列宽可拖、列可移、点表头右端箭头排序（**点正文不排序**）；悬停看全文（长值 / 长列名截断后的唯一出路）；右键：按值筛选 / 复制此值 / 复制此列 / 复制整行（TSV）/ 升序·降序下发 / 冻结此列 / 洞察此列 |
| ⑦ 状态行 | `共 N 行`（还没抓完显示 `N+`）· `已选第 N 行` · `已截断至 N 行`（警告色） |

### 3.4 状态栏（编辑器底部）

左：模式 · 语句数 · 未保存"●"；右：只读维度（「只读」/「连接只读」**分开写**，互不蕴含）· Ln/Col · 已选字数；
中间按需出现：**连接段** · **通道段** · **TX 区**（`TX 未开启` / `TX 已开启 3.4s` + 自动提交开关 + 提交 / 回滚）·
`执行中 3.4s…` + `■ 中断` · 动作失败原因（未命名需另存为 / 只读拒绝 / 通道拒写…）。

## 4. 典型流程

### 4.1 跑一条查询

1. 绑连接（不绑 = 跟随导航里当前选中的连接）；
2. 光标放某条语句上按 `Ctrl+Enter`（有选区就只跑选区；`Ctrl+Shift+Enter` 跑全部）；
3. 结果落当前结果集（`▶` 菜单里选「在新结果标签中执行」则新开一份，**原结果不动**）；
4. 写语句报「影响 N 行」，查询报 `行数 / 耗时`；失败给**错误卡片**（摘要 + 「定位到第 N 行」+ 复制原文）。

> **只取第一段**：查询固定先抓 **1000 行**（状态行显示 `1,000+`）。「取下一段」按钮或**滚动到底自动续取**；
> 每段会**重跑一次查询**，所以 `ORDER BY` 不稳的查询可能在两段之间重复 / 跳过行——要精确用一次性查询。

### 4.2 结果集上的六件事

| 想做的事 | 怎么点 | 落到哪 |
| --- | --- | --- |
| 找行 | `⌕ 筛选`（300 ms 防抖） | **只改视图行序**，不重查；工具栏明示 `已筛选 N / M 行` |
| 排序 | 点表头右端箭头 | 本地排序（数字按数值比）；要整份结果排 → 右键「升序 / 降序下发」 |
| 下推到源库 | `▢ 下发源库` 开着再筛 / 右键排序下发 | 拼 `WHERE` / `ORDER BY` **重查**，落**新结果集**（原结果保留）；去掉原 `LIMIT` 时状态栏说清 |
| 聚合 | `⚗ 分析 ▾` → 计数行数 / 按「列」分组计数 / 自定义分析 SQL… | 在**本地内存 DuckDB** 上对**已抓到的行**跑（最多 2 万行，超出如实说明），**不重跑源库**；落新结果集 |
| 拿走 | `⤓ 导出 ▾` / 复制 TSV / 右键复制 | 导出分两组：**仅已抓取** 与 **抓全量后导出（会重跑查询）**；格式 CSV / JSON / INSERT / WHERE 子句 / Parquet / XLSX（`SQL Updates` 要有键列才摆）。筛选中导出的是**筛后**的行集并明示 |
| 重跑 | `⟳ 刷新` | 重跑**选中那份**的 SQL，原位替换（分析结果不摆刷新——那是另一件事） |

### 4.3 格式化 / 转译 / 执行计划

- **格式化**：`Ctrl+Shift+F` 或工具栏 `⇤`。**逐条按语句区间回填**——语句之间的注释 / 空行 / 没写完的半句一个字节不动；
  解析不了的条数会如实报（「N 条解析不了（可能是还没写完），已原样保留」），不是"格式化失败"。
- **转译**：`⋯ 更多 ▾ ▸ 转译为 ▸ <目标>`。先切分再逐条转译（脚本**一条不丢**）；源方言来自**本文档绑定的连接**，
  未绑定 / 驱动认不出时点下去给一句可读拒绝，不猜。
- **执行计划**：`⋯ 更多 ▾ ▸ 执行计划`。按**当前通道**取方言（源库档用源库的；加速 / 联邦档用 DuckDB 的——
  那里才是真要跑的引擎），落**新结果集**并贴「执行计划」标题；SQL Server / Oracle 如实不支持。

### 4.4 补全与模板

打字时自动触发（标识符 / `.` 之后）；`Ctrl+Space` 手动叫一次（与打字那条**同一份候选**）。
候选来自导航侧的元数据缓存（按通道给限定名：联邦是 `别名.schema.表`），未绑定连接或缓存未命中时**只给关键字与函数**（如实，不假装有元数据）。
模板走 `⋯ 更多 ▾ ▸ 插入模板`：插到光标处并**选中 `{table}` 占位符**（接着敲表名就覆写它），只读文档在这里就拒。

### 4.5 事务 · 中断 · 超时

- **事务**：状态栏 TX 区的「自动提交」关掉 → 下一次执行先自动开事务（DDL 除外：MySQL 会隐式提交，那样开着事务就是骗人）；
  提交 / 回滚在 TX 区。事务内语句**不可取消 / 无超时**（驱动事务接口没有取消入口，见 §12.2）。
- **中断**：查询执行中状态栏出现 `■ 中断`（批量执行时，中断后**剩余语句不再发给驱动**，各自回一行「已取消」）。
- **超时**：按**连接**上配的查询超时执行；连接没配就是**没有超时**（不造默认值）。

### 4.6 执行位置三通道

| 通道 | 数据来源 | 前提 | 写限制 |
| --- | --- | --- | --- |
| 源库 | 目标库实时 | 连接已建立 | 受连接 / 项目只读约束 |
| 本地加速 | DuckDB `ATTACH` 的源库（**只读挂载**） | 连接开了「本地加速」+ 驱动可加速 + 扩展可用（首次要联网装一次） | 写源库被拒（引擎侧 `READ_ONLY` 再兜一次）；本地临时对象照常 |
| 联邦 | DuckDB + 多个外部源 | ≥ 2 个已连接且可挂的源 | 同上 |

加速 / 联邦档**不摆 TX 区**（没有事务语义）；加速档的**表清单**在 `ATTACH` 时定型——源库后来新建的表要
「重新挂载源库」才可见（数据本身是实时的）。

### 4.7 历史面板（右 Dock）

列表（时间 · 耗时 · 行数 · 来源 · 失败原因）· 搜索 · **重放**（在编辑器打开，不自动执行）· 删除单条 · 清空。
数据来自引擎的真实历史：成功与失败都留痕，通道会被标出来（`MYSQL·加速 · 源 mysql_src`）。
**未做**：多条选择与批量删除 · 引擎侧已有的筛选（库类型 / 仅成功 / 时间范围）未接到界面。

### 4.8 与草稿箱的闭环

1. 草稿箱双击 → 编辑器打开（带连接预选）；
2. 在编辑器里执行 → 那个连接被记回该草稿（下次打开还是它）；
3. 改了没保存 → 草稿树上打**脏点**；`Ctrl+S` 存回后消失；
4. 磁盘被外部改了而你这边还改着 → 草稿箱出**冲突条**（差异 / 重载 / 忽略）。

### 4.9 保存与关闭

- `Ctrl+S` 保存（未命名文档要先「另存为」，`Ctrl+Shift+S`）；保存成功才清脏点，写盘失败**不留假状态**（还会弹二次确认）；
- `Ctrl+W` 关闭：脏文档走**三态确认**（保存 / 不保存 / 取消）；Dock 标签栏 `⋯` 菜单的关闭项在脏文档上**直接不出现**（既不会静默丢，也不会点了没反应）；
- 点窗口 ✕ / `Alt+F4` 也会把**每一份**打开文档的会话落库（光标 / 选区 / 模式 / 连接 / 通道），**不是拦截**；
- 下次启动**恢复最近更新的那一份**（未命名 / 空文档不持久化）。**未做**：多文档恢复（只恢复最近一份）。

## 5. 一次操作落到哪

| 你做什么 | 落点（引擎 / 存储 / 界面） |
| --- | --- |
| 打字 / `Ctrl+/` / 格式化 / 插模板 | 内核文本（撤销栈保得住）→ `InputEvent::Change` → `EditorService`（脏状态由它比基线得出） |
| `Ctrl+Enter` / `▶` | 执行目标解析（选区 > 光标所在语句 > 全部）→ 执行端口 → 工作线程 → `SqlService` → 驱动 → 结果回填 `ResultStore` |
| 任意一次执行 | 引擎写一条**真实**历史（耗时 / 成功 / 行数 / 失败原因 / 所在连接 / 通道） |
| 筛选 / 排序 / 冻结列 / 复制 | 只动视图层（`view_rows` / `Column.fixed` / 剪贴板），**不重查** |
| 下发筛选 / 排序下发 / 分析 / 执行计划 | 引擎改写或本地 DuckDB → **新结果集**（原结果保留），来源摘要写进结果工具栏 |
| `Ctrl+S` | 写盘 → 清脏点 → 会话落库（光标 / 选区 / 模式 / 连接 / 通道） |

## 7. 只读与安全

| 维度 | 来源 | 表现 |
| --- | --- | --- |
| 编辑器只读 | 文档属性（资产库本体 / ≥ 200 MB 的超大文件） | 内核直接不可输入；写类动作（格式化 / 插模板 / 执行写语句）各自给可读拒绝 |
| 连接只读 | 连接策略 | 状态栏标「连接只读」；**不蕴含**编辑器只读，反之亦然 |
| 项目只读 | 项目锁（另一实例占用 / 用户锁） | **强只读**：写源库对象的语句在**提交前**就被拒（原因可读），`SELECT` 照跑 |
| 通道写限制 | 执行位置 = 本地加速 / 联邦 | 写源库被拒（提示切回源库）；本地临时对象放行 |

## 8. 常见问题与排查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 不上色 / 没有「格式化」/ `Ctrl+Enter` 被拒 | 文档在**文本模式**（后缀不认识，比如没有后缀的草稿） | 看工具栏 `[文本]`；要跑 SQL 就把后缀改成 `.sql`（草稿箱新建时用 SQL 模板会自动补） |
| 执行说「失败」但你确信 SQL 没问题 | 先看错误卡片：数据库说的原话在里头（位置认得出来就点「定位到第 N 行」） | 常见真因：保留了没加引号（如 MySQL 的 `order`）、库 / 表写错、连接选错（看工具栏 `连接 ▾` 与状态栏连接段） |
| 跑完只有 1000 行 | 分段抓取：查询固定先取第一段 | 状态行的 `1,000+` 与「取下一段」/ 滚动到底续取；求全量用「抓全量后导出（会重跑查询）」 |
| 两段之间行有重复 / 漏 | 每段重跑一次查询；`ORDER BY` 不稳时顺序不保证 | 给查询加稳定的 `ORDER BY`（含唯一列）；或改一次性查询 |
| 结果里数字列排序不对 | 展示文本是字符串 | 本地排序已经"两边都像数字就按数值比"；要严格按类型排 → 右键「升序 / 降序下发」（源库按自己的列类型排） |
| 切了执行位置，旧结果变灰 | 旧结果来自另一个通道（`·旧` 徽标 + 顶部一行说明） | 预期行为；旧结果**不会被删**，按需重跑 |
| 「重新挂载源库」后才有新表 | 加速档的表清单在 `ATTACH` 时定型 | 点「执行位置 ▾」里的那一项（数据本身一直是实时的） |
| 关闭标签时找不到关闭项 | 文档有未保存改动（`closable = false`） | 先 `Ctrl+S`，或 `Ctrl+W` 走三态确认 |
| 补全只给关键字 / 函数 | 未绑定连接 或 元数据缓存未命中 | 先绑连接；稍等缓存预载；这一档是**如实降级**，不是坏了 |
| 快捷键没反应 | 焦点不在编辑器面板（面板未 `track_focus` / 焦点在别的面板） | 先在编辑区点一下再按；若整块都无反应按缺陷反馈 |

## 9. USIT 验收清单（可勾选）

> 口径：**能量化的都能量**（状态栏 / 工具栏 / 结果区会把它写出来）。标「人工」的是窗口交互与明暗主题对照。

### 打开与模式

- [ ] 启动即有一份未命名 SQL 文档；`Ctrl+P` →「新建查询 / 新建笔记 / 新建文件」各能开出对应档位
- [ ] `Ctrl+O` 打开一个 `.sql` → 工具栏显示 `[SQL]`，`⇤ 格式化` 出现；打开一个 `.txt` → `[文本]`，格式化与执行按钮都不出现
- [ ] 文本档按 `Ctrl+Enter` → 状态栏给出「文本模式不解析 SQL」这样的**原因**（不是静默）
- [ ] 同一路径再打开一次 → **只激活已有标签**，不重读（先用未保存改动验证）

### 编辑体验

- [ ] 关键字 / 字符串 / 数字 / 注释 / 函数各有颜色，表名列名保持正文色（人工，明暗各看一次）
- [ ] 括号块 / `CASE…END` / `BEGIN…END` 前出现 chevron，点一下能折叠（人工）
- [ ] 打字出现补全候选；`Ctrl+Space` 也能叫出来且候选一致
- [ ] `⋯ 更多 ▸ 插入模板 ▸ <一条>` → 插到光标处且 `{table}` 被选中，`Ctrl+Z` 能撤回
- [ ] `Ctrl+F` / `Ctrl+H` 出查找 / 替换浮层
- [ ] `Ctrl+/` 注释开关可逆（`Ctrl+Z` 回到原样）

### 执行族与结果

- [ ] 光标在不同语句上按 `Ctrl+Enter` → 执行的是**那条**；选中一段按 → 只执行选区
- [ ] `Ctrl+Shift+Enter` → 整篇（多语句各自出结果）；`▶` 菜单「批量执行」→ 每句一份结果且中间失败不中断
- [ ] 「在新结果标签中执行」→ 新结果集出现且**原结果集保持选中**
- [ ] 结果集标签条超过 5 份 → 淘汰最旧的**未选中**那份，正在看的那份不被挤掉
- [ ] 写语句（`INSERT` / `UPDATE`）→ 工具栏报「影响 N 行」
- [ ] 故意写错列名 → 错误卡片有摘要与「定位到第 N 行」；点它光标落到出错词上（状态栏报行列）
- [ ] 查询超过 1000 行 → 状态行 `1,000+`；点「取下一段」或滚到底 → 续取，行号接缝不重不漏

### 结果集六件事

- [ ] `⌕ 筛选`：命中行收敛、工具栏 `已筛选 N / M 行` 出现、清除后行序恢复，**期间不重查**（无新结果集）
- [ ] `▢ 下发源库` 开着再筛 → **新结果集**出现（来源摘要写「下发筛选」），原结果保留；含 `LIMIT` 的原查询给出提示
- [ ] 右键「按此列升序（下发源库）」→ 新结果集按该列有序（来源摘要「排序下发」）
- [ ] 点表头右端箭头 → 本地排序（数字列按数值）；同键再点翻转方向
- [ ] `⚗ 分析 ▾ ▸ 计数行数` → 新结果集只有一行计数（来源摘要「本地分析」），且**不摆 ⟳ 刷新**
- [ ] `⤓ 导出 ▾`：在筛选中导出 → 文件里只有筛后行且回执带「（已筛选）」；`抓全量后导出` 会多跑几段再落盘（内容行数 = 全量）
- [ ] 复制 TSV 粘进表格能直接分列（含带制表符 / 引号的值）
- [ ] 右键「冻结此列」→ 横向滚动时该列钉住；换个结果集后冻结清空

### 文档级动作

- [ ] `Ctrl+Shift+F`：注释与空行一个字节不动；没写完的半句原样保留并如实报条数
- [ ] `⋯ 更多 ▸ 转译为 ▸ PostgreSQL`：语句一条不丢（多语句脚本逐条都在）
- [ ] `⋯ 更多 ▸ 执行计划`：落新结果集并贴「执行计划」标题（SQLite 是 `EXPLAIN QUERY PLAN`）

### 事务 · 中断 · 通道

- [ ] 关「自动提交」→ 执行后 TX 区显示「TX 已开启 Ns」；「回滚」后数据未变、「提交」后生效
- [ ] 长查询时状态栏出现 `执行中 Ns…` 与 `■ 中断`，点它快速返回可读结果
- [ ] 连接上配了查询超时的库 → 超时报可读错误（没配就是不超时）
- [ ] 「执行位置」里不可用的档**置灰 + 行尾给原因**；切到加速 / 联邦后旧结果缀 `·旧` 且顶部有一行说明
- [ ] 加速 / 联邦档执行写源库 → 被拒且提示切回源库；本地临时表照常可用
- [ ] 加速档：源库新建一张表 → 旧会话不可见 →「重新挂载源库」后可见

### 只读与关闭

- [ ] 打开资产库存档本体 → 以只读打开；写类动作各自给可读拒绝
- [ ] 项目只读时：`SELECT` 照跑；写语句在提交前被拒（执行器一行未收到）
- [ ] 脏文档：Dock 关闭项消失；`Ctrl+W` 弹三态确认；「不保存」不改磁盘
- [ ] 点窗口 ✕ 后重启 → 恢复最近那份文档的光标 / 模式 / 连接 / 通道

### 与相邻模块（M5 / M8）

- [ ] 草稿箱双击草稿 → 编辑器打开且**预选**该草稿记过的连接；执行一次后关掉再开，连接仍是它
- [ ] 编辑器里改草稿不保存 → 草稿树出现**脏点**；`Ctrl+S` 后消失
- [ ] 结果集列头右键「洞察此列」→ 右 Dock 洞察面板指向该列（M8 已接）
