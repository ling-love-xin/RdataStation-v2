## 2. 布局结构（对齐 v5 原型）

```
┌─ dialog（模态，popover 底 + border 边框，圆角 8）────────────────────┐
│ 标题栏（Dialog title）：『新建数据源连接』/『编辑数据源连接』  ─ □ ✕ （模态层）│
├───────────────────────────────────────────────────────────────┤
│ sidebar（200px，sidebar 底，高度恒定）│ main-panel（flex:1，Header 3 行）
│  ├ 搜索框（input，placeholder 搜索类型…）│  ├ Header：
│  ├ 暂存列表（标题行 + 添加）        │  │  ① 🐬 类型徽标(仅图标,1.75rem) · 名称(弹性) · 作用域三态分段
│  │   ▸ 固定高度 7.5rem，超出滚动    │  │  ② 备注(弹性) + 项目(定宽 17rem，仅全局禁用占位)
│  │   ├ 🐬 MySQL 演示 ●            │  │     项目下拉 = 项目名 + 路径，末项「＋ 新增项目」
│  │   ├ 🐘 生产 PG [G]             │  │  ③ 驱动(定宽 11rem，实现短名) · 地址/URI(弹性)
│  ├ 数据库类型（平面分类，不折叠）    │  ├ tabs-bar（tab_bar 底）
│  │   ▸ 占满剩余高度，超出滚动       │  │  常规 | 网络 | 能力 | 驱动属性 | 高级
│                                   │  └ 结果提示行（载入 / 保存 / 校验消息）
└───────────────────────────────────────────────────────────────┘
   底部操作栏： [🔌 测试连接] [⟳ 从全局定义同步*]  ✓ 成功·版本·延迟   [取消] [保存] [保存并关闭]
   （* 仅编辑「全局+项目」快照连接（GP_）时显示）
```

- **布局恒定**：左侧两区（暂存列表 / 类型树）与 Tab 内容区均为**固定高度 + 内部滚动**——条目 / 类型 / Tab 内容再多也不会拉长对话框（真机反馈）。
- **Header 只 3 行（建议布局）**：① 类型徽标（定宽 1.75rem，仅图标）+ 名称（弹性）+ 作用域三态分段；② 备注（弹性）+ 项目（定宽 17rem）；③ 驱动（定宽 11rem）+ 地址（弹性，网络型标签为 `URI` / 文件型为 `地址`）；标签列统一 1.75rem 左对齐。
- **地址列随驱动变形（真机反馈）**：
  - **网络型**：标签 `URI`，Header 内为**可编辑输入框**（唯一地址输入）；占位取当前驱动声明的 `url_template`（`{username}`/`{port}` 等换成示例值，端口用驱动声明的默认端口），无模板时退回 `{type_id}://主机:端口/数据库`。
  - **文件型（SQLite / DuckDB）**：标签 `地址`，Header 内**不再放输入框**（避免与卡片重复），只显示当前路径（截断）或引导文案；真正的地址输入在「常规 → 连接设置」卡片内，带 `打开文件… / 新建文件…`。占位按类型给文件提示（`.db/.sqlite`、`.duckdb` 或 `:memory:`）。
  - **单地址输入框约定**：同一个地址（InputState）只在一处渲染——网络型在 Header、文件型在常规卡片；不两处重复渲染（两处会让人分不清哪一个是权威值）。
- **数据库类型以徽标形式常驻行首**（**仅图标**：emoji，定宽 1.75rem，不显示类型名）；**未辨识时**徽标显示 `?`（warning 边框），驱动位置保留**禁用下拉占位**（placeholder「先选类型」）。
- **类型可用性**：类型目录按 `enabled` 过滤（禁用的类型不出现）；**无可用驱动的类型**（当前只内置 mysql / postgres / sqlite / duckdb 四个驱动）置灰 + 行尾小字「暂无驱动」，点击**不切换**并在结果行给原因。
- **项目栏单下拉（无模式切换）**：下拉项为**项目名（左）+ 路径（右，弱化、超长从头部省略）**左右结构；末项固定为 **`＋ 新增项目`**（选中后由宿主打开「新建项目」对话框；创建成功后新项目成为当前会话，本栏下一次渲染自动跟随）。作用域「仅全局」时保留**禁用下拉占位**（placeholder「仅全局不需要」）。
- **项目栏固定位置**：位于备注行右侧（固定宽 17rem）；作用域为「仅全局」时不参与落库，置灰不编辑；选中项目的项目根会写回**路径输入**（保存与作用域预检统一读路径，单一数据源）。
- **Header 元素定宽**：类型徽标 1.75rem / 驱动 11rem / 项目 17rem / 作用域分段短标签——切换数据库类型时后续元素位置不移动。

### 2.1 作用域（全局 / 项目 / 全局+项目，三态单选 —— 对齐后端双轨设计）

| 选择 | 落库语义 |
| --- | --- |
| 仅 全局 | 保存至 `global.db` 的 `global_connections`（`G_xxx`） |
| 仅 项目 | 保存至当前项目 `project.db` 的 `connections`（`P_xxx`） |
| 全局 + 项目 | 保存为全局（`G_xxx`）**并共享至当前项目**（`GP_xxx` 快照引用）——连接同属两作用域 |

- 依据：v1 双轨制（`convert_to_global_connection` / `convert_to_project_connection`，v2 `workbench/services/connection_service.rs:1426/1516`）+ ID 前缀 `G_/P_/GP_`（engine `id_prefix.rs`）；规则：项目可引用全局（快照 GP_），全局不可引用项目私有配置
- UI 为**三态单选**（全局 / 项目 / 全局+项目），选中项即落库目标；**不再有行内落点提示行**（信息冗余；落点由选中态与常规 Tab 信息条表达）

### 2.2 暂存列表与多连接连续编辑（参考 v1 v5 §8）

侧栏上半区为「暂存列表」（`saved-section`），用于在**同一个对话框内连续编辑多个连接**（DataGrip「数据源和驱动程序」式交互）：

| 条目类型 | 来源 | 行为 |
| --- | --- | --- |
| **未保存草稿（Draft）** | 新建时自动生成（默认名「新建数据源」） | 可切换续编、删除；保存成功后**移出暂存区**（已落库） |

> **暂存区只放未保存草稿**（用户决策）：库里已保存的连接**不再并入**暂存列表，它们统一从导航栏进入编辑（✎ 入口）与删除。保存成功后的提示为「已保存：…（编辑请从导航栏进入；暂存区只保留未保存草稿）」。若历史草稿表里残留过已保存条目，打开对话框时会被清理。

- 条目结构（v1 v5 `saved-item`）：类型徽标（缩小的数据库类型 UI：类型 emoji，如 🐬；无类型时回退状态点）+ `item-name`（名称）；选中项高亮（`sidebar.accent` + coral 左边条）；未保存草稿右侧有条目 `✕`（删除草稿）。
- 当前条目有未写回修改时名称后显示**脏标记 `●`**（warning 色）；最左侧为缩小的数据库类型 UI（类型 emoji；无类型时回退状态点）。
- 标题行按钮：当前仅 `+ 添加`（追加空草稿）；C4 的 `导出` / `导入` 能力已就绪但**UI 入口按决策暂缓**（避免当前阶段界面变动）。
- 快照字段（与表单一致）：类型 / 驱动（`type_id` + `driver_id` + 实现短名）、URL、凭据、作用域与项目路径、SSL、驱动属性、策略覆盖、三类引用，以及**标签文本与已勾选分组 id**（保存时同步 `connection_tags` / `connection_group_members`）。
- 交互规则：
  1. 点击条目 → 先把当前表单状态写回该条目，再载入目标条目（各 Tab 字段 / SSL / 引用 / 作用域 / 驱动属性**全部按条目隔离**）；
  2. 标题「暂存列表 [+ 添加]」→ 追加空草稿并选中；
  3. 删除草稿；**删除到最后一条自动补一个空草稿**（v1 v5 行为，保证列表恒非空）；
  4. 保存成功 → 该草稿**移出暂存区**（已落库，从导航栏编辑）并自动追加一个空草稿，保持可连续新建；
  5. 关闭对话框不丢失草稿；**草稿跨会话持久化**（global.db `connection_drafts` 表，**无密码列**），应用重启后首次打开自动恢复；
  6. 快捷键（焦点在对话框内）：`Ctrl+Enter` 保存、`Ctrl+T` 测试连接、`↑/↓` 切换条目（焦点在输入框内时 ↑↓ 仍为光标移动）；
  7. footer 同时提供「保存」与「保存并关闭」：前者保持对话框开启（连续编辑），后者保存成功后关闭。
- 与作用域的关系：草稿仅在保存时落库（G_/P_/GP_ 语义不变）；已保存条目的来源短码在对话框内仅供辨识（导航栏展示归 database-nav）。
- 实现约束：草稿为**状态快照**（新增 / 编辑共用同一套字段；与 `load_for_edit` 的回读语义对齐），列表状态存 `ConnectionDialogState`（对话框层关闭不销毁，故草稿天然保留）。

## 3. 五 Tab 内容（对照 v5 原型）

### 3.1 常规（tab-general）—— 单列分组大纲（**按驱动动态渲染**）

> 布局语言（真机反馈后定稿）：**放弃并排卡片**。原因：卡片靠 `flex_wrap + min_w` 均分宽度，对话框一窄就换行（
> 4 张卡会排成 3+1 两行）、卡高不齐；卡内只剩 ~236px，长值（路径 / URI）被挤；最要命的是
> **卡片底与输入框底同为 `background`（白）+ 极浅边框 → 输入框“几乎看不见”**。
> 单列大纲只有一列宽度，顺序即填写顺序，不会出现换行 / 遮挡 / 挤压。

```
info-banner（类型 · 驱动短名 · 特性）        ← 常驻，不参与折叠
╭─ ▾ 连接设置 ──────────────────────╮   ← 面板（group_box 浅底 + 圆角）
│  主机|地址   [ 数据框 / 输入框 ]      │   ← form_row：标签 4.25rem + 控件弹性
│  提示行（弱化小字，缩进对齐控件列）      │   ← hint_line
╰───────────────────────────────╯
╭─ ▾ 数据库认证（仅网络型） ───────────╮
╭─ ▾ 连接安全（SSL/TLS）（按声明） ──────╮
╭─ ▾ 组织（标签 / 分组）（固定最后） ──────╮
```

- **分组集合随驱动变化**（只渲染有意义的组，不出现空壳）：

| 驱动类型 | 分组（自上而下） | 说明 |
| --- | --- | --- |
| **网络型**（MySQL / PostgreSQL…） | 连接设置 · 数据库认证 · 连接安全 · 组织 | 连接设置 = 主机 / 端口 / 数据库**可编辑字段**（与 Header URI 双向同步：改字段重建 URI（保留凭据与查询串）；保存以 URI 为权威）；SSL 组仅驱动声明 `ssl` 时出现 |
| **文件型**（SQLite / DuckDB） | 连接设置 · 组织 | 连接设置 = `地址` 输入 + `打开文件…` / `新建文件…` |

- **行样式**：标签列定宽 `4.25rem`（68px，贴近控件）+ 控件占满剩余宽度；连接设置三字段是**可编辑输入框**（白底 + `input` 边框，放在面板浅底上对比清晰）。
- **字段 ⇄ URI 双向同步**（网络型）：
  - 改 Header URI（或编辑回读 / 切驱动）→ 解析出主机 / 端口 / 数据库回填字段；
  - 改任一字段 → 用 `rewrite_url_authority` 重建 URI（保留用户名密码与查询串；端口空 → 驱动默认端口；数据库空 → 去掉路径段；主机空 → 不重建，避免非法 URL）；
  - **保存以 URI 为权威**（引擎按 URL 解析出 host/port/database 写入库列）；
  - 两个方向靠“上次同步标记（驱动 id, URI）”互相让路，不会循环改写。
- **分组容器**：每个分组是一块**整幅面板**（`group_box` 浅底 + 8px 圆角 + 内边距），标题行下方一条分隔线；分组之间留 8–10px 空隙 → 连接设置 / 数据库认证 / 连接安全 / 组织 逐个可辨（真机反馈：否则区域分辨不清）。
- **未选类型 / 驱动**：表单**正常渲染但整体置灰不可输入**（Input / Select / Checkbox / 按钮统一禁用；SSL 分组也以禁用形态出现）——避免“能打字但存不了”的无效输入。
- **文件选择器**（真机反馈两次修正）：`打开文件…` = 系统**打开**对话框（Windows 带 `FOS_FILEMUSTEXIST`，**只能选已存在的文件**）→ 引用该文件；`新建文件…` = 系统**保存**对话框（`prompt_for_new_path`，默认名按驱动给 `new_database.db` / `new_database.duckdb`）→ 路径不存在则创建**空**库文件并写回地址，**路径已存在则不创建、不引用、不动原文件**（提示换名或用 `打开文件…`）——两个入口职责互斥；取消 / 失败 / 无响应都会写结果行（不再静默，否则看着像按钮没反应）。
- **折叠**：分组标题行即折叠手柄（chevron 方向）；**默认全展开**；折叠态只是 UI 偏好（进程内保存，不落库）。
- **字段集合是「驱动 schema × 连接方式」的函数**（为将来的服务型 / HTTP / NoSQL 留口）：
  - 行的**存在性**：看 `drivers.config_schema.fields[].key` 是否声明（如某驱动无 `database` 字段则不出该行）；
  - 行的**标签**：网络型摘要行（host / port / database）取 schema 声明（不再写死「主机 / 端口 / 数据库」）；
    **地址行标签固定为「地址 / URI」**（按用户明确要求，不被 schema 的「数据库文件」类标签覆盖）；
  - 行的**占位**：文件型地址行优先取 schema 声明的文件字段 `placeholder`（如「选择 .db 或 .sqlite 文件」），未声明时回退类型字典；网络型取驱动 `url_template`；
  - schema 为空（旧目录 / 插件未声明）→ 回退内置字段（网络型三行 / 文件型地址行），保证界面不空；
  - 尚未映射的 schema 字段（多主机、服务地址、token 等）暂不渲染，待驱动插件阶段扩展字段类型与 URL 组装策略（见 §7 开放问题）。
- **连接设置（文件型）**：`地址` 行 = 本地文件路径输入 + `打开文件…`（系统选择器）/ `新建文件…`（创建空库文件；已存在文件不会被引用，见上）；提示行说明「首次连接自动初始化结构」。
- **数据库认证**（仅网络型；含**管理**入口，打开 AuthConfigManager 覆盖层）：
  - **认证方法** select：选项来自当前驱动的 `supported_auth_types`（数据源：`drivers` 表）；
    驱动未声明 → 禁用占位「驱动未声明认证方法」；引用档案时只读并显示档案声明的方法
  - 用户名 / 密码标签优先取 schema 声明（`username` / `password`），未声明时回退中文标签
  - **引用已保存认证配置**下拉（选中后字段只读 disabled + 降透明）
- **连接安全（SSL/TLS）**（仅网络型且驱动声明 `ssl`）：模式（disable/prefer/require/verify-ca/verify-full）、CA 证书、客户端证书/私钥。
- **组织（标签 / 分组）**（所有类型都有，固定最后）：
  - 标签：逗号分隔输入（`prod, core`）→ 保存时写 `tags` + 同步 `connection_tags`；
  - 分组：项目分组多选（`Checkbox`，多对多）；未打开项目时提示「打开项目后可用」，本项目无分组时提示「暂无分组」
- **布局稳定**：Tab 内容区固定高度（20.5rem）+ 超出滚动 —— 切换 Tab / 折叠分组不改变对话框高度，侧栏与 Header 不抽动
- **落库卫生**：文件型连接不写凭据 / 认证引用 / 网络链 / SSL（表单从上个类型残留的值一律清洗，见 `strip_file_db_noise`）。

### 3.2 网络（tab-network）

> 修订（2026-09-12，审计 #25）：**内联协议链已撤下**——它只有「类型 + 标签」占位、无任何主机与凭据字段，无法执行，反而造成“配了就该生效”的假象；同样能力（含多跳）由类型 `chain` 的网络档案完整提供。以下为当前实现。

- 引用条：**引用网络档案**（下拉，选档案即生效）+ **管理**入口（NetworkConfigManager 覆盖层）
- 诚实提示：未引用时显示「未引用档案时直连；SSH 跳板 / 代理 / 多跳（chain）请在「管理」里建档案后在此引用」；已引用时显示「连接时生效（改档案一处全量生效）」
- **数据路径预览**：`本机客户端 → 档案名（或直连）→ 目标数据库（TLS 徽标）`；SSL 细节在「常规 → 连接安全」
- 档案类型与权限：`ssh` / `proxy` / `socks5` / `ssl` 用**结构化字段表单**（必填 / 端口 / 布尔 / SSH 凭据二选一均拦截）；`chain` 填 `ChainHop` JSON 数组（多跳，连接时逐跳执行）

### 3.3 能力（tab-capabilities）
- 从 `drivers.capabilities` JSON 解析（数据源：驱动表；UI 只做「能力键 → 中文标签」字典映射），声明与未声明均列 chip（未声明置灰）；字典外的键原样展示不丢信息；未选驱动时提示选型。

### 3.4 驱动属性（tab-properties）
- `driver_properties` key-value 行，支持动态增删（高级用户）

### 3.5 高级（tab-advanced）—— 与常规同一套单列分组大纲
- 分组：**环境** → **安全策略（覆盖环境默认）** → **DuckDB 本地加速**（仅网络型可见，warning 色标题）
- **环境**：下拉 + `管理环境` 入口（EnvironmentManager 覆盖层）+ 策略生效摘要行
- **安全策略**：勾选项 = 当前环境的**启用策略**（数据源 `environment_policies`，切环境自动重查）；行内展示库里的配置摘要（如 `readonly=true · rowLimit=1000`）；勾选即“覆盖该策略”并标记「已覆盖」，落库 `advanced_options.policy_overrides`（值为 `policy_type`）；未选环境 → 无项可覆盖并给出提示（不造默认值）
- **DuckDB 本地加速**：`启用` 开关行 + 开启时展开 `缓存路径` 行与说明（warning 色标题提高权重）
- 与常规 Tab 共用 `outline_section` / `form_row` / `hint_line`（同一套排版语言，避免一个对话框里出现两套视觉）

### 3.6 凭证 / 网络 / 环境的管理与引用（复用机制）
| 类型 | 引用（连接内） | 管理（覆盖层，v1 弹出窗） | 复用语义 |
| --- | --- | --- | --- |
| 认证配置 | 常规→数据库认证、网络→SSH/Proxy 认证：下拉引用已保存配置，选中后字段只读 | AuthConfigManager：类型列表（`password` / `ldap` / `pg_class` / `kerberos` / `ssh_key` / `proxy_pwd`）+ 新建/编辑/删除；**按类型展开结构化字段**（键与后端读取端一致，含驼峰 `keyPath` / `certPath`）；列表**真脱敏**（只显示名称与类型）+ 显示**被引用计数** | 数据库 A 直接引用数据库 B 的认证配置（共用同一份凭据），修改一处全量生效；被引用的配置不可删除 |
| 网络配置 | 网络 Tab：下拉引用已保存网络档案（**无内联编辑**） | NetworkConfigManager：按类型展开字段（ssh / proxy / socks / ssl）或 `chain` JSON（多跳）+ CRUD；`config` 内的 `password` / `passphrase` **加密落库**（`AES:` 前缀），列表脱敏（不回显 config） | 建一次网络档案，多连接复用；连接时解析并应用（含隧道）；库文件被复制也不会泄露跳板机凭据 |
| 环境 | 高级 Tab：下拉选择环境 + 策略摘要 | EnvironmentManager：环境 CRUD + 策略编辑；显示**被使用计数** | 环境（5 类策略）共享；单连接可覆盖策略并标记"已覆盖" |

> **实现状态（2026-09-12，A2）**：三种管理器的列表均已显示**被引用计数**，删除被引用的配置会被拦下（消息含引用数与范围）；引用的档案被删 / 类型未知时，**连接与测试连接都会报错**而不是静默直连（两个入口共用同一套严格模式）。计数范围：全局库全部连接 + 当前打开项目的 P_/GP_（未打开项目的引用不可见，见架构 §14 #33）。

## 4. 关键交互

| 交互 | 行为 |
| --- | --- |
| 类型树 | **不折叠**（实现为四个分类小节，均占满侧栏剩余高度并内部滚动）：分类行 = `名称（数量）`，条目行 = 选中指示条 + 类型 emoji + 名称；搜索框过滤类型名 / 类型 id / 驱动名（命中驱动也保留该类型）；选中类型 → 右侧驱动下拉仅列该类型**启用驱动**（实现短名，如 `sqlx` / `Official`）并默认选中第一个；未选类型时驱动位保留**禁用下拉占位**（placeholder「先选类型」）；条目类型徽标取类型 `icon`（emoji） |
| 作用域 | **三态单选**：仅全局→`G_xxx`；仅项目→`P_xxx`；全局+项目→保存全局并共享至当前项目（`GP_xxx` 快照）；Header 用**分段按钮**（短标签 全局 / 项目 / 全局+项目，写库仍用全称标签）；**不再有行内落点提示行**（落点由选中态与常规 Tab 信息条表达） |
| 项目 | **单下拉**（项目名 + 路径左右结构）；尾部三个动作：**「不需要项目（仅全局）」**（切作用域，不留无效空态）、**「打开现有目录…」**、**末项「＋ 新增项目」**；作用域「仅全局」时禁用占位；选中项目 → 项目根写回路径输入；新增/打开动作 → 宿主开对应入口，**编辑区有未保存草稿时先走确认，确认后直接打开目标对话框**（#4：不再要求回选择器重新点一次）；对话框打开期间项目会话变更 → 本栏自动跟随 |
| URI / 地址 | **网络型**：Header 内自绘**可编辑输入框**（直接改文本；无「✎ 编辑 / 完成」两态）；占位随驱动 `url_template` 变化。**文件型**：Header 只显示当前路径（截断）或引导文案，可编辑输入框与文件选择按钮在「常规 → 连接设置」；系统选择器取消时保持原值 |
| 测试连接 | 独立会话（不注册连接池、不落库），返回 `{success, message, latency_ms, version}`；成功 → 绿色 ✓ + 版本 + 延迟；失败 → 红色错误**摘要**（长错误行尾带 `详情` / `复制`，见下行）。**与真实连接同源**（A1）：按同规则注入认证档案凭据、**真实建立网络档案隧道**（测完即关）；档案缺失 / 隧道建不起来 → 直接失败（不静默降级） |
| 结果行（保存 / 测试 / 同步 / 驱动属性 / 暂存来源） | **分级不看文案看级别**（`ResultLevel`，由唯一写入口 `set_result` / `set_result_ok` 给出）：成功 = `success` 绿；警告 = `warning` 黄（当前生产路径：保存成功但分组未落库 → 「已保存：…（分组未同步：原因）」）；错误 = `danger` 红；进行中 / 普通提示 = 弱灰（如「测试中…」）。**摘要恒占一行**；内容 **> 80 字（按字符计）或含换行** 时行尾出现 `详情`（展开完整原文，正文区高度上限 6rem 内部滚动，按钮变 `收起`）与 `复制`（整段原文进剪贴板）。短消息不出现这两个入口；UI 不截断也不改写服务层原文（#28） |
| 保存 | 校验 → 落库（ID 前缀按作用域 G_/P_/GP_）→ `use_duckdb_fed=1` 时注册 DuckDB Secret → 刷新列表；**保存后不关闭对话框**（草稿转正式 + 自动补空草稿）；「保存并关闭」则在成功后关闭 |
| 暂存列表 | **只放未保存草稿**（详见 §2.2）：条目切换 / 新增 / 删除（删至最后一条自动补位）；保存后草稿移出暂存区并自动补空草稿；关闭不丢失且**跨会话持久化**（`connection_drafts`，无密码列）；当前条目有改动时显示脏标记 `●`；已保存连接从导航栏编辑 |
| 模板导入导出 | 暂存列表标题行 `导出 / 导入`：剪贴板 JSON（`kind`/`version` 校验），**不含密码**；导出仅未保存且非空草稿；导入追加并选中（提示补填密码）——**能力已就绪，UI 入口按决策暂缓**（原型图中不展示）|
| 项目快照同步 | 编辑「全局+项目」快照（GP_）时 footer 出现 `从全局定义同步`：拉取全局侧最新配置与凭据密文到本项目快照（保留快照 ID / 创建时间 / 分组关系）；其他作用域不显示该按钮 |
| Tab 条 / 分段控件 / 开关（组件化） | 均用 gpui-kit 0.6.1 组件（#15）：Tab 条 = `TabBar::underline()`（下划线指示条 2px `primary`；文字 `tab.foreground` / 选中 `tab.active.foreground`；Small 尺寸档）；作用域三态 = `TabBar::segmented()`（浅底组 + 白色胶囊活动项，XSmall 档；短标签只用于显示，写库仍用全称）；开关 = `Switch`（Small；开启色 `primary`，未选驱动时置灰不可点）；尺寸与颜色由组件尺寸档 + 主题 token 决定（`switch.background` / `tab_bar.segmented.background` 未在 RDS 主题声明时回退组件默认值） |
| 首次引导（空态） | 常规 Tab 顶部引导条：仅在“**未选类型 + 名称/地址都空**”时出现——五步流程（选类型 → 选驱动 → 填连接信息 → `Ctrl+T` 测试 → `Ctrl+Enter` 保存）+ 「草稿不丢」说明；选完类型自动消失（不占老手版面）；不引外链 |
| 类型不可用 | 无可用驱动的类型：置灰 + 「暂无驱动」+ 点击不切换（结果行给原因）；未选类型时驱动位为禁用占位 |
| 认证配置选择 | 按 auth_type 过滤已保存配置；选中后动态字段只读；**管理**按钮打开 AuthConfigManager |
| 网络/环境引用 | 网络 Tab「引用网络配置」+「管理网络配置」；高级 Tab「管理环境」——均打开对应覆盖层 |

## 7. 开放问题

本文件只描述**目标形态（作为实现基准）**；当前实现与目标之间的差距、以及已知缺陷，统一记录在
`connection-dialog-architecture.md` §14「已知问题与后续项」——那里是**权威待办清单**（分级：🔴 阻断 / 🟡 语义与体验 / ⚪ 工程与文档债）。

本轮（2026-09-12）已确认并关闭的原待确认项：

1. ~~作用域同属~~ → 作用域为**三态单选**（全局 / 项目 / 全局+项目），落库语义与前一致（G_ / P_ / GP_）。
2. **SSL 移常规**（网络 Tab 仅档案引用）—— 已按此实现（内联链已撤下，见 §3.2 修订）。
3. **管理与引用**（认证 / 网络 / 环境三类：引用 + 管理覆盖层）—— 已按此实现。
4. 入口形态（活动栏 / 导航树 / 空态按钮 → 模态对话框）—— 已按此实现。
5. ~~项目栏两态~~ → 项目栏为**单下拉**（项目名 + 路径，末项「+ 新增项目」）。
6. ~~Header 落点提示行~~ → 已删除（落点由作用域选中态与常规 Tab 信息条表达）。

     ③ `config_schema.options[]`（驱动可选参数，如 sqlite `mode`）目前未渲染，计划入「驱动属性」Tab。
