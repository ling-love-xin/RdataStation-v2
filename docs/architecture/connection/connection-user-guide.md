# 数据源连接模块 · 使用指南（M3）

> 读者：产品 / 测试（USIT）/ 新加入的开发者。设计原理见 `connection-dialog-architecture.md`；
> 视觉与交互原型见 `connection-prototype-design.md`；任务与轮次记录见 `connection-dev-plan.md`。

---

## 1. 这个模块能做什么

管理**数据源连接**本身：新建 / 编辑 / 测试 / 删除连接，配置作用域（全局 / 项目）、标签、分组、
SSL 与协议链（SSH / 代理）、认证与环境引用、DuckDB 本地加速。

不在本模块内：数据库导航树、表数据浏览、分组/标签的**视图消费**（那是 database-nav 模块）。
本模块只负责"连接的定义与组织元数据的写入"，导航模块负责"按分组/标签展示与检索"。

## 2. 入口

| 入口 | 位置 | 行为 |
| --- | --- | --- |
| 新建数据源 | 编辑区数据库面板「新建数据源」按钮（空态 / 列表态均有） | 打开新建对话框 |
| 编辑连接 | 数据库导航栏连接行 ✎ | 打开对话框并回读该连接全部字段 |
| 连续新建 | 对话框内「暂存列表 → + 添加」 | 在同一对话框内编辑下一条连接 |

> 打开 / 关闭对话框后宿主会显式重绘（`Shared::notify_host`）；若发现点入口无反应，
> 见 §8 排查。

## 3. 界面导览

```
┌─ 标题栏：新建/编辑数据源连接 ─────────────────────────────────────┐
│ 左栏（200px，高度恒定）        │ 主区（Header 3 行，建议布局）        │
│  搜索类型                     │  ① 类型徽标(仅图标) · 名称(弹性) · 作用域分段
│  暂存列表（+ 添加）            │  ② 备注(弹性) + 项目(定宽，仅全局灰显；  │
│    [固定高度，超出滚动]         │       单下拉：项目名 + 路径，末项新增项目)  │
│    类型徽标 + 名称 ●/P/G/GP    │  ③ 驱动(定宽) · URI(弹性)            │
│  数据库类型树                  │  Tab 条：常规/网络/能力/驱动属性/高级 │
│    [占满剩余，超出滚动]         │  Tab 内容（固定高度，超出滚动）       │
│                               │  结果提示行                         │
├──────────────────────────────────────────────────────────────────┤
│ 底栏： [测试连接]  [取消]  [保存]  [保存并关闭]                    │
└──────────────────────────────────────────────────────────────────┘
```

> Header 只保留**需要操作的三类信息**：身份（类型徽标 + 名称）、落点（作用域 + 项目）、连接串（驱动 + URI）与备注；
> 类型徽标常驻行首便于一眼识别当前数据库类型，类型未辨识时徽标与驱动位置同步给出提示。

> 左右两侧均为**区域固定 + 内部滚动**：条目 / 类型 / Tab 内容再多也不会拉长对话框（保证操作时视线不跑位）。

**关键分工：类型在左，驱动在右。**

- 左栏选中**数据库类型**（MySQL / PostgreSQL / SQLite / DuckDB…），类型行首是类型图标（emoji）。
- 右栏「驱动」只列**当前类型的驱动实现**，显示实现短名：`sqlx`、`Official`、`rusqlite`、`duckdb-rs`。
- 未选（或无法辨识）类型时，驱动位置**直接显示提示文本**（不再渲染空下拉）：`请先在左侧选择数据库类型`。

**项目栏（落点）**：

- 作用域为 `仅全局` 时项目栏**禁用**（placeholder「仅全局不需要」），三态切换不会引起布局跳动。
- 其余作用域下为一个**下拉框**：每一行是「**项目名**（左）+ **路径**（右，弱化、超长从头部省略）」；点开可搜项目名或路径。
- 末项固定为 **`＋ 新增项目`**：选中后弹出「新建项目」对话框（有未保存草稿时先走未保存确认），创建成功后新项目成为当前会话，本项目栏自动跟随。
- 选中项目的**项目根会写回路径输入**（保存 / 作用域预检读的就是它）；项目栏不再提供手输路径。

**暂存列表条目**（`saved-section`）：

| 元素 | 含义 |
| --- | --- |
| 最左类型图标 | 该条目所属数据库类型（缩小的类型 UI）；无类型信息时显示状态点 |
| 名称后 `●` | 当前条目有未写回的修改（关闭 / 切换会自动写回） |
| 名称后 `P` / `G` / `GP` | 已保存条目的作用域来源（仅项目 / 仅全局 / 全局+项目快照） |
| `✕` | 删除草稿（已保存条目不可在此删除，删除入口在导航栏） |

> 暂存区**固定高度**（约 4 条可见），条目更多时在该区域内滚动；标题行「+ 添加」始终可见。
> 模板导入导出（C4）能力已实现、**UI 入口按决策暂缓**（避免当前阶段界面变动）。

## 4. 典型流程

### 4.1 新建连接（4 步）

1. **选类型**：左栏点数据库类型（如 MySQL）→ 右侧驱动自动选中该类型第一个实现。
2. **选驱动 + 填名称 / URI**：驱动可换（如 `sqlx` ⇄ `Official`）；名称为连接显示名。
3. **选作用域与项目**：分段按钮
   - `仅全局`：写入 `global.db`，所有项目可见（ID `G_…`）；
   - `仅项目`：写入当前项目 `.RSMETA/project.db`（ID `P_…`），需已打开项目；
   - `全局+项目`：全局定义 + 项目快照引用（ID `GP_…`），需已打开项目。
   - 需项目侧时，用**项目下拉**选项目（默认已选中当前打开的项目；末项 `＋ 新增项目` 可新建）。
4. **测试 → 保存**：`测试连接` 独立会话验证（不改动库）；`保存` 落库且**不关闭**对话框
   （草稿转为已保存 + 自动补一条空草稿）；`保存并关闭` 成功后关闭。

### 4.2 编辑已有连接

导航栏连接行 ✎ → 对话框打开并回读全部字段（含协议链 / SSL / 策略覆盖 / 标签 / 分组）。
保存走 `update`（按 ID 前缀 G_/P_/GP_ 路由）。

### 4.3 连续配置多个连接

1. 「+ 添加」追加空草稿并选中；
2. 填完保存 → 当前条目变"已保存"，自动补新空草稿；
3. 重复即可；关闭对话框不丢草稿，**重启应用后再次打开对话框仍会恢复**（密码不落盘）。

### 4.4 标签与分组（常规 Tab「组织」卡片）

- **标签**：逗号分隔（如 `prod, core`），保存时写入连接 `tags` 并同步 `connection_tags` 检索表。
- **分组**：项目级勾选（一个连接可属多个分组），保存时以**当前勾选为准**替换成员关系；
  未打开项目时该区域提示「打开项目后可用」。
- 分组/标签的**新建与管理**在数据库导航模块（本模块只做连接侧的绑定）。

### 4.5 模板导入导出（C4，能力已就绪，UI 入口暂缓）

> 当前界面**未展示**导入 / 导出按钮（避免 UI 变动）；能力与测试已就绪（`ConnectionTemplate` /
> `templates_export` / `templates_import` + `connection_template.rs` 2 项），后期只需在暂存列表
> 标题行接上两个按钮（走剪贴板 JSON）。以下为届时行为：

暂存列表标题行的 `导出` / `导入` 通过**剪贴板**交换 JSON（无需文件对话框）：

| 操作 | 行为 |
| --- | --- |
| 导出 | 把暂存列表中**未保存且非空**的草稿序列化为模板 JSON 并写入剪贴板；结果行提示条数 |
| 导入 | 读取剪贴板 JSON，解析后**追加**到暂存列表（选中第一条导入项，光标落位）并提示「密码请补填」 |
| 导入校验 | `kind` 必须为 `rds.connection.template`；`version` 不高于当前（1）；列表非空 |

模板内容：名称 / 数据库类型 / 驱动 id / URL / 用户名 / 备注 / 作用域与项目路径 / SSL 模式 / 标签 / 联邦开关。
**不含密码**（也不含分组与协议链内联值）—— 导入后需人工补填凭据，写入前可用「测试连接」验证。

## 5. Tab 内容速览

| Tab | 内容 | 备注 |
| --- | --- | --- |
| 常规 | 信息条 + 连接设置（只读摘要）/ 数据库认证 / 连接安全（SSL）/ 组织（标签·分组）四张卡片 | 文件型库隐藏网络 Tab |
| 网络 | 协议链（SSH / 代理，≤4 跳，上移 / 下移 / 启用 / 删除）+ 拓扑预览 | 可引用「网络配置」档案（选中后字段只读） |
| 能力 | 驱动 capabilities 只读矩阵 | 由 `drivers.capabilities` 提供 |
| 驱动属性 | key-value 动态增删 | 落库 `driver_properties` |
| 高级 | 环境引用 + 安全策略覆盖 + DuckDB 本地加速（仅网络型库） | 加速开启后注册 DuckDB PERSISTENT SECRET |

## 7. 草稿与数据安全

| 项 | 说明 |
| --- | --- |
| 草稿归属 | 挂在对话框状态上（同一进程内关闭重开不丢）；同时写入 `global.db` 的 `connection_drafts` |
| 恢复时机 | 每次**打开对话框**时：仅当列表仍是初始单空草稿才用库中内容替换（不覆盖本次会话已编辑内容） |
| 密码 | **不写入草稿表**（无 password 列），恢复后密码框为空 |
| 模板（导出） | JSON **不含密码**（仅名称 / 类型 / 驱动 / URL / 用户名 / 备注 / 作用域 / SSL / 标签） |
| 落库凭据 | 正式保存时由 `auth_store`（AES-256-GCM）加密；DuckDB Secret 目录为应用数据目录（不写用户主目录） |
| 写失败 | 草稿持久化 / 标签 / 分组同步失败只记日志，不阻断连接保存 |

## 8. 常见问题与排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 驱动下拉为空 | 未选数据库类型：先在左栏点类型；或该类型下驱动被禁用（`drivers.enabled=0`） |
| 提示「未选择数据库类型」 | 同上；旧草稿只有驱动完整名时可自动回退解析，解析不到需手动选类型 |
| `仅项目` / `全局+项目` 保存报错 | 未打开项目：先打开项目，或把作用域改为 `仅全局`；也检查项目下拉是否选中了项目（项目根会写回路径输入） |
| 测试连接失败 | 看结果行错误信息；确认主机 / 端口 / 凭据 / 协议链（网络 Tab）与 SSL 模式 |
| 项目下拉里没有我要的项目 | 下拉列当前项目 + 最近项目；未列出的项目删过 / 未在本机打开过——用末项 `＋ 新增项目` 新建，或在标题栏项目菜单切换后再打开本对话框 |
| 点 `＋ 新增项目` 后弹出未保存确认 | 当前项目编辑区有未保存草稿：先完成确认（不静默丢弃），随后从项目选择器新建项目 |
| 分组区域显示「打开项目后可用」 | 分组是项目级数据（`project.db`），需打开项目 |
| 分组列表为空 | 该项目下尚无分组：分组新建在数据库导航模块 |
| 导入提示「模板解析失败」/「kind 不匹配」 | 剪贴板内容不是本应用导出的模板 JSON：先用 `导出` 复制一份模板对照格式 |
| 导入提示「模板版本过新」 | 模板由更新版本的应用导出，需升级应用 |
| 导出的 JSON 里没有我保存的连接 | 导出仅包含**未保存草稿**（已保存连接请从导航栏用 ✎ 打开后另存为草稿再导出） |
| 保存后列表没变化 | 列表刷新由服务侧触发；若界面未更新，请复现并附 `target/rds-app.err.log` |
| 编辑项目连接（P_/GP_）后表单为空 | 已修：编辑回读改走 `get_with_project`（带项目根）。若仍为空，确认该连接属于当前打开的项目；反之确认项目库文件未被外部删除 |
| 应用启动即退（0xc000041d） | 历史问题：Windows 主线程栈溢出，已由大栈线程修复（参 dev-plan ㉑）；若复现请附日志 |
| 对话框点入口无反应 | 历史问题：宿主重绘缺失（参 dev-plan ㉑）；请确认使用最新构建 |

## 9. USIT 验收清单（可勾选）

**A. 基础闭环**

- [ ] 新建 SQLite 连接：选类型 → 选驱动 → 填名称/URI → 测试 → 保存 → 列表出现该连接
- [ ] 导航栏 ✎ 编辑该连接：全部字段正确回读（类型 / 驱动短名 / URI / 作用域）
- [ ] 修改驱动（`rusqlite` → 其它）并保存：库中 `db_type` / `driver_id` 为新驱动 id

**B. 类型 × 驱动**

- [ ] 左栏点 MySQL：驱动下拉只有 `sqlx` / `Official`（无 `MySQL` 前缀）；点 PostgreSQL：只有 `sqlx`
- [ ] 未选类型时：驱动下拉为空 + Header 显示「请先在左侧选择数据库类型」
- [ ] 暂存条目最左侧显示类型图标；无类型草稿显示状态点

**C. 暂存与持久化**

- [ ] 「+ 添加」后编辑第二条：切换条目字段互不串
- [ ] 保存第一条 → 条目变已保存（带 `G`/`P`/`GP` 短码）+ 自动补空草稿
- [ ] 关闭应用后重开 → 打开对话框草稿恢复，且密码框为空
- [ ] 当前条目有改动时名称后出现 `●`

**D. 作用域与项目**

- [ ] 未打开项目时 `仅项目` 保存被拦截并提示
- [ ] 打开项目后保存 `仅项目`：导航栏出现该连接（P_ 前缀）
- [ ] Header 作用域分段按钮三态切换，提示行文案同步变化
- [ ] 已打开项目时项目下拉默认选中当前项目，右侧列显示项目路径（超长从头部省略）
- [ ] 项目下拉末项 `＋ 新增项目` → 弹出「新建项目」；创建后本栏自动选中新项目
- [ ] 编辑项目连接（P_/GP_）：字段全量回读（含标签与分组勾选），作用域仍是「仅项目 / 全局+项目」

**E. 标签与分组**

- [ ] 常规 Tab「组织」卡片填写 `prod, core` → 保存 → 重新编辑该连接可见标签回显
- [ ] 打开项目并勾选分组 → 保存 → 重新编辑勾选保持
- [ ] 取消全部勾选 → 保存 → 重新编辑无勾选

**F. 布局与交互**

- [ ] 逐个切换五个 Tab：对话框高度不变化，侧栏与 Header 不跳动（内容多的 Tab 内部滚动）
- [ ] `Ctrl+Enter` 保存、`Ctrl+T` 测试、`↑/↓` 切换条目、`Esc` 关闭
- [ ] 明暗主题切换：对话框各区域颜色正确（无裸色值残留）

**G. 网络与安全（需要环境）**

- [ ] SSH / HTTP 代理协议链：测试连接成功且断开后无残留端口（可用 `tunnel_count` 诊断）
- [ ] 开启 DuckDB 加速：保存后 Secret 注册；关闭 / 删除连接后清理
- [ ] 连接失败路径：隧道回滚，不残留后台任务

**H. 模板导入导出**

- [ ] 填一条草稿 → `导出` → 粘贴剪贴板：JSON 含 `rds.connection.template`，**不含密码**
- [ ] 清空剪贴板并粘贴一段非法文本 → `导入` → 结果行报「模板解析失败」（列表不变）
- [ ] 用导出的 JSON → `导入` → 暂存列表追加条目、表单载入该条、密码框为空
