# 数据源连接模块 · 使用指南（M3）

> 读者：产品 / 测试（USIT）/ 新加入的开发者。设计原理见 `connection-dialog-architecture.md`；
> 视觉与交互原型见 `connection-prototype-design.md`；任务与轮次记录见 `connection-dev-plan.md`。

---

## 1. 这个模块能做什么

管理**数据源连接**本身：新建 / 编辑 / 测试 / 删除连接，配置作用域（全局 / 项目）、标签、分组、
SSL 与协议链（SSH / 代理）、认证与环境引用、DuckDB 本地加速。

不在本模块内：数据库导航树、表数据浏览、分组/标签的**视图消费**（那是 database-nav 模块）。
本模块只负责"连接的定义与组织元数据的写入"，导航模块负责"按分组/标签展示与检索"。

## 2. 入口

| 入口 | 位置 | 行为 |
| --- | --- | --- |
| 新建数据源 | 编辑区数据库面板「新建数据源」按钮（空态 / 列表态均有） | 打开新建对话框 |
| 编辑连接 | 数据库导航栏连接行 ✎ | 打开对话框并回读该连接全部字段 |
| 连续新建 | 对话框内「暂存列表 → + 添加」 | 在同一对话框内编辑下一条连接 |

> 打开 / 关闭对话框后宿主会显式重绘（`Shared::notify_host`）；若发现点入口无反应，
> 见 §8 排查。

## 3. 界面导览

```
┌─ 标题栏：新建/编辑数据源连接 ─────────────────────────────────────┐
│ 左栏（200px，高度恒定）        │ 主区（Header 3 行，建议布局）        │
│  搜索类型                     │  ① 类型徽标(仅图标) · 名称(弹性) · 作用域分段
│  暂存列表（+ 添加）            │  ② 备注(弹性) + 项目(定宽，仅全局灰显；  │
│    [固定高度，超出滚动]         │       单下拉：项目名 + 路径，末项新增项目)  │
│    类型徽标 + 名称 ●/P/G/GP    │  ③ 驱动(定宽) · 地址(弹性)            │
│  数据库类型树                  │  Tab 条：常规/网络/能力/驱动属性/高级 │
│    [占满剩余，超出滚动]         │  Tab 内容（固定高度，超出滚动）       │
│                               │  结果提示行                         │
├──────────────────────────────────────────────────────────────────┤
│ 底栏： [测试连接]  [取消]  [保存]  [保存并关闭]                    │
└──────────────────────────────────────────────────────────────────┘
```

> Header 只保留**需要操作的三类信息**：身份（类型徽标 + 名称）、落点（作用域 + 项目）、连接串（驱动 + 地址）与备注；
> 类型徽标常驻行首便于一眼识别当前数据库类型，类型未辨识时徽标与驱动位置同步给出提示。

> **地址列随驱动变形**：网络型（MySQL / PostgreSQL…）标签为 `URI`，Header 内直接编辑，占位会按当前驱动的连接模板变化（如 `mysql://user:password@localhost:3306/db`，不再是写死的 mysql 示例）；
> 文件型（SQLite / DuckDB）标签为 `地址`，Header 只显示当前文件路径（截断），**实际的地址输入与文件选择在「常规 → 连接设置」卡片里**（只保留一个地址输入框，避免两处分不清权威值）。

> 左右两侧均为**区域固定 + 内部滚动**：条目 / 类型 / Tab 内容再多也不会拉长对话框（保证操作时视线不跑位）。

> **常规 / 高级 Tab 用「单列分组大纲」**：一节一个可折叠分组（标题行 = chevron + 图标 + 标题），组内每行是「标签（定宽）+ 控件（占满剩余宽）」；只读值以纯文本展示。
> 不再用并排卡片：卡片在窗口变窄时会换行、高度参差，且输入框底色与卡底同色时几乎看不见。

**关键分工：类型在左，驱动在右。**

- 左栏选中**数据库类型**（MySQL / PostgreSQL / SQLite / DuckDB…），类型行首是类型图标（emoji）。
- 右栏「驱动」只列**当前类型的驱动实现**，显示实现短名：`sqlx`、`Official`、`rusqlite`、`duckdb-rs`。
- 未选（或无法辨识）类型时，驱动位置保留**禁用下拉占位**（placeholder「先选类型」）而不是换行裸文本。

> ⚠️ **当前只内置 4 个驱动**：MySQL（`sqlx`）、PostgreSQL（`sqlx`）、SQLite（`rusqlite`）、DuckDB（`duckdb-rs`）。
> 其余类型（MariaDB / Oracle / SQL Server / ClickHouse 等）仍然列在类型树里，但**置灰并标注「暂无驱动」**：
> 点它们不会切换类型，只会在结果行提示原因（避免“选了类型却存不了”）。驱动安装（插件）能力开放后这些类型自动可用。
> MongoDB / Redis 在类型目录里本身就是禁用状态（`enabled=0`），不会出现在类型树。

**认证方法**（常规 Tab「数据库认证」卡片）：下拉选项来自**驱动声明**（`drivers.supported_auth_types`）；
引用认证档案时该行只读并显示档案声明的方法（连接时也是用它的类型注入凭据）。

**类型树**：左侧下半区，按分类平铺（关系型 / 文件型 / 分析型 / NoSQL），分类行显示 `名称（数量）`，条目行 = 选中指示条 + 类型 emoji + 类型名（不可选的类型右侧额外显示「暂无驱动」）；**不可折叠**（超出时区域内部滚动）；上方搜索框同时过滤类型名 / 类型 id / 驱动名。

**项目栏（落点）**：

- 作用域为 `仅全局` 时项目栏**禁用**（placeholder「仅全局不需要」），三态切换不会引起布局跳动。
- 其余作用域下为一个**下拉框**：每一行是「**项目名**（左）+ **路径**（右，弱化、超长从头部省略）」；点开可搜项目名或路径。
- 尾部三个动作项（顺序固定）：
  - **`不需要项目（仅全局）`**：把作用域切为「仅全局」并清空项目（项目作用域必须有项目，不会停在无效态）；
  - **`打开现有目录…`**：选择一个不在“最近项目”里的本机项目（走项目管理的目录选择）；
  - **`＋ 新增项目`**（末项）：弹出「新建项目」；创建成功后新项目成为当前会话，本项目栏自动跟随。
- 有未保存草稿时，后两个动作会先弹未保存确认（不静默丢弃）。
- 选中项目的**项目根会写回路径输入**（保存 / 作用域预检读的就是它）；项目栏不再提供手输路径。

**暂存列表条目**（`saved-section`）：

| 元素 | 含义 |
| --- | --- |
| 最左类型图标 | 该条目所属数据库类型（缩小的类型 UI）；无类型信息时显示状态点 |
| 名称后 `●` | 当前条目有未写回的修改（关闭 / 切换会自动写回） |
| 名称后 `P` / `G` / `GP` | 已保存条目的作用域来源（仅项目 / 仅全局 / 全局+项目快照） |
| `✕` | 删除草稿（已保存条目不可在此删除，删除入口在导航栏） |

> 暂存区**固定高度**（约 4 条可见），条目更多时在该区域内滚动；标题行「+ 添加」始终可见。
> 模板导入导出（C4）能力已实现、**UI 入口按决策暂缓**（避免当前阶段界面变动）。

## 4. 典型流程

### 4.1 新建连接（4 步）

1. **选类型**：左栏点数据库类型（如 MySQL / SQLite）→ 右侧驱动自动选中该类型第一个实现。
2. **选驱动 + 填名称 / 地址**：驱动可换（如 `sqlx` ⇄ `Official`）；名称为连接显示名。
   - **网络型**：Header 第三行 `URI` 直接填写（占位会随驱动显示模板，如 `mysql://user:password@localhost:3306/db`）。
   - **文件型（SQLite / DuckDB）**：切到常规 Tab，在「连接设置」卡片的 `地址` 里填路径，或点 `打开文件…` / `新建文件…`（新建会在所选位置创建空库文件，已存在则直接引用；DuckDB 可输 `:memory:`）。
3. **选作用域与项目**：分段按钮
   - `仅全局`：写入 `global.db`，所有项目可见（ID `G_…`）；
   - `仅项目`：写入当前项目 `.RSmeta/project.db`（ID `P_…`），需已打开项目；
   - `全局+项目`：全局定义 + 项目快照引用（ID `GP_…`），需已打开项目。
   - 需项目侧时，用**项目下拉**选项目（默认已选中当前打开的项目；末项 `＋ 新增项目` 可新建）。
4. **测试 → 保存**：`测试连接` 独立会话验证（不改动库）；`保存` 落库且**不关闭**对话框
   （草稿转为已保存 + 自动补一条空草稿）；`保存并关闭` 成功后关闭。

### 4.2 编辑已有连接

导航栏连接行 ✎ → 对话框打开并回读全部字段（含协议链 / SSL / 策略覆盖 / 标签 / 分组）。
保存走 `update`（按 ID 前缀 G_/P_/GP_ 路由）。
项目侧连接（P_/GP_）的回读走 `DataSourceService::get_with_project`（带项目根）——无项目根时会得到空表单而不是报错。

**编辑时不重填密码 = 保留原密码**：密码框留空保存不会清空库中凭据（全局侧与项目侧一致）。

**认证方法与引用配置**：`认证方法` 决定连接时如何从「引用的认证档案」注入凭据。
档案未选方法时以档案自身声明的类型为准（服务层兜底），因此**引用档案不必再手选方法**。

**「全局+项目」快照的同步**：GP_ 是**独立副本**，全局定义（G_）后续修改不会自动跟随。编辑 GP_ 连接时 footer 会出现
`从全局定义同步`：点它会把全局侧的最新配置与凭据复制到本项目快照（保留快照 ID、创建时间与分组关系），
结果行提示同步完成，表单同时重载——无需再点保存。

### 4.3 连续配置多个连接

1. 「+ 添加」追加空草稿并选中；
2. 填完保存 → 当前条目变"已保存"，自动补新空草稿；
3. 重复即可；关闭对话框不丢草稿，**重启应用后再次打开对话框仍会恢复**（密码不落盘）。

### 4.4 标签与分组（常规 Tab「组织」卡片）

- **标签**：逗号分隔（如 `prod, core`），保存时写入连接 `tags` 并同步 `connection_tags` 检索表。
- **分组**：项目级勾选（一个连接可属多个分组），保存时以**当前勾选为准**替换成员关系；
  未打开项目时该区域提示「打开项目后可用」。
- 分组/标签的**新建与管理**在数据库导航模块（本模块只做连接侧的绑定）。

### 4.5 模板导入导出（C4，能力已就绪，UI 入口暂缓）

> 当前界面**未展示**导入 / 导出按钮（避免 UI 变动）；能力与测试已就绪（`ConnectionTemplate` /
> `templates_export` / `templates_import` + `connection_template.rs` 2 项），后期只需在暂存列表
> 标题行接上两个按钮（走剪贴板 JSON）。以下为届时行为：

暂存列表标题行的 `导出` / `导入` 通过**剪贴板**交换 JSON（无需文件对话框）：

| 操作 | 行为 |
| --- | --- |
| 导出 | 把暂存列表中**未保存且非空**的草稿序列化为模板 JSON 并写入剪贴板；结果行提示条数 |
| 导入 | 读取剪贴板 JSON，解析后**追加**到暂存列表（选中第一条导入项，光标落位）并提示「密码请补填」 |
| 导入校验 | `kind` 必须为 `rds.connection.template`；`version` 不高于当前（1）；列表非空 |

模板内容：名称 / 数据库类型 / 驱动 id / URL / 用户名 / 备注 / 作用域与项目路径 / SSL 模式 / 标签 / 联邦开关。
**不含密码**（也不含分组与协议链内联值）—— 导入后需人工补填凭据，写入前可用「测试连接」验证。

## 5. Tab 内容速览

| Tab | 内容 | 备注 |
| --- | --- | --- |
| 常规 | **单列分组大纲**（可折叠；组集合随驱动）：信息条（类型 · 驱动短名 · 认证方法）+ 分组 | 分组标题行可点击折叠；折叠态不落库（重新打开对话框恢复全展开） |
| 常规（网络型） | 连接设置（主机 / 端口 / 数据库，从 URI 解析的文本行）/ 数据库认证（认证方法 + 引用档案 + 用户名密码）/ 连接安全（SSL，仅驱动声明 `ssl` 时出现）/ 组织（标签·分组） | 地址编辑在 Header URI；摘要行标签取驱动 schema 声明（未声明不出该行）；地址行标签固定为 `地址` / `URI` |
| 常规（文件型） | 连接设置（**地址输入 + `打开文件…` / `新建文件…`**）+ 组织（标签·分组）—— 没有认证 / SSL 分组 | `新建文件…` 在所选位置创建空库文件（已存在则直接引用）；DuckDB 可直接输 `:memory:` |
| 网络 | **引用网络档案**（下拉）+ **管理**入口 + 诚实提示 + **数据路径预览**（本机 → 档案/直连 → 目标数据库） | 选档案即生效（连接时解析为协议链 / SSH / 代理并执行）；**内联协议链已撤下**（占位模型无法执行，多跳请用 `chain` 类型档案）。点「管理」建档案：类型 `ssh` / `proxy` / `socks5` / `ssl` 用**结构化字段表单**（必填 / 端口 / SSH 凭据会拦下），`chain` 填 `ChainHop` JSON 数组 |
| 能力 | 驱动 capabilities 只读矩阵（**来自 `drivers.capabilities`**；未声明项置灰） | 由 `drivers.capabilities` 提供；UI 只做键→中文标签映射 |
| 驱动属性 | key-value 动态增删 | 落库 `driver_properties` |
| 高级 | 同一套单列分组大纲：**环境**（下拉 + 管理入口 + 策略摘要） / **安全策略**（**勾选项来自 `environment_policies`**，切环境自动重查） / **DuckDB 本地加速**（仅网络型库） | 加速开启后注册 DuckDB PERSISTENT SECRET（缓存路径行随开启展开） |

## 7. 草稿与数据安全

### 7.1 每个字段落到哪里（写库映射）

> 回答“表单是否都有后端接口、能否写进库”：**是**。本模块无独立后端服务，所有字段经 `DataSourceService`
> → engine 持久化层写入本地库（全局 `global.db` / 项目 `.RSmeta/project.db`，凭据经 AES-256-GCM 加密）。

| UI 字段 | 落库位置（表.列） |
| --- | --- |
| 名称 / 备注 / 作用域 | `global_connections.name` / `.description` / `.is_active`（项目侧 `connections` 同名列） |
| 主机 / 端口 / 数据库 | `.host` / `.port` / `.database`（保存时由 URI 解析写入；字段编辑会同步回 URI） |
| 文件型地址（SQLite/DuckDB） | `.database`（裸路径；不写 host） |
| 用户名 / 密码 | `.username` / `.password_encrypted`（密文，空密码保留原值） |
| 认证方法 / 引用认证档案 | `.auth_method` / `.auth_config_id` |
| 引用网络配置 / 环境 | `.network_config_id` / `.environment_id` |
| SSL（模式 / CA / 证书 / 私钥） | `advanced_options.ssl`（JSON，仅驱动声明 `ssl` 时写入） |
| 策略覆盖 | `advanced_options.policy_overrides`（值为 `environment_policies.policy_type`） |
| 驱动属性 | `.driver_properties`（JSON key-value，覆盖驱动默认） |
| DuckDB 加速 / 缓存路径 | `.use_duckdb_fed` / `.metadata_path` |
| 标签 | `.tags` + `connection_tags`（检索表） |
| 分组（项目级多选） | 项目库 `connection_groups` / `connection_group_members`（替换语义） |
| 草稿（跨会话） | `connection_drafts`（**无密码列**） |
| 作用域 | ID 前缀 `G_` / `P_` / `GP_`（全局定义 / 项目独占 / 项目快照） |

校验与守卫：同名拦截、项目根预检（读写分离）、文件型输入清洗、空密码保留、时间戳兜底——详见 `connection-dialog-architecture.md` §15.4。

### 7.2 草稿不落密码

| 项 | 说明 |
| --- | --- |
| 草稿归属 | 挂在对话框状态上（同一进程内关闭重开不丢）；同时写入 `global.db` 的 `connection_drafts` |
| 恢复时机 | 每次**打开对话框**时：仅当列表仍是初始单空草稿才用库中内容替换（不覆盖本次会话已编辑内容） |
| 密码 | **不写入草稿表**（无 password 列），恢复后密码框为空 |
| 模板（导出） | JSON **不含密码**（仅名称 / 类型 / 驱动 / URL / 用户名 / 备注 / 作用域 / SSL / 标签） |
| 落库凭据 | 正式保存时由 `auth_store`（AES-256-GCM）加密；DuckDB Secret 目录为应用数据目录（不写用户主目录） |
| 写失败 | 草稿持久化 / 标签 / 分组同步失败只记日志，不阻断连接保存 |

## 8. 常见问题与排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 测试连接报 `CONN_DRIVER_NOT_FOUND` / `Driver 'xxx' not found in registry` | **已修**：应用启动漏注册内置驱动（`DriverRegistry` 为空）→ 现已在外层初始化时注册；导航树连接 / 重连的同类失败也一并修复。若仍复现，请附 `target/rds-app.err.log`（应能看到驱动注册日志） |
| 测试连接报 `Database path is required for SQLite` | **已修**：文件型工厂原先只读 `config.database`、忽略服务层传的地址（`url_override`）→ 现与网络型驱动一致从 `to_url()` 取地址 |

- [ ] 数据库字段留空 → 保存后 URI 无路径段；端口留空 → 用驱动声明默认端口；主机清空 → URI 不变（不产生非法 URL）
- [ ] 已存在文件用“新建”选一次：提示“已存在，直接引用（未清空）”，文件内容不变
- [ ] 拖动窗口变窄：Tab 内容不换行错位、不出现卡高参差；内容超高时在 Tab 区域内滚动

**P. 测试连接与真实连接同源（A1 新增）**

- [ ] 引用一个认证档案（此时用户名 / 密码为只读说明）→ 点 `测试连接`：结果行出现「已应用认证档案凭据」；把引用改成不存在的 ID（或删除档案后编辑旧连接）再测 → 提示「未找到引用的认证档案，测试未包含档案凭据」（不再静默）
- [ ] 引用一个**不可达**的 SSH 网络档案（如端口写 `1`）→ `测试连接`：直接失败并提示「网络档案应用失败：…」（不再拿远端地址直连试探）
- [ ] 引用可用的 SSH / 代理档案并测试：结果行出现「已建立网络档案隧道」；测试结束后本机不残留监听端口（可对照 `connection_tunnel_cleanup` 的诊断思路）
- [ ] 同一连接：`测试连接` 通过后，导航栏点「连接」也应成功（两者共用同一套组装规则）；反之测试失败时真实连接也不应成功

**Q. 凭据特殊字符（A1 新增）**

- [ ] 密码含 `@` / `:` / `/` 的连接（如 `p@ss:w/rd`）保存后查库：URL 中密码为转义形式（`p%40ss%3Aw%2Frd`），主机 / 端口不被截断
- [ ] 此类连接测试连接与真实连接均可成功（转义后解析回原密码）
