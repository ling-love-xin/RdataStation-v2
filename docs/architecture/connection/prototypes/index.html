① 连接对话框主体

一个对话框 = 选类型 → 五 Tab → 暂存 → 批量提交
🪟
对话框骨架 已实现
信息架构总图：左侧类型树 + 暂存草稿列表，右侧 Header（名称 / 作用域三态 / ? 徽标）+ 五 Tab 导航 + footer（测试 / 保存 / 保存并关闭）+ 结果行四级分级。各 Tab 内容由各分页承接。
类型树暂存草稿作用域结果行
📋
常规 Tab 已实现
地址 / 认证 / 连接安全（SSL）/ 组织（分组 / 标签）。网络型与文件型双形态（字段由 DriverDescriptor 派生）；引用认证档案后字段转只读。
网络型文件型SSL分组/标签
🌐
网络 Tab 部分实现
直连 / SSH 隧道 / HTTP 代理 / SOCKS / 协议链五选；内联 SSH（主机密钥 TOFU 三态）与档案引用两种模式。多跳可视化编辑器为提案（归档案侧，#25）。
SSH代理TOFU协议链
⚙️
高级 Tab 部分实现
环境引用 + 策略覆盖 + DuckDB 加速（scanner 扩展门控）+ 元数据缓存身份指纹。策略覆盖的执行效果预览为提案（依赖环境策略执行语义落地）。
环境策略覆盖加速指纹
🧩
能力 / 驱动属性 Tab 已实现
能力 = 驱动 capabilities 只读矩阵（单一来源 drivers.capabilities）；驱动属性 = 键值对透传（写入 driver_properties）。
只读矩阵键值透传

② 三类复用引用的管理域

上轮分析确认的详细设计缺口：能配，缺「配了之后发生什么、怎么运维」
🔐
密码管理（认证档案） 重点补设计
现状：AES-256-GCM 存储 / 脱敏 / 引用计数已硬。补：密钥来源（机器绑定 → 系统凭据管理器 / 主密码）、引用影响面（改档案 → 哪些连接受影响）、轮换与换机迁移流程。
密钥来源引用影响面轮换换机迁移
🛰️
代理隧道管理 重点补设计
现状：协议链执行 / TOFU / 加密已硬，但混在一张表（chain 内嵌每跳）。提案：资源/链两层（SSH、HTTP 代理等最小单位 + 组合引用序列，凭据引用密码档案）、活动隧道监控、逐跳诊断、存量拆表迁移。
最小单位/组合活动隧道逐跳诊断拆表迁移
🏭
环境管理 重点补设计
现状最弱：5 类策略只存储展示、执行侧零消费。补：策略执行语义矩阵（每类策略 × 生效层 × 消费入口）、策略字段化配置、环境应用预览（同一连接在 prod / dev 下行为差异）。
执行语义矩阵5 类策略应用预览
🗂️
配置中心页 已实现
三域（认证档案 / 网络代理 / 环境策略）从「对话框内再开一层」升格为中央 Dock 单实例页：左域导航 + 右面包屑 + 三格统计条 + 列表/表单两态 + 名称搜索与类型 chips。外壳已落地，与源码一致。
三域导航列表⇄表单统计条搜索/筛选
