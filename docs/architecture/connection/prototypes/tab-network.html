网络方式

连接层只选「走哪条路径」
🔗 直连
驱动 TCP 直连目标库（默认）
📦 引用网络资源… 两层模型
从资源库选单个资源（跳板 / 代理）——最常见
⛓ 引用协议链… 两层模型
多跳组合（资源引用序列）
✏️ 内联（一次性）
快速临时配置，仅本连接可见；建议转为资源（下方入口）
SSH / HTTP / SOCKS 是资源类型，在 网络资源管理里建；连接层不再按协议分形态。内联是入口不是终点——保存前可一键沉淀为资源。
直连 = 驱动直接 TCP 连接常规 Tab 的地址。
高级场景（SSL 材料、客户端证书）见 常规 Tab 连接安全卡 与驱动属性；文件型连接无本 Tab。
