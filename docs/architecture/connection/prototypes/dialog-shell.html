Header 与 footer 的关键语义

作用域三态
仅全局 G_ / 仅项目 P_ / 项目内全局 GP_（项目快照）；? 徽标 = 落库语义 Tooltip（决策 #110）；新建默认「仅项目」（#39）
保存语义
「保存」= 追加暂存条目 + 自动新建空草稿（#40，Ctrl+Enter）；「保存并关闭」= 批量提交全部暂存（部分失败保留现场）
结果行
四级分级 Info/Success/Warning/Error（#28）；摘要 >80 字或含换行 → 「详情 / 复制」；Warning 有真实生产者（分组同步失败降级）
异步
测试 / 保存跑在后台执行器，不阻塞 UI（#102）；重复触发被 BusyOp 挡住
