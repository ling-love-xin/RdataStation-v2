## 状态口径（与仓库诚实约定一致）

每个交互元素标注四态徽章：

- <span style="color:green">**已实现**</span>——代码已落地，原型 = 现状还原，供回归对照；
- **部分实现**——主链路有、缺口明确（如网络 Tab 的 chain 仍 JSON 编辑、档案侧无链编辑器）;
- **设计提案**——本原型新增的设计、**代码未实现**（⑦⑧⑨ 的余项：轮换影响面 / 迁移包、隧道监控 / 逐跳诊断 / 链编辑器、策略独立成态）;
- **不做/观察**——已拍板不做或挂观察项（例：网络 Tab 的「内联一次性 SSH」按决策 #72 不采纳）。

三个管理页的「提案」部分即上轮模块分析（2026-11-10）确认的详细设计缺口交付——**2026-11-20 复核：主体已落地，余项见括号**：

1. **密码管理**：密钥生命周期（机器绑定 → 系统凭据管理器 / 主密码三档）**已实现**（含切档重加密与启动解锁）；轮换影响面、换机迁移包**仍缺**（§14 #44）；
2. **代理隧道管理**：资源 / 链两层**已实现**（`net_resources` / `chains` + 档案域读写 + 链展开）；运行态监控（`TunnelRegistry` 现仅 `count()`）、逐跳诊断、档案侧链编辑器**仍缺**（§14 #42）；
3. **环境管理**：执行语义矩阵八行**已实现**（只读 / DDL 拦截、超时、行数上限、审计、schema 白黑名单、写确认、连接级覆盖、PROD 徽标）；策略独立成态与影响面预览**仍缺**（§14 #43）。

## 工程约定

- 共享主题 [`_theme.css`](_theme.css)（亮/暗双主题，设计语言沿用旧原型：陶红主色 `#C25B46`、13px 基准、VS Code 式拟真）与 [`_theme.js`](_theme.js)（主题记忆 + 页内 Tab）——各页不再内嵌主题样式；
- 纯静态 HTML，直接从磁盘打开即可（相对路径引用同目录共享文件）；
- 页内链接互指（对话框 → 管理器 → 回总览），`footer` 逐页标注与实现代码的对照锚点；
- 修改时保持状态徽章诚实：功能落地后把「提案」改标「已实现」并同步本 README 与 §14 台账。

## 与权威文档的同步义务
