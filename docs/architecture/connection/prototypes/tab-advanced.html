③ 本地加速（DuckDB 联邦）

门控 = 加速开 + 驱动族有 scanner 扩展（#38）
联邦源
mysql（mysql_scanner ✅）——凭据注册为 DuckDB PERSISTENT SECRET（secret 目录在应用数据目录，不写用户主目录）
注册目标
按作用域：G_ → 全局分析库；P_/GP_ → {项目}/.RSmeta/analytics.duckdb（与缓存指纹同源域隔离）
回收
断开连接 / 关闭加速 / 删除连接 → Secret 移除；注册失败只告警不影响连接
无 scanner 扩展的类型（如 DuckDB 文件源）此卡禁用并说明「本地文件无需联邦」；UI 文案区分「本地加速 / 联邦源」。

④ 元数据缓存身份指纹

已实现（#19/#113）· 只读展示
v1| mysql| net:db-order-ro.internal:3306/orders/-| user:app_ro meta_a1b2c3d4e5f67890.sqlite · 域内共享
作用
同物理库的多条连接共享一份 L2 元数据缓存（避免重复预热）；密码与密钥绝不进指纹；驱动实现 id 不进身份（差异属能力覆盖面）
域隔离
全局域 / 项目域目录分离互不互通；GP_ 项目侧走项目域
不共享
内存库、地址为空、或 driver_properties.identity_salt 显式声明独立目标
