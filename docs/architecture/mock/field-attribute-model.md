# 字段属性模型与生成器架构（2026-11-06 讨论定稿）

## 1. 核心模型：字段 = 四件属性

| 属性 | 是什么 | 例子 |
| --- | --- | --- |
| **产出类型**（ColumnDataType） | 物理类型，决定存进数据库是什么 | `VARCHAR(255)` / `INT` / `DECIMAL(10,2)` |
| **生成器配方** | 同一数据类型下的预设参数集 + 格式约束 | 手机号 / 邮箱 / 随机整数 / 自增 ID |
| **业务组**（GeneratorCategory） | 这个字段属于哪个业务分类 | 个人信息 / 地址 / 金融 / 数值 |
| **注释** | 后期用，先占位 | "用户主手机号" |

## 2. 参数是分层的

```
产出类型参数（底层）：VARCHAR → length、charset
    ↓
生成器配方参数（上层）：手机号 → 格式（11位/带区号）、前缀（138/139）
```

生成器配方不是独立的东西，它就是"某个数据类型下的一套预设参数 + 格式约束"。选了手机号，底层就是 VARCHAR，上层套了手机号的格式规则。

## 3. 双视角保留

左栏生成器库保留两种分组方式（Tab 切换）：

- **业务视角**：按业务组分组（个人信息 / 地址 / 金融...）
- **技术视角**：按**产出类型**分组（产出 INT / 产出 VARCHAR / 产出 DATE...）

注意：技术视角分组名从"INTEGER/VARCHAR"改成"产出 INT/产出 VARCHAR"——明确这是配方的产出属性，不是在选数据类型。

## 4. 布局职责

### 左栏 = 选"生成什么东西"（配方）
- 搜索框在顶
- 下面按业务/技术分组折叠列表
- 点击 = 选了这个配方

### 右栏属性区 = 配置"怎么存 + 怎么生成"
```
右栏属性区
  ├─ 产出类型     [VARCHAR ▾]        ← 选物理类型
  │    └─ 类型参数：长度 [255]
  │
  ├─ 生成器配方   [手机号 ▾]         ← 当前选的配方（左栏点进来的，这里可换）
  │    └─ 配方参数：格式 [11位▾]  前缀 [138]
  │
  ├─ 业务组       [个人信息 ▾]
  ├─ 注释         [________]
  │
  └─ 公共属性（右下角一行）
       空置率 [slider]  唯一值 [slider]  样例：138****5678
```

## 5. 新增生成器 = 新增自定义配方

不需要单独"新增数据类型"——数据类型只有 13 个基本类型是固定的，所有"自定义类型"都是生成器配方。

新增自定义生成器流程：
1. 左栏底部「＋ 自定义生成器」
2. 选基础类型（VARCHAR/INT...）+ 业务组
3. 定义自己的参数（名称 + 类型 + 默认值）
4. 保存后：出现在业务组列表 + 产出类型列表，带「自定义」标签

## 6. 三层架构（下一步方向）

| 层 | 是什么 | 怎么加 |
| --- | --- | --- |
| **算法层**（Rust） | 生成值的代码逻辑 | 写 Rust，编译 |
| **元数据层**（YAML/JSON） | 生成器名字/分类/参数定义/默认值/图标 | 写 YAML，热加载，不用编译 |
| **预设层**（YAML/JSON） | 表级方案（时序数据 / 电商订单 / 金融交易） | 写 YAML，一键建表 |

### YAML 配置草案
```yaml
generators:
  - name: 手机号
    category: person
    base_type: varchar
    algorithm: phone           # 对应 Rust 算法
    params:
      - name: 前缀池
        kind: text
        default: "138,139,150"
      - name: 格式
        kind: select
        options: ["3-4-4", "3-5-4"]
        default: "3-4-4"
```

### 时序数据等复杂场景
不是单生成器，是**表预设**——预设一组跨列的列配置：
```
「时序数据」表预设
  ├─ created_at  → 时间序列（步长 1 小时）
  ├─ price      → 随机游走（上一个 ± 0.5%）
  ├─ sales      → 泊松分布
  └─ stock      → 随销量递减
```

## 7. 当前代码与目标模型的差距

| 目标 | 现在 |
| --- | --- |
| 产出类型 / 配方 / 业务组 / 注释 四属性在右栏竖排 | 弹窗里结构混乱，类型 chip 在列行，业务组不明确 |
| 公共属性（空置率/唯一值/样例）沉底一行 | 散落在参数区各处 |
| 左栏技术视角按"产出类型"分组 | 按数据类型分组，名不副实 |
| 生成器元数据 YAML 化 | 全硬编码在 generator_catalog.rs |
| 表预设（时序数据） | 只有 Templates 简单预设，无时序 |
