## 1. 一句话口径

生成器库的「筛选」不是一个独立控件，而是**顶部搜索定位框 + 双视角分组**的组合：搜索词实时过滤左栏分组项并**强展开全部命中分组**；`Enter` 直接采纳当前视角下**第一个命中**写回列草稿；`Esc` 关闭对话框（有未应用修改先弹确认）。搜索定位是「选生成器」的主路径，点击分组 / 最近使用 / 智能推荐是并列的次路径，全部走同一个写回入口。

## 4. 搜索定位语义（#3 定稿）

### 4.1 匹配域（`spec_matches`，大小写不敏感）

- 内建生成器：`name`（snake_case 标识）或 `label`（中文标签）或 `category.label()`（所属分类名）包含词即命中。
- 自定义生成器（`UserGenerator`）：`name` 或产出类型中文标签（`column_type_label`）包含词即命中。
- 锚点：`generator_library.rs:1587-1592`、`:267-272`。

### 4.2 强展开（搜索态）

- `is_expanded = !query.is_empty() || expanded.contains(name)`：**有搜索词时所有分组无条件展开**（命中组自然可见，未命中组展开后为空）；无搜索词时按用户展开状态（`expanded` / `expanded_types`）。
- 锚点：`generator_library.rs:495, 554`。

### 4.3 Enter 采纳（`first_match_for`）

- `Enter`（搜索框 `PressEnter` 事件）→ 取**当前视角 + 当前词**下第一个命中 → 走 `apply_picked_generator`（与点击列表项同一入口）写回草稿。
- **空搜索词不采纳**（没有「当前项」概念）。
- 首个命中的顺序（与列表渲染同一套顺序）：
  - 业务视角：按 `GeneratorCategory::ALL`（15 分类）顺序，组内**内建在前（目录序）、自定义在后**；
  - 数据视角：按 `COLUMN_TYPES`（13 类型）顺序，内建只算**方法级**（`is_method_spec`），自定义项始终参与；
  - 命中判定：内建 = `spec_matches`；自定义 = 名称 / 产出类型标签包含。
- 锚点：`generator_library.rs:233-245`（订阅分支）、`:258-318`（`first_match_for`）。

### 4.4 计数反馈

- 搜索框为 `Input`（占位「搜索定位生成器…」），词在 Change 订阅里回填 `state.query` 并 `cx.notify()`。
- 命中数量在左栏渲染时自然体现（未命中组展开为空），原型内补充「N / M 项」计数条便于对照。

## 5. 键盘流

| 键 | 行为 |
| --- | --- |
| `Enter`（搜索框内） | 采纳当前视角第一个命中 → 写回草稿（空词无操作） |
| `Esc` | 关闭列编辑对话框；**有未应用修改 → 弹「放弃未应用的修改？」确认框并阻止关闭**（#6 丢失防护，`detail.rs:933-947`） |
| `Tab` 焦点 | 分组行 / 「＋」 / 项行 / 编辑 / 删除 全部为 `Button`（键盘可达，Enter/Space 于 KeyUp 激活）；搜索框、列名输入为 `Input` |

## 6. 双视角边界（#1 定稿：技术视角只留方法）

- **方法级**（`is_method_spec`，`generator_catalog.rs:2190-2202`）：
  - 分类级方法：`Numeric / Text / Markdown / DateTime / Constraint` 全量；
  - `Tech` 仅 `uuid_v1 / uuid_v3 / uuid_v4 / uuid_v5`；
  - `Person / Address / Business / Finance / Image / Color / FerroidId / Code / Vehicle` 为业务级，**不进数据视角**。
- 数据视角分组内只显示方法级内建 + 该类型的自定义项；业务视角显示全量。
- 精调层「基础生成器」候选与数据视角同口径：只方法级，按锁定类型过滤（`generator_library.rs:979-989`）。
- 徽标口径：业务视角项徽标 = 数据类；数据视角项徽标 = 数据类（与所在组一致），不再标业务组。

## 7. 分组与自定义精调层

- 分组行：`ChevronDown/ChevronRight` + `toggled` 展开态 + 计数 `名称（内建数 + 自定义数）`；行尾「＋」`icon_button` 打开精调层：
  - 业务组「＋」→ 锁业务组、类型可自选；数据组「＋」→ 锁类型、业务组可自选/不分组（`CreateSeed::New`）。
- 自定义项行：名称 + 徽标 + 「编辑」（精调层预填：基础生成器锁定只读、`preset` 保用户参数）「删除」（会话级移除，`panel.delete_user_generator` 后刷新对话框列表）。
- 自定义生成器 = **命名变体**（基础生成器 + 参数 patch + 名称），不是新 `GeneratorConfig` 变体（`spec_of` / `generate_cell` 编译期穷尽 match）。
- 保存即应用：`submit_create` 成功 → `apply_picked_generator` 写回当前列草稿；内嵌模式不关对话框，独立窗口模式关闭。

## 8. 最近使用与智能推荐

- 最近使用：`panel.recent_generators()`（会话级，菜单退役后快速路径），非空才渲染，点击直接 `apply_picked_generator`，不受搜索词过滤。
- 智能推荐：`smart_reset`（`detail.rs:1001`）按**当前列名输入框的值** + 类型整套重推（生成器 + 参数 + 空值率 + 唯一值回到推荐值）；区别于右栏「采纳推荐」（只换生成器、保留参数）。挂在左栏顶部，语义是「选哪个生成器」的一种解法。

| 触发 | 写回 | 关对话框 |

| 最近使用点击 | 同上 | 否 |
