# 列编辑弹窗（Column Dialog）

点列行的生成器按钮弹出的编辑窗口——左栏生成器库 + 右栏属性参数区。

## 右栏属性区（四属性）

```
产出类型     [VARCHAR ▾]    ← 可改
生成器名     [手机号]       ← 左栏点进来的
业务组       [个人信息]     ← 只读
注释         （后期支持）   ← 占位

参数区（生成器参数）
样例预览

公共属性（底部一行）：空值率 [slider]  唯一值 [switch]
```
