# 原型目录（Prototypes）

所有 UI 原型 / 设计稿 / 交互文档都在这个目录下，按功能块分子目录。

## 目录索引

| 子目录 | 功能块 | 内容 |
| --- | --- | --- |
| `column-zone/` | 列管理区 | 列行布局 / 工具栏 / 空态 |
| `generator-library/` | 生成器库 | 搜索 / 双视角分组 / 自定义生成器 |
| `column-dialog/` | 列编辑弹窗 | 左库 + 右属性参数区 |
| `toolbar/` | 工具栏 | 场景/预设/导入/筛选/加列 |
| `figcraft/` | FigCraft 设计稿 | 像素级设计稿（.json / .png） |

## 规则

- 每个功能块一个子目录，原型文件放里面
- 子目录带 README.md 说明当前布局和待做项
- 调整哪个功能就找哪个子目录，不要在根目录堆文件
