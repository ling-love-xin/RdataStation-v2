思路：把「堆」改成「层」

现在的左栏从上到下堆了四层导航结构（智能推荐 / 最近使用 / 双视角 Tab / 分组树）， 右栏再分两块，一屏里有五六个等重的视觉入口。规范里「一屏视觉焦点不超过 2 个」 在这个面板里是失守的。

本方案把窗口拆成三层：顶层直达条（推断直达 / 历史直达，充满整宽）， 左边是「我在找」（双视角 Tab + 分组卡片，只回答"有哪些"）， 右边是「我选的是这个、它长什么样」（固定三区：属性 / 参数 / 预览， 预览可以点「点击生成」反复看产出）。

可以点的：左栏生成器项（切选中态，右侧跟着变）、预览区的「点击生成」（随机换一批）、 分组头（展开 / 收起）、分组上的「＋」（悬停显形）。

这一版改了什么

1 分组行 → 分组卡片：一张卡 = 一个分组（头行 + card_divider + 子项）， 与右面板已卡片化的清单同族。注意不是「卡片套卡片」——子项是行，不是卡。
2 选中项有标识了：list_active 底 + 左侧 2px 条（走 workbench_shell::tree::active_bar）。现在左栏点中哪一项，只有右栏在变， 左栏自己看不出来。
3 右栏三区全部卡片化，与左侧同族同构（用户反馈 v4）：左侧是「一列分组卡」， 右侧原来是「一张卡 + 两摊散件」——视觉语言断了。现在属性 / 参数 / 预览各是一张卡， 卡内结构照抄左侧分组卡的「头行（标题 + 右侧操作）+ card_divider + 内容」， 左右两栏读起来是同一种东西。
4 直达条上移、充满整宽（用户反馈 v3）：智能推荐 + 最近标签从「左栏里的一行」 提到「分栏之上的一条」——横跨两栏后 320px 的拥挤消失，标签基本不再 wrap； 左栏直接从 TabBar 开始，与右侧属性卡同一水平线起。
5 右栏固定三张卡，操作各归其位：属性卡挂「恢复智能默认」（作用于生成器本身）， 预览卡挂「点击生成」（作用于样例），参数卡无操作。产出类型下拉在属性卡内 保留可改——类型 chip 是注解不是编辑器。
6 预览区带「点击生成」（用户反馈 v3）：点一次按当前参数随机出一批样例， 可以反复点看产出分布——「这个生成器实际会长出什么样」从静态示意变成可探查。 样例区定高 5 行，点生成时布局不跳动。落地走事件路径（按钮 on_click 里生成 + cx.notify），render 保持纯读。
7 左栏 280 → 320px：长标签「地址与网络标识（18）」在 280px 里与计数挤在一起； 320px 装得下「标签 + 计数 + ＋」且留出余量。

逐条对照规范

项现状违反建议
分组行形态 Quiet 文字按钮 + 行尾「＋」图标，子项缩进 pl(px(20.)) 裸 px()；缩进不走 tree 原语；与模块其他清单（已卡片化）不同族 card + card_divider；缩进走 tree::indent_spacer（8 + 14×depth = 22px）
选中态 无。左栏点中后只有右栏变化 rds-design §交互反馈「选中态有明确视觉标识」；§视觉层级「当前选中项」应是焦点之一 row_card_selected 语义：list_active 底 + tree::active_bar 左条 2px
右栏区域形态 属性是三行 kv，参数 / 样例是 section 标题 + 散落内容 左侧是「一列分组卡」，右侧是散件——两栏视觉语言不一致，区域无实体边界 属性 / 参数 / 预览各一张 card，卡内「头行 + card_divider + 内容」 与左侧分组卡同构；产出类型下拉在属性卡内保留可改
智能推荐 / 最近使用 智能推荐独立一行按钮 + 最近使用一个 section，两块同重 两者是同一类东西（推断直达 / 历史直达），不该各占一块； 且「最近使用」section 标题再吃 24px 合并成一行「直达条」：[智能推荐] 最近：标签×N； 标签可点直达，超宽 wrap 不横向滚动
预览区 夹在参数行末尾的一行 kv（固定种子两条，逗号分隔） 语义被读成「又一个参数」；且是死的——用户想多看几条、换个随机批次都不行 独立预览卡：头行挂「点击生成」，点一次随机出 5 条； 样例区是卡内无边框内容块、定高防跳动，可以反复点看产出分布
左栏宽度 280px 长标签「地址与网络标识（18）」+ 计数 + 「＋」挤压 320px，登记为 ui::COLUMN_GENERATOR_LIST_WIDTH
视觉焦点 智能推荐 / 最近使用 / TabBar / 分组头 ×N / 属性 / 参数，六级同重 rds-design §视觉层级「一屏不超过 2 个焦点」 降到 2 个：左栏选中项 + 右栏已选卡；其余为静态 / 辅助档
操作显形 分组「＋」、自定义项「编辑 / 删除」常显 15 组常显 15 个「＋」，扫视时是噪声 悬停 / 键盘聚焦显形（与列卡片同口径，占位宽度不变）

没做的事（有意不动）

不动双视角的信息架构（业务分类 15 组 / 数据类型 13 类）—— 这是用户 4 版原型验收后拍板的口径，本轮只改「怎么画」，不改「怎么分」。

不动列名 + 搜索框同排的顶部条——用户定稿项。

不引入自定义生成器的持久化（SQLite 落盘）—— 记录在 mock-view-ui-design.md §9.5，属基础设施轮次，与布局无关。
