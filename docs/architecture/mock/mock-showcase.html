01

没有它的时候

造测试数据的三种常见做法，以及各自的坑

手工写 INSERT / 脚本

  • 几十万行要写循环或 generate_series，还得自己编值域
  • 换一张表就重写一遍；改列名就全烂
  • 分布不像真实数据：金额全是均匀随机，一眼假

从生产库导一份

  • 敏感数据要脱敏，脱敏又要写脚本
  • 导出大表慢，还可能把生产库拖垮
  • 数据与表结构一起漂移，样本很快就过期

Mock 数据生成

  • 只要表结构：不读任何真实数据，没有脱敏问题
  • 列名 + 类型自动推断生成器（≈91 条规则 + 类型兜底），换表即换数据
  • 分布族与日历：长尾、计数、比例、时序、工作日、工作时段都能表达
  • 生成只落内存，落地必须显式点出口，不会误写
02

六个值得记住的特点

🧬

元数据驱动

输入只有列名 + 类型 + 可空/主键。列名规则（≈91 条）+ 类型兜底自动选生成器，置信度三态告诉你哪些是猜的。

📈

像真实业务数据

正态 / 对数正态 / 泊松 / 指数 / 帕累托 / Beta / 二项 / 时序数值（趋势 + 周期 + 噪声），不用外部分布库。

🗓

工作日历在列上

仅工作日 + 工作周掩码 + 节假日 / 调休列表 + 工作时段（窗口可自定义，夜班跨零点）。不内置节假日表——那种表每年都会过期。

🔗

多表与关系

6 套内置场景模板一键产多张表；也能自建多表、加关系。取值域由父表参数算出，不读数据、O(1) 内存。

🚪

生成 ≠ 写入

四个显式出口各自有独立语义：新建（同名报错）· 追加（主键接续）· 草稿箱 · 另存为（CSV / Parquet / Xlsx / SQL）。

🛡

护栏在生成前

空区间、负权重、λ ≤ 0、掩码写错、日期串不规范……一律生成前拦住并说清「哪一列、哪个字段、怎么改」。

04

一次生成的六个阶段

每个阶段都有明确落点与失败时的可读原因
STEP 1
拿结构
导航右键「生成 Mock 数据」，或面板里「导入结构」手填连接 / 库 / schema / 表。
只读列名 / 类型 / 可空 / 主键
STEP 2
自动映射
≈91 条列名规则 → 前后缀 → 模糊子串 → 类型兜底，给出生成器与置信度。
置信度：high / low（按类型猜）/ manual
STEP 3
调参数
每列可换生成器、调参数、定空值率与唯一；标量、集合、（日期）日历参数都在同一个对话框里。
非法值不收起对话框
STEP 4
生成
后台线程按 10k 行/批写入内存临时表，进度实时上报，可在批次边界取消。
生成前先跑参数护栏
STEP 5
预览
中央 tab 直接给前 10 行；改任何配置旧结果自动作废，出口随之禁用。
结果表 tab 只读，改列要回草稿
STEP 6
落出口
四个出口各自独立语义；多表时还能一键「落库这 N 张」。
出口不可取消，跑在后台
生成 → 内存临时表 temp_mock_* 持久化 → 项目分析库（新建，同名报错） 追加 → 既有表（自增主键接续） 草稿箱 → {项目}/mock/ 另存为 → CSV / Parquet / Xlsx / SQL 不回传源库（M7 硬约束）
清单上的状态点：○ 未生成 · ◐ 生成中 · ● 已生成 · ✓ 已落库 · ⚠ 引用的表没落库（多表时才有）

分布族：让数值有形状

常见数据的形状其实是可枚举的：收入 / 房价（对数正态、帕累托长尾）· 到达数 / 点击数（泊松）· 等待时长（指数）· 转化率（Beta，恒在 0~1）· 成功次数（二项）。

实现自建（Box-Muller / 逆变换 / Marsaglia-Tsang），不引分布库；泊松 λ≥30、二项 n>64 自动转正态近似，十万行不卡住。

工作日历：让时间戳像真的

仅工作日（顺序日期按工作日数推进，跳过的日子不占行；随机日期只采工作日）· 工作周掩码（1111100 = 周一~周五）· 节假日与调休两张列表（调休优先）· 工作时段窗口（09:00~18:00 起 > 止 = 跨零点夜班）。

参数在每一列自己身上，不与别的列共享；写错的日期串（如 2026-1-1）会在生成前被拦住。

07

边界：三条硬约束，写进不变式

① 只进分析引擎

全模块没有任何写入源库的路径。目标只有内存临时表与项目分析库 {项目}/.RSmeta/analytics.duckdb。

② 只取结构，不取数据

与源库的唯一沟通是表结构（经元数据路径）。跨表引用的取值域由父表参数算出，不读已落地数据。

③ 不改已落地数据

「持久化」遇同名表报错（引导改用追加）、「追加」只增行；都不 DROP、不重写既有数据。

能拦住什么：空区间（min > max）· 时间区间不足一分钟 · 权重为负 / 全零 · 集合只填了一半 · λ 或 α 非正 · p 不在 0~1 · 工作周掩码不是 7 位 · 日期串不是 10 位 YYYY-MM-DD · 工作时段起 = 止。 全部在生成前拦下，并指出是哪一列、哪个字段、怎么改。
