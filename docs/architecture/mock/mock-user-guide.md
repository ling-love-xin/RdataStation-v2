# Mock 数据生成模块 · 使用手册（M7）

> 读者：产品 / 测试 / 使用者。设计理念与原理见 `mock-architecture.md`；视觉与交互规格见 `mock-prototype-design.md`；
> 任务与逐轮记录见 `mock-dev-plan.md`；模块入口见 `README.md`。
>
> **状态说明**：本手册对应**已落地实现（2026-09-18）**——Phase A–G 全部完成（生成器目录 **143 变体**、
> 数值分布族与时序、**列级工作日历**、一表一 tab、批量落库）。若 UI 与手册不一致，以手册为准并提 issue 修 UI。
>
> **一句话理解这个模块**：Mock 是「表的模具」——你给它**列定义**（列名 + 类型 + 生成器），它还你一表**可信的假数据**；
> **生成只落内存**，落地必须你点出口。

---

## 1. 这个面板能做什么

- **造新表**：命名一张**新表** + 组织列（导入源库结构 / 手工加列 / 套场景模板），行数 / 种子 / 语言都在同一处定；
- **生成**：在项目分析引擎的**内存临时表**里生成模拟数据，中央 tab 立刻给前 10 行预览；生成走后台线程，有进度、可取消；
- **四个显式出口**：持久化到项目分析库（新建）/ 追加到既有表（主键自增接续）/ 保存到草稿箱（`{项目}/mock/`）/ 另存为（CSV · Parquet · Xlsx · SQL INSERT，不需要项目）；多表时还有一键「落库这 N 张」（同属出口组）；
- **多表与关系**：6 套内置场景模板一键生成多张表；也能在**工作副本**里「＋ 加表 / 删除 / 编辑表（表名 · 行数）/ ＋ 加关系」，
  关系声明在**子表列**上，值取自父表主键的取值域（由父列自增参数 + 父表行数**算出**，不读任何已落地数据）；
- **生成器**：143 个变体分 15 类（数值 / 文本 / 个人信息 / 地址 / 日期时间 / 商业 / 金融 / 网络技术 / 图片 / 颜色 / 编码 / 约束…），
  两条找法——**分类子菜单**（知道属于哪类）与**搜索对话框**（只记得名字）；菜单顶部还有「最近使用」与「推荐」标记；
- **像真实业务数据**：数值类有正态 / 对数正态 / 泊松 / 指数 / 帕累托 / Beta / 二项与**时序数值**（趋势 + 周期 + 噪声）；
  日期时间类可勾**仅工作日**（工作日历：工作周掩码 + 节假日 + 调休）与**仅工作时段**（窗口可自定义，支持夜班跨零点）；
- **历史与模板**：最近 20 次生成可**重放**、可删；当前配置可**保存为模板**随时复用。

**不在本面板内**：数据源的连接与对象浏览（→ 数据库导航 M4）、DuckDB 表的查询与编辑（→ 编辑器 / 洞察 M8）、
草稿文件的日常新建与编辑（→ 草稿箱 M5）、把项目里的表提升为跨项目资产（→ 资产库存档 M6）。

### 1.1 什么该用 Mock、什么不该

| 该用 Mock | 不该用 Mock |
| --- | --- |
| 开发 / 演示用的表结构与样例数据（几十万行也要够快） | 需要**真实**数据的分析（Mock 生成的是模拟值） |
| 压测 JOIN / 聚合 / 索引效果的宽表与多表 | 要把数据**回写到源库**（M7 硬约束：只进不出） |
| 前端联调用的接口样例数据（要固定 seed 可复现） | 逐值精确可控的测试夹具（那应写成 SQL / 脚本） |
| 教学、录屏、模板演示的填充数据 | 需要按**已落地真实数据**仿制的场景（属后续的「影子数据」，本模块不做） |

> 生成不是「另一个查询」：它是**一次性试算**。改一行配置就要重新生成，旧预览随之作废（出口也会一起禁用）。

## 3. 界面导览

两处排版是刻意分开的（架构 D38）：**右 Dock = 管理表**，**中央 tab = 这张表的设计与生成状态**。

### 3.1 右 Dock「Mock 生成」= 管理表

从上到下四块：

1. **表清单**（唯一入口）：单表 / 本次多表 / 结果表三种来源共用一个渲染器，一行 = **状态点 + 表名 + 行数**；
   多表时子表行下挂 `↳` 子行显示关系（`user_id → users.id · 1..1,000`，行尾 `✕` 删关系）。
   状态图例（清单底部常显）：

   > 状态：○ 未生成 ◐ 生成中 ● 已生成 ✓ 已落库 ⚠ 引用的表没落库（多表时才有）

2. **集合动作**（多表时才有）：「场景模板 ▾」（6 套内置）/「退出场景」/「生成 N 张表」/「＋ 加表（当前草稿）」，
   以及**集合任务的进度与取消**（单表任务的进度在中央表头——同一时刻只有一处画进度）。
3. **出口**（标题写着「出口（作用于当前 tab 那张表；生成后可用）」）：四个按钮竖排——
   **持久化到项目分析库** / **追加到既有表 ▾** / **保存到草稿箱 ▾** / **另存为 ▾**。
   前三个是**项目级出口**：未打开项目或只读会话时按钮直接置灰，理由就在旁边那一行（不用点了才知道）。
   出口反馈就地显示在下面（成功文案 / 失败原因 / `落库目标：X` / 只读提示）。
   关系相关时另有一条 warning 与**批量落库**：「还有 N 张没落库：…」+「落库这 N 张」。
4. **折叠段**（默认收起）：`▸ 生成历史 · 用户模板` —— 展开是最近 20 次生成（重放 / 删除 / 刷新）与用户模板（应用 / 删除）。

任务进行中时，**状态栏右侧**给一行 `◐ Mock 生成中 40% · 取消`（出口类任务给阶段名且不给取消）：
面板被切到别的区块、或中央那张 tab 被关掉时，任务还在跑也得看得见、点得到取消；
进度读数仍只在它自己那一处（中央表头 / 右 Dock 清单下）。

### 3.2 中央 tab = 这张表的设计与生成状态

- **表头**：目标表名 / 行数 / 种子 / 语言（13 种）四个输入 + **生成三态**（生成 / 生成中… / 重试）+ 场景模板菜单 + 进度与取消；
  生成失败时就在表头下方给 `生成失败：<原因>`，改完点「重试」即可。
- **列段**：一张列一张卡片，第二行是**生成器菜单** + 编辑 / 智能 / 删除 + 参数摘要；
  卡片头上有置信度徽标（`high` 绿 / `low` 灰 = 按类型猜的 / `manual` = 你手改过）。
  列来源两个入口（「导入结构」/「＋ 加列」）也在这一段旁边。
- **预览段**：前 10 行（`预览（前 10 行）· 尚无结果——点表头「生成」`）。表格是组件库的表：**列头可拖宽**（值被截断就拖开看全）、可横向滚；
  **右键**给「复制此值 / 复制整行（TSV）」；不做筛选与排序——这是取样，不是结果集。
- 空态给**起手卡片**：套场景模板 / 导入结构 / ＋ 加列。

### 3.3 结果表 tab（只读）

一张结果表一个 tab，标题是 `Mock · 表名（N 行）`（行数实时取自结果）。**切 tab 就是切表**——出口跟着走。
结果表 tab 的表头是**只读事实 + 跨表后果**（如「引用了 user_id → users.id：只落这张表，被引用的表不会跟着落库」），
列也只读（标题写着「来自这次生成（只读）」）：要改列，回草稿 tab 改完重新生成。

旧 tab **不会自动关**（关不关 tab 是你自己的窗口布局）：切换项目后它们会说清原因——
`所属项目已切换：这张表的结果已作废（切项目会清空 mock 结果）——重新生成后再看`；
同一项目里的前几轮生成则是「这一轮没有它的结果」。

### 3.4 六个对话框

| 对话框 | 标题 | 内容 | 确认 |
| --- | --- | --- | --- |
| 导入源库结构 | 导入源库结构 | 连接（下拉）/ 数据库 / catalog / schema（可留空）/ 表名 + 说明「从源库读取表结构…**不读取数据本身**」 | 「导入」 |
| 列编辑 | 列编辑 | 列名 / 类型 / 生成器（只读，从卡片菜单换）/ 参数 / 空值率（%）/ 唯一 / 「恢复智能默认」 | 「应用」（非法值不收起） |
| 搜索生成器 | 搜索生成器 | 搜索框（按名称 / 中文标签 / 分类，143 项）+ 列表（当前在用的打勾） | 点行或回车 |
| 加表间关系 | 加表间关系 | 子表 / 子列 / 父表 / 父列四个下拉（父列**只列自增列**） | 「添加」（四处选齐才可用） |
| 编辑表 | 编辑表 | 表名 / 行数（改行数时关系里的取值域自动跟着走；改名字会同步所有指向它的关系） | 「保存」 |
| 保存为模板 | 保存为模板 | 模板名（只问名字；行数 / 种子 / 语言 / 列都取当前配置） | 「保存」 |

## 4. 典型流程

### 4.1 从源库结构生成一张表并落库（最常用）

1. 数据库导航里找到那张表 → 右键 **「生成 Mock 数据」**（面板打开 + 结构已导入 + 目标表名已预填，状态行提示「已从 库.schema.表 导入 N 列」）；
2. 中央 tab 检查每一列的生成器（卡片菜单可换、点「编辑」调参数、点「智能」恢复按列名 / 类型的推断结果）；
3. 表头定**行数**（上限 1,000,000）与**种子**（留空 = 每次都不一样；填一个数 = 可复现）；
4. 点**「生成」** → 看预览；不满意就改配置（旧预览会自动作废）；
5. 满意后回右 Dock 点出口：**「持久化到项目分析库」**（新建一张表，同名已存在会报错并引导改用「追加到既有表」）；
6. 落库成功后清单里那行状态点变 **✓ 已落库**，底部显示「落库目标：表名」。

> 换名字才会多占一份内存：同一张目标表重复生成会重建临时表，不会越堆越多。

### 4.2 手工造一张表（不用源库）

草稿箱「生成 Mock」→ 表头填**目标表名**与行数 → 「＋ 加列」→ 列编辑里选类型与生成器 → 生成。
适合「先有数据想法，再去连库」的场景；列名建议直接写业务名（`order_amount` / `created_at`），智能映射命中率更高。

### 4.3 用场景模板一次生成多张相关表

表头「场景模板 ▾」选一套（电商 / HR / 博客 / 金融 / 社交 / 企业通讯录，共 6 套）→ 右 Dock 出现**工作副本**：
本次要生成的表清单 + 表间关系段 → 点「生成 N 张表」（进度按「张表」计）→ 结果**一张表一个 tab**。
场景生成**不记入生成历史**（历史是单表配置的重放来源）——面板里会写明这一句。

### 4.4 自建多表：加表 / 删表 / 编辑表 / 加关系

- **＋ 加表（当前草稿）**：把中央草稿那张表（表名 / 行数 / 列）加进本次生成——先在草稿里调好再加；
- **编辑**：改这张表的表名 / 行数；改行数时关系行的取值域跟着变，改名字会同步所有指向它的 `ref_table` 并报出同步了几条；
- **✕ 删除**：删表会**连带清掉指向它的关系**（并报出清了几条），避免留下「指向模板里没有的表」的悬空引用；
- **＋ 加关系**：子表 / 子列 → 父表 / 父列（父列只列自增列）。关系随时可加，**不要求父表先于子表**（自关联与前向引用都合法）。

### 4.5 追加到既有表（主键自增接续）

出口「**追加到既有表 ▾**」→ 选项目分析库里已有的表 → 生成的数据追加进去，**自增主键接着表内现有最大值往下走**。
目标表缺少这次生成的列会直接报错（不让 DuckDB 的原始错误冒到界面）；多余列保持默认值。
「持久化」与「追加」是两个语义不同的出口，**同名表不会自动追加**（免得你以为新建了一张）。

### 4.6 导出文件 / 保存到草稿箱

- **另存为 ▾**：CSV / Parquet / Xlsx / SQL INSERT（SQL 是整表 INSERT 文本，含表名与列清单）；
- **保存到草稿箱 ▾**：四种格式 × `{项目}/mock/mock_表名_时间戳.扩展名`，与文件出口同一套格式选择；
- 两者都**不消耗**临时表：导完还能再导另一个格式。

### 4.7 保存为模板与重放历史

- **保存为模板…**（折叠段里）：只问名字，把当前配置（行数 / 种子 / 语言 / 列 / 生成器参数）存进 `{项目}/.RSmeta/project.db`；
  **模板不存目标表名**——「怎么造数据」可复用，「造到哪张表」留当时的输入；
- **应用**模板 = 把配置铺回面板（不动目标表名）；**删除**即时生效；
- **生成历史**（最近 20 次）：每次成功生成自动记一条，可**重放**（把当时的配置写回草稿）与**删除**；
  失败与取消不记（出口类任务也不记——历史是**生成配置**的重放来源）。

### 4.8 让日期列只落工作日（工作日历）

在日期时间列的「编辑」里勾 **「仅工作日」**，然后按需填（都在同一列上，不与别的列共享）：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 工作周（周一~周日，1 上班） | `1111100` | 默认周一~周五；单休写 `1111110`，大小周按周切换时按主要形态填 |
| 跳过日期（节假日） | 一行一个 `YYYY-MM-DD` | 法定假日；留空则只按工作周判定 |
| 上班日期（调休） | 一行一个 `YYYY-MM-DD` | 调休上班的周六日，**优先于**工作周与跳过列表 |

- `sequential_date` / `sequential_date_with_gaps` 勾上后**按工作日数推进**（休息日不占行，日内时刻保持起始值）；
  此时「步长（秒）」必须是**整天**（`86400` = 每个工作日一行，`172800` = 每两个工作日一行）；
- `date` / `date_time` / `date_time_before` / `date_time_after` / `date_time_between` 勾上后只采工作日（落在休息日就重抽，重抽不成顺延）；
- 其中**带时刻的四个**（`date_time` / `date_time_before` / `date_time_after` / `date_time_between`）还能勾 **「仅工作时段」**，窗口用两个 `HH:MM` 自定（默认 `09:00`~`18:00`）；
  **起 > 止 按跨零点理解**（夜班写 `22:00`~`06:00`，两段都会出现）；
- 参数**在生成前校验**：掩码不是 7 位 0/1、日期串不是 10 位 `YYYY-MM-DD`、列表超 366 条、窗口起 = 止，都会被拦下并说清是哪一列哪个字段。

> **不内置节假日表**是刻意的：法定节假日与调休每年发通知，内置表必然静默过期（数据看着像真的，只是落在不该上班的那天）。

### 4.9 让数值更像真实业务（分布族与时序）

| 想要的效果 | 用哪个生成器 |
| --- | --- |
| 身高 / 成绩（围绕均值波动） | 正态分布（均值 / 标准差） |
| 收入 / 房价（长尾、不能为负） | 对数正态（中位数 / 离散度）或帕累托（尺度（最小值）/ 形状参数 α） |
| 到达数 / 点击数（计数） | 泊松分布（强度 λ） |
| 等待时长 / 间隔 | 指数分布（强度 λ） |
| 转化率 / 占比（0~1） | Beta 分布（形状参数 α / β） |
| 成功次数（n 次里几次） | 二项分布（试验次数 n / 概率 p） |
| 有趋势与季节性的指标 | **时序数值**：起始值 + 趋势（每行增量）+ 周期（行数）+ 周期振幅 + 噪声强度 |
| 带季节性的时间戳列 | `sequential_date`（按行序铺日期）+ 时序数值列，两列并排就是一条时间序列 |

> 这些分布的参数越界（λ / α 非正、`p` 不在 0~1、`n = 0`）都在生成前拦住；`周期 = 0` 表示**不叠周期**（合法）。

## 5. 速览：一次操作落到哪

| 操作 | 落到哪 | 说明 |
| --- | --- | --- |
| 生成 | **内存临时表**（进程级，`temp_mock_*`） | 不写任何库；切项目会被清掉（面板里的旧预览随之作废） |
| 持久化到项目分析库 | `{项目}/.RSmeta/analytics.duckdb`，**新建表** | 同名已存在 → 报错引导改用「追加」；写失败回滚本次刚建的表 |
| 追加到既有表 | 同上，**追加行** | 自增主键接续表内最大值；缺列报错 |
| 保存到草稿箱 | `{项目}/mock/mock_表名_时间戳.扩展名` | 项目文件，随项目走（未打开项目会被拒） |
| 另存为 | 你选的任意路径 | 系统保存对话框；**不需要项目** |
| 生成历史 / 用户模板 | `{项目}/.RSmeta/project.db` | 项目级；切项目后看到的是另一个项目的记录 |
| 所有出口 | —— | **都不回传源库**（M7 硬约束）；进全局分析库要走资产库存档（M6） |

面板底部常显这一句：**「数据只写入项目分析库（{项目}/.RSmeta/analytics.duckdb）与文件，不回传源库（M7）」**
（未打开项目时换成不带路径的同一句，因为那时没有「项目」可指）。「要进全局分析库走资产库存档 / 草稿箱升级」这条指引**不常驻**：它在真正需要时由被拒的出口给出（见下方故障表），避免 280px 宽的面板底部每隔一帧就占掉三行。

## 6. 快捷键

- 中央「Mock · {表}」tab 内：**Ctrl+Enter** = 生成当前草稿（等价于点表头的「生成 / 重新生成」）。
  **键位只在草稿 tab 内生效**（结果表 tab 上没有「生成」这个动作，要改回草稿改完再生成）；
  进行中按它静默忽略（与按钮的禁用态同语义）。
  订正：早先这里写的是「没有专属快捷键（生成是重操作，不做一键触发）」——重操作的说法站不住：
  按钮本就是一次点击，而 `Ctrl+Enter` 在本应用已是「把当前配置跑起来」的通用手势
  （连接对话框的保存同键），且它只在草稿 tab 有焦点时生效，不会误触外部；
- 结果表 tab 与右 Dock：**无快捷键**（右 Dock 的日常动作是选表，键盘路径不划算）；
- 对话框通用：**Enter** 确认（有输入焦点时先提交输入）、**Esc** 关闭 / 取消（焦点陷阱与遮罩关闭由组件负责）；
- 「搜索生成器」对话框：输入即过滤（同步、无 loading 闪烁），**↑ ↓** 选、**Enter** 写回该列；
- 命令面板里的「打开 Mock 生成」可用于快速切到面板。

## 7. 只读与数据安全

### 7.1 三条硬边界

1. **不回传源库**：全模块没有任何写入源库的代码路径（M7 硬约束）；
2. **只取结构，不取数据**：与源库的唯一沟通是表结构（列名 / 类型 / 可空 / 主键），经元数据路径取；跨表引用的取值域由**父表参数算出**，不读已落地数据；
3. **不改已落地数据**：Mock 从不修改已生成的表与文件；「持久化」遇同名表报错、「追加」只追加——都不 DROP / 不重写既有数据。

### 7.2 只读项目

项目只读（写锁被别的实例占用，或启动时没拿到写锁）时，面板照常可用、**生成与预览照常**，
但四个出口会被拒绝并给出「只读模式：不允许落库与写文件（仍可生成预览）」。

### 7.3 生成前护栏（拦什么）

不能采样的参数一律在**生成前**拦住并给可读原因（带具体数字），而不是生成到一半崩掉：

| 类别 | 例子 |
| --- | --- |
| 空区间 | 随机整数区间 min > max；半开区间（文本词数 / 句数 / 密码长度）min ≥ max |
| 时间区间 | 区间不足一分钟（fake 按「分钟差」取偏移） |
| 权重 | 加权选项为空 / 负权重 / 全零（总权重要正） |
| 集合 | 外键取值、序列取值为空（一行都没填） |
| 分布族 | λ / α 非正或非有限、`p` 不在 0~1、`n = 0` |
| 工作日历 | 掩码非 7 位 0/1 或全 0、日期串不是 10 位 `YYYY-MM-DD`、列表超 366 条、步长不是整天 |
| 工作时段 | 时刻串解析不了、起 = 止（`24:00` 只能当结束时刻） |

**注意**：护栏只在生成前起效——列编辑对话框里允许先粘一半（比如假期列表），不会边打字边报错。

### 7.4 取消与并发

- **生成 / 场景 / 追加可取消**：在**批次边界**生效（每批 1 万行），点过取消后按钮转「正在取消…」，任务结束报「生成已取消」；
- **出口不可取消**：落库 / 导出 / 草稿箱写盘没有中断点（强杀会留半张表 / 半个文件），按钮**不渲染**取消；
- **一次只跑一个任务**：任务进行中所有出口按钮禁用，重复提交会被拒（面板提示已有任务在进行中）。

### 7.5 跨表引用与落地完整性

出口以「当前表」为单位，而关系是跨表的——**只落子表不落父表，项目库里就有悬空值**（Mock 不改已落地数据，也不会替你补）。
面板为此给两件事：结果表头 / 出口区的一句 warning（「引用了 …：只落这张表，被引用的表不会跟着落库」/「被 … 引用：只落这张表，引用它的一方会落空」），
以及「还有 N 张没落库：…」+**一键「落库这 N 张」**（依次新建，同名的跳过并报出，**成功的不回滚**）。

## 8. 常见问题与排查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 点「生成」报「行数需为正整数」 | 行数空 / 0 / 负数 / 非数字 | 填 1~1,000,000 的整数 |
| 「种子需为 0~4294967295 的整数，留空则随机」 | 种子不是整数 | 留空（随机）或填整数（可复现） |
| 「暂无列：在这张 tab 里点「导入结构」或「＋ 加列」开始造表。」 | 还没有任何列 | 导入结构 / ＋ 加列 / 套场景模板三选一 |
| 生成失败并列出某列的区间 / 权重问题 | 参数不能采样（§7.3） | 按提示改那一列的参数再「重试」；旧结果已作废 |
| 落库报「项目分析库已存在表 X：请改用「追加到既有表」」 | 目标表名与项目库里已有表重名 | 换个表名，或改用「追加到既有表」 |
| 追加报缺列 | 目标表没有这次生成的某些列 | 用「持久化」新建，或把目标表的列补齐再追加 |
| 落库 / 追加 **按钮是灰的**，面板写「未打开项目：落库 / 追加 / 草稿箱不可用」 | 没有打开项目（这三个出口都是项目级的） | 打开或新建项目；**纯生成（含场景模板）、预览与另存为都不受影响** |
| 落库 / 追加报「未打开项目：Mock 只写项目分析库…」（旧路径，现在按钮已预先禁用） | 同上；这一句仍会作为任务层拒绝出现（如面板已摆着、项目刚被关闭） | 打开或新建项目 |
| 草稿箱报「未打开项目：草稿箱不可用（请先打开或新建项目）」 | 草稿箱目录属于项目（`{项目}/mock/`） | 同上；只想要文件就改用「另存为」（它写你选的任意路径，不需要项目） |
| 出口按钮灰了且面板写「只读模式…」 | 项目被别的实例占用（只读） | 关掉另一个实例，或只用生成 / 预览 |
| 旧结果表 tab 写着「所属项目已切换…」 | 切项目会清空 mock 结果（临时表是进程级内存表），而旧 tab 不自动关（D35） | 回草稿 tab 重新生成；或直接关掉那些 tab |
| 面板被切走 / 中央 tab 关掉了，任务还在跑 | 进度读数在它自己那一处（D38），但状态栏始终给一行指示 | 看状态栏右侧 `◐ Mock 生成中 N% · 取消`，就地取消（出口类任务不可取消） |
| 面板块显示「只读模式：不允许落库与写文件（仍可生成预览）」 | 同上 | 同上 |
| 清单里出现 `⚠ 引用的表没落库` | 关系里还有没落库的表 | 点「落库这 N 张」批量落，或按需只落其中几张 |
| 切项目后旧预览 / 结果没了 | 生成产物在进程级内存临时表，切项目会清理 | 重新生成；要留下就先用出口落库 / 落文件 |
| 历史里找不到场景生成 | 场景一次产 N 张表，**不记入历史**（历史只记单表配置） | 想复用多表配置：把工作副本「保存为模板」 |
| 「模板不存目标表名？」 | 模板只存「怎么造数据」 | 应用模板后表头会保留当前输入的表名 |
| 工作日历填了却不生效 | 没勾「仅工作日」；或日期串不是 10 位 `YYYY-MM-DD`（如 `2026-1-1`） | 先勾开关；日期一律写 `2026-10-01` 这种 10 位形式 |
| 夜班窗口（`22:00`~`06:00`）看起来「反了」 | 起 > 止 表示跨零点，是刻意的 | 想只要白天就写 `09:00`~`18:00` 这种起 < 止 |
| 生成很慢 | 行数大 / 唯一列多 / λ 或 n 参数很大 | 先小行数试参数；删除不必要的「唯一」列；周期 / 分布参数不要用极端值 |

## 9. USIT 验收清单（可勾选）

### 生成

- [ ] 从导航右键「生成 Mock 数据」打开面板，目标表名与列已按源表预填，状态行提示「已从 库.schema.表 导入 N 列」；
- [ ] 表头四项（表名 / 行数 / 种子 / 语言）都能改，改完生成用的是新值；
- [ ] 同 seed 两次生成结果**逐值相同**；留空 seed 每次不同；
- [ ] 生成中可见进度条与阶段文案（单表是「生成中…（N 行）」，集合任务是「…（N / M 张表）」），可取消，取消后报「生成已取消」且面板回到空闲；
- [ ] 预览显示前 10 行，且与生成结果一致；改任何配置后旧预览作废、出口禁用。

### 列与生成器

- [ ] 列卡片显示置信度徽标（high / low / manual），「智能」能恢复推断结果；
- [ ] 生成器菜单有「最近使用」分组与「推荐」后缀，当前生成器打勾；
- [ ] 搜索对话框输入即过滤、↑↓ 选、Enter 写回；无命中显示空态；
- [ ] 列编辑的参数改动即时反映到卡片摘要；非法输入不收起对话框；
- [ ] 数值分布族（泊松 / 指数 / 帕累托 / Beta / 二项）与「时序数值」都能选中并生成出合理量级的取值；
- [ ] 日期列勾「仅工作日」后：不出现周末与「跳过日期」，出现「上班日期」里的调休日；
- [ ] 工作时段窗口（如 `10:30`~`12:00`、夜班 `22:00`~`06:00`）生效。

### 出口

- [ ] 「持久化到项目分析库」在 `{项目}/.RSmeta/analytics.duckdb` 新建表且行数正确；同名再点报「已存在」且不覆盖；
- [ ] 「追加到既有表」自增主键接续（`MAX(id)` 连续、无重复）；
- [ ] 「保存到草稿箱」在 `{项目}/mock/` 出现 `mock_表名_时间戳.扩展名`；
- [ ] 「另存为」四种格式都能落盘，CSV 有表头、SQL 有 INSERT 语句；
- [ ] 出口跑在后台（有阶段文案），进行中不可重复提交、不渲染「取消」，完成后预览仍可用。

### 多表与关系

- [ ] 「场景模板 ▾」6 套都能载入工作副本并「生成 N 张表」，一张表一个 tab；
- [ ] 「＋ 加表（当前草稿）」把草稿加进本次生成；重名与空列被拒；
- [ ] 「编辑表」改行数后关系行的取值域跟着变；改表名同步所有指向它的关系；
- [ ] 「✕ 删表」连带清掉指向它的关系并报出条数；出边随表消失；
- [ ] 「＋ 加关系」父列只列自增列；四处选齐才可「添加」；
- [ ] 只落子表时，结果表头 / 出口区给「引用了 …」warning；「落库这 N 张」依次落库、同名的跳过并报出。

### 历史与模板

- [ ] 成功生成后历史多一条（失败 / 取消不记）；「重放」把配置写回草稿；「删除」即时生效；
- [ ] 场景生成不写历史，面板里有对应说明；
- [ ] 「保存为模板…」只问名字；「应用」铺回配置但**不改目标表名**；「删除」生效；切项目后看到的是另一个项目的记录。

### 只读与安全

- [ ] 只读项目：生成与预览可用；四个出口都被拒绝并提示原因；分析库零写入；
- [ ] 面板底部常显「不回传源库」那一句；
- [ ] 参数护栏：把区间 / 权重 / 掩码 / 日期串写坏，生成前就被拦下并说清是哪一列哪个字段；
- [ ] 出口后 `analytics.duckdb` 里既有表的数据没有被改动（同名不覆盖、追加只增行）。

### 主题与尺寸

- [ ] 明暗两套主题下面板与对话框配色正常（取 `cx.theme()`，无硬编码色值）；
- [ ] 右 Dock 可拖拽调宽；中央 tab 与编辑器 tab 混排正常（一表一 tab，切 tab 即切表）。
