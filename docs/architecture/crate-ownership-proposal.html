建议新增 / 迁移 资产，不建 crate App Shell 职责
主题为什么不做 crate：无独立状态（状态在 gpui-kit 的 Theme global）、无业务生命周期，内容是 JSON 资产 + 少量加载代码（App Shell）+ 一个切换命令（settings 的「外观」节）。
设置为什么做 crate：有独立状态（设置项 model）、生命周期（持久化）、稳定公开边界（设置服务 + 打开设置命令）、多使用方——符合 coding-guides 的 settings 示例结构（lib.rs / model.rs / settings_view.rs / commands.rs）。
文档目录：设计决策（布局 / 主题配色 / settings）统一放 docs/architecture/{layout, theme, settings}/（方案 A，导航见 README.md），实现说明随代码（注释 + PR + 文档尾部映射表），crate 目录不承担文档仓库职责。
