# 草稿箱模块（M5）· 使用手册

> 面向**使用者与验收人员**：这个面板怎么用、每个按钮做什么、出问题怎么排查。
> 设计与实现看 `scratchpad-architecture.md`（权威）与 `scratchpad-prototype-design.md`（视觉规格）。
>
> **能力期次标注**：本文写的是**已落地**能力（Phase A/B，2026-09-15）。标 `Phase C` / `Phase D` 的段落是**尚未接线**的预期形态，请勿按此验收。

## 1. 这个面板能做什么

草稿箱是**项目内的临时工作区**：随手写 SQL、放脚本、导入数据文件、引用项目外的大文件，都放这里。它的根就是项目下的 `scratchpad/` 目录——**你在面板里看到的，就是磁盘上真实存在的文件**。

| 能做 | 不能做（属别的模块） |
| --- | --- |
| 新建 / 重命名 / 移动 / 复制（含文件夹递归）/ 删除（进回收站） | 编辑文件内容（`Phase C` 接中央编辑器） |
| 导入外部文件（复制进来）、引用外部路径（只记路径） | 归档为只读存档（`Phase D`，属资产库 M6） |
| 搜索文件名、搜内容（正则/大小写）、批量替换 | 连接数据库、跑数据（属数据源模块） |
| 回收站还原 / 清空 | 跨项目共享草稿（设计上不支持） |

### 1.1 什么该放草稿箱、什么不该

| 放草稿箱 | 放别处 |
| --- | --- |
| 随手写的 SQL、试验脚本、一次性笔记 | 需要长期留存、要能被引用的产物 → 资产库（`Phase D` 归档） |
| 临时测试数据（会随项目一起走） | 几个 GB 的外部数据集 → 用**引用**（不要导入，否则项目体积爆炸） |
| 导入后要改的小文件 | 需要多人共享/版本管理的文件 → 项目自己的 git 仓库 |

## 2. 入口

| 入口 | 位置 | 前提 |
| --- | --- | --- |
| 左侧活动栏「草稿」图标 | 打开左侧 Dock | 已打开项目 |
| `Ctrl+P` → 输入「草稿」 | Quick Open | 同上 |
| 项目工作区默认 | 左侧 Dock 默认停在草稿箱或数据源面板（看上次选择） | 同上 |

- **未打开项目**时面板显示提示：草稿箱根即项目目录，请先打开/新建项目。
- **项目已打开**时，若之前已存在 `scratchpad/` 目录，内容直接列出；不存在则首次写入时自动创建。
- 项目以**只读**打开（同项目被别的实例占用，选了「只读打开」）时，面板可用但所有写操作被拒绝。

## 3. 界面导览

### 3.1 整体解剖（240 px 左 Dock）

```
草稿箱（240 px 左 Dock）
├─ 工具栏第 1 行：＋ 新建文件 · 🗀 新建文件夹 · ⬇ 导入 · 🔗 引用 …… ⇅ 排序 · ↻ 刷新
├─ 工具栏第 2 行：✂ 剪切 · ⧉ 复制 · 📋 粘贴 · 🗑 删除（有选中或剪贴板时出现）
├─ 搜索行：[文件名] 搜索…  ·  [.*]（正则） [Aa]（大小写） [⏎]（运行）
├─ ▼ 草稿 · 4
│    ├─ ● data/（文件夹，展开后显示子项）
│    ├─ ● 临时订单分析.sql   1.2 KB · 2 分钟前   ← 选中行显示 ↗ ✎ ✕
│    └─ ● transform.py       1 小时前
├─ ▼ 外部引用 · 2
│    ├─ ● 下载数据            D:\data          ↗ ✎ ✕
│    └─ ● 月度报表（丢失）     E:\moved\…       ↗ ✎ ⟲ ✕   ← 失效：置灰 + 重新引用
├─ ▶ 回收站 · 3（展开后逐条「还原」；头部「清空」不可恢复）
└─ 底部状态：4 个文件 · 2 个文件夹 · 2 项引用 · 3 项回收站 · 排序 名称 ↑
```

> 图标说明：● = 文件类型色点（§3.2）；草稿树是面板**唯一滚动区**，引用/回收站固定在下方并各自限高可滚。

### 3.2 一行怎么读

| 位置 | 含义 |
| --- | --- |
| 行首 `▸/▾` | 文件夹是否展开（点击行即展开/折叠） |
| 双击 | 文件：在中央编辑器中打开（同路径只激活，不重读）；文件夹：展开折叠 |
| 色点 | 类型：文件夹 `warning`（琥珀）· SQL `info` · Python `success` · 数据文件与 JSON（`.csv/.tsv/.parquet/.xlsx/.xls/.json/.ndjson/.db/.duckdb`）`primary` · 其他 `muted` |
| 文件名后的实心圆点 | **脏点**：该文件在中央编辑器里有未保存修改（只有文件会打点；文件夹不打；位置与原型 §2 一致：名字 · ● · 大小时间） |
| 文件名 | 点击 = 选中（再点文件夹同时展开/折叠） |
| 行尾 `大小 · 相对时间` | 文件显示大小与相对时间（刚刚/N 分钟前/N 小时前/N 天前/日期）；文件夹只显示时间 |
| 选区底色 + 左侧珊瑚条 | 选中（支持多选） |
| 选中行右侧 `↗ ✎ ✕` | 打开所在位置 / 重命名 / 删除（只对选中行显示，避免噪声） |

### 3.3 两个分组：草稿与回收站之间是「外部引用」

| 分组 | 内容 | 操作 |
| --- | --- | --- |
| **草稿** | 模块根下的真实文件/文件夹（懒加载） | 双击/`Enter` 打开到编辑器、`F2`、`Del`、右键菜单 |
| **外部引用** | 别名 + 外部路径（不复制本体） | `↗` 打开位置 · `✎` 改别名 · `⟲` **仅失效时出现**，重新指向 · `✕` 移除 |
| **回收站** | 项目级回收站条目（含来源模块标签） | 展开后逐条「还原」；头部「清空」不可恢复 |

## 4. 典型流程

### 4.1 新建一个 SQL 草稿（3 步）

1. 点工具栏 `＋`；
2. 内联输入框里填名字（如 `订单分析`），下面一排模板 chip 点 `SQL` → 框里自动变成 `订单分析.sql`；
3. `Enter`（或 `✓`）提交 → 文件创建并填入 `-- 订单分析.sql … SELECT 1;` 占位内容。

> **落点规则**：先选中某个文件夹再点 `＋`，内联框会出现在**该文件夹内部**（并自动展开）；未选中文件夹则建在模块根。`🗀` 新建文件夹同理。

### 4.2 打开一个草稿来编辑（双击）

1. **双击**文件名（或选中后按 `Enter`，或右键选「打开」）；
2. 文件在**中央编辑区**新标签中打开；
3. 若该文件已在编辑器中打开过 → **只激活那个标签，不重读**（不会冲掉你未保存的修改）；
4. 打开失败（文件被删/权限不足）→ 通知栏给出原因。

> **连接预选与回写**（已接）：该草稿记过「绑定 / 最近执行」的数据源连接时，打开即自动选中那个连接（已删除的连接不预选）；在编辑器里跑一次之后，用过的那个连接会被记下（下一次打开用它）——均只存**连接 ID**，凭据不在草稿里。
> **脏点**（已接）：一改东西，树上的文件名前会出现圆点；`Ctrl+S` 存回后消失（最迟 1.2 s 内刷新）。
> 编辑与保存（`Ctrl+S` 回存）本身在**编辑器**里（草稿箱不做回存）。

### 4.3 导入一个外部文件（复制进来）

1. 点 `⬇ 导入`；
2. 系统文件对话框里选一个或多个文件 → 确定；
3. 文件被**复制**进 `scratchpad/`（同名自动改名：`x.csv` → `x_copy.csv`）。

> 导入 = 本体进入项目，**计体积、随项目迁移**。几个 GB 的文件请改用「引用」。

### 4.4 引用一个外部目录（不复制）

1. 点 `🔗 引用`；
2. 选**文件或目录** → 内联输入**别名**（默认取名称，可改成好记的名字）→ `Enter`；
3. 引用行出现，`↗` 可跳到系统文件管理器。

之后目标被移动/删除时，该行会置灰并显示「（丢失）」，点 `⟲` 重新选路径即可恢复（**别名不变**）。

### 4.5 移动、复制、批量操作

| 目标 | 操作 |
| --- | --- |
| 多选 | `Ctrl` 点选、`Shift` 范围选、`Ctrl+A` 全选（已加载条目） |
| 剪切移动 | 选中 → `✂` → 选中目标文件夹（或不选） → `📋`；移动是**真移动**，`file_meta` 随文件走 |
| 复制 | 选中 → `⧉` → `📋`；生成 `名字_copy`（同目录再来一次是 `_copy_1`）；**文件夹会整棵复制** |
| 打开所在位置 | 选中行的 `↗` 或右键「打开位置」 |
| 重命名 | `F2` 或行内 `✎` 或右键「重命名」 |
| 删除 | `Del`、行内 `✕` 或右键「删除」 |

> 复制/粘贴的目标是"当前唯一选中的文件夹"，否则是模块根；**不允许**把文件夹复制到它自己的子树里。

### 4.6 删除与撤销（重要）

1. `Del` 删除 → 条目进入**项目级回收站**，面板底部弹出撤销栏；
2. **5 秒内**点「撤销」可一键还原（本次删除的全部条目）；
3. 错过 5 秒也不怕：展开「回收站」分组 → 找条目 → 点「还原」（回到原路径；若原路径已被占用会自动改名）。

`回收站 · 清空` 是**不可恢复**操作，请确认后再点。

### 4.7 搜索文件名

- 左侧 chip 显示 `文件名`（默认）时，在输入框输入片段即可**实时过滤**树；
- 命中子树的父文件夹会自动展开；
- 清空输入框恢复完整树。

### 4.8 搜索内容（结果落到中央编辑区）

1. 点左侧 chip 切到 `内容`；
2. 需要时点 `.*`（正则）、`Aa`（区分大小写）；
3. 输入关键词 → `Enter`（或点 `⏎`）；
4. 结果出现在**中央编辑区**：`文件 · 行号` + 命中行 + 前后各 2 行上下文，命中文本带底色高亮；
5. **点命中标题（`文件 · 行 号`）即打开该草稿**到编辑器（跳行待编辑器跳行端口）；
6. 结果头部显示 `N 处匹配 · 扫描 M 个文件`；命中过多会标「已截断」（上限 500 条），点「关闭」收起。

> 搜索范围是草稿箱目录树（深度上限 4 层）；单个文件超过 30 秒会跳过，不拖住整体。

### 4.9 批量替换（在搜索结果面板内）

1. 按 §4.8 搜出结果；
2. 在结果面板的「替换为」输入框里填替换内容；
3. 点「全部替换」（输入为空时按钮禁用）；
4. 面板会**逐文件原子写回**并自动刷新结果，状态栏提示「已替换 N 处（M 个文件）」。

- 正则模式下替换串支持 `$1` 分组引用；字面量模式不解析 `$`（写 `$` 就是 `$`）。
- 区分大小写跟随搜索栏的 `Aa` 开关。
- 只读项目下会被拒绝并提示。

### 4.10 键盘导航

点击面板任意一行会**把焦点交给面板**，之后：

| 按键 | 行为 |
| --- | --- |
| `↑` / `↓` | 上下移动单选（自动滚入视口） |
| `Enter` | 同上 | 文件：在编辑器中打开；文件夹：展开/折叠 |
| `Ctrl+N` | 新建文件（落点规则同 §4.1） |
| `Ctrl+A` | 全选已加载条目 |
| `F2` | 重命名唯一选中项 |
| `Delete` | 删除选中（进回收站 + 撤销栏） |
| `Esc` | 取消内联编辑 |

### 4.11 冲突：磁盘被外面改了，而我还改着（重要）

1. 你在编辑器里改了一个草稿还没 `Ctrl+S`，同时这个文件被外部改了（另一个工具、脚本、或者你自己在外部编辑器里改）；
2. 左侧草稿箱工具栏下方会出现**冲突条**：`冲突：<文件名>` + 三个按钮；
3. 选一个：
   - **差异**：行级对比投到**中央编辑区**（左 = 磁盘、右 = 你手里那份，行号 + 红/绿）——先看清楚再决定；
   - **重载**：丢掉你的缓冲，用磁盘上的内容重新加载（冲突消失）；
   - **忽略**：保留你改的；下次磁盘再变才会重新报冲突。

> 判据是**内容**不是时间：两边内容一样（比如外部改动已经被写回）就不会报冲突；
> 「差异」按钮在差异算好之前是置灰的（后台在读盘对比，界面不会卡）。

### 4.12 拖一个草稿到编辑器里（插入内容）

1. 抓住草稿树里的**文件名**，拖到中央编辑器的文本区（拖拽时跟随一个写着文件名的幽灵）；
2. 松手 → 该文件的内容**插到光标处**（有选区则替换选区），状态栏提示「已插入 <文件名>」；
3. 只读文档会拒绝并告诉你原因；空文件、读盘失败也会给消息（不静默）。

> 只对**文件**有效（文件夹拖不动）；插入后文档变脏，`Ctrl+S` 才真正写回磁盘。

## 5. 速览：一次操作落到哪

| 你的操作 | 磁盘上发生了什么 |
| --- | --- |
| 新建文件/文件夹 | `scratchpad/` 下出现真实文件/目录（模板会写入占位内容） |
| 导入 | 文件被复制进 `scratchpad/` |
| 引用 | **不动磁盘**；只在 `.RSmeta/scratchpad/config.json` 多一条 `external_references` |
| 改别名 / 重新引用 | 只改 `config.json` 里的引用记录 |
| 重命名 / 移动 | 真实 `rename`；`config.json` 里 `file_meta` 的键跟随迁移 |
| 复制 | 真实复制（文件夹整棵）；`_copy` 命名避让 |
| 删除 | 条目被**移动**到 `.RSmeta/trash/<id>/{payload,manifest.json}` |
| 还原 | 从回收站移回原路径（同名自动改名） |
| 清空回收站 | 删除 `.RSmeta/trash/` 下对应条目，不可恢复 |
| 替换 | 命中的文件被原子写回（无命中不写盘） |
| 内容搜索 | **只读**，不改任何文件 |

## 7. 只读与数据安全

### 7.1 只读从哪来，表现是什么

项目被判定为**只读**（同项目根的另一个实例持有 `ProjectLock`，你选了「只读打开」）时：

- 面板照常浏览、搜索；
- 新建 / 重命名 / 删除 / 粘贴 / 替换 / 引用增删改**全部被拒绝**，状态栏给出「只读模式：不允许…」提示。

### 7.2 能不能手工动 `scratchpad/` 目录

**可以**，这正是"可见模块目录"设计的意图：

- 用系统文件管理器增删改文件，草稿箱会在 ~1.2 s 内**自动同步**（文件监控）；也可随时 `↻` 立即刷新；
- 但 `.RSmeta/scratchpad/config.json` 引用与元数据**不会自动跟着变**——手工把文件挪走，面板可能仍记得它的连接绑定（无害，下次同名文件会复用）；
- **不要手工编辑 `.RSmeta/` 下的文件**（回收站清单、配置）；改坏了不影响草稿内容本体，但会丢失引用与元数据。

### 7.3 备份与版本控制

- 备份 = 复制整个项目目录（含 `scratchpad/` 与 `.RSmeta/`）；
- 想给草稿做版本控制，可在**项目根**初始化 git 并忽略 `.RSmeta/`（草稿箱自身不做版本）；
- 迁移项目到另一台机器：直接搬整个目录即可，`file_meta` 用的是相对路径，不会失效；**引用**指向的是本机绝对路径，可能需要在目标机 `⟲` 重新指定。

### 7.4 磁盘占用

- 面板底部状态行给出文件/文件夹/引用/回收站计数，**不统计体积**；
- 占用 = `scratchpad/` 实际大小 + `.RSmeta/trash/`（回收站里的是完整副本，长期不清会一直占着）。

## 8. 常见问题与排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 面板显示「未打开项目：草稿箱根即项目目录」 | 没有打开项目 | 转项目管理打开/新建项目 |
| 面板显示「加载草稿箱失败: …」 | 目录不可读/不可写（权限、网盘、盘符不存在） | 检查项目目录权限；确认盘符在线后 `↻` |
| 点 `＋` 后内联框位置不对 | 之前选中了某个文件夹 | 落点跟随选中；先点空白处或取消选中再新建 |
| 新建提示「操作失败: … already exists」 | 同名已存在 | 换个名字（面板不会自动覆盖） |
| 粘贴报「不能把文件夹复制到自身内部」 | 目标就是源文件夹或其子树 | 选择别的目标目录 |
| 复制出来的名字是 `xxx_copy` | 同名避让规则 | 手动重命名即可 |
| 文件行没有 `↗ ✎ ✕` | 只有**选中**行才显示 | 先点选中该行 |
| 引用行显示「（丢失）」且置灰 | 目标被移动/删除 | 点 `⟲` 重新选路径（也可 `✕` 移除） |
| 搜索内容没结果 | 关键词不在 ≤4 层目录内 / 文件非 UTF-8（被跳过） | 缩小到已知文件手动确认；二进制文件不参与文本搜索 |
| 结果标「已截断」 | 命中超过 500 条 | 加长关键词或开 `Aa`/`.*` 缩小范围 |
| 改了文件但面板没变 | 已不再需要手动刷新：监听服务会把外部改动去抖重拉（~1.2 s），**结果面板若开着会一并重跑搜索** | 等一拍；若长期不刷新（网络盘/监控不可用）就点 `↻`（此时是预期降级） |
| 在外部编辑器里新建的文件会自动出现 | 正常（文件监控） | 想关掉监控需改代码；当前无开关 |
| 展开的文件夹突然空了 | 历史问题（缓存被清空）**已修**：重载会保留并刷新已展开子目录 | 若仍复现请按缺陷反馈 |
| 状态行显示「加载中…」很久 | 读盘在后台线程（大目录 / 网络盘 / 盘符脱机），此时界面不会冻结 | 稍等或切走该面板；确认盘符在线后点 `↻` |
| 导入/粘贴大文件时界面仍然能用 | 正常：导入、粘贴、清空回收站、搜索、替换都在后台线程执行 | 完成后通知栏给出结果；大任务期间可继续浏览其他面板 |
| 点「全部替换」后短暂显示「替换中…」 | 正常：替换在后台一次完成（匹配 → 写回 → 重搜） | 结果到达后通知栏显示「已替换 N 处（M 个文件）」 |
| 面板先空白一下再出内容 | 正常：首次进入是先出骨架再等首次加载结果（避免错误地显示「草稿箱是空的」） | 无需处理 |
| 替换按钮点不动 | 「替换为」为空（按钮禁用） | 先填替换内容 |
| 替换后提示失败 | 某文件被外部程序占用/只读 | 关闭占用程序；确认项目非只读 |
| 状态栏提示「只读模式：不允许…」 | 项目只读打开 | 关闭另一个实例后重新打开项目 |

## 9. USIT 验收清单（可勾选）

### 基础与空态
- [ ] 未打开项目：面板给出引导文案，不崩溃
- [ ] 空草稿箱：显示大图标 + 「＋ 新建 / 🗀 文件夹 / ⬇ 导入」
- [ ] 打开有内容的项目：树按目录正确列出，文件夹带箭头

### 打开与编辑器
- [ ] 双击文件 → 中央编辑器新标签中打开
- [ ] 再次双击同一文件 → **只激活已有标签**，不重读（不冲掉未保存修改）
- [ ] 已绑定过连接的 SQL 草稿 → 打开时连接下拉已选中该连接
- [ ] 在编辑器里跑一次 → 关掉再打开该草稿，连接仍是刚才那个（`last_connection_id` 已回写）
- [ ] 在编辑器里改动未保存 → 树上一行文件名前出现**脏点**；`Ctrl+S` 后脏点消失
- [ ] 在编辑器里改动未保存、同时用外部编辑器改同一文件并保存 → 左侧出现**冲突条**
- [ ] 点冲突条「差异」→ 中央区出现红/绿行级对比（左=磁盘，右=编辑器）
- [ ] 点「重载」→ 编辑器里的内容换成磁盘版、冲突条消失、脏点消失
- [ ] 再制造一次冲突并点「忽略」→ 冲突条消失，但编辑器里你改的内容还在
- [ ] 选中文件按 `Enter` / 右键「打开」→ 同上
- [ ] 文件夹双击/`Enter` → 展开折叠（不会进编辑器）

### 新建与模板
- [ ] `＋` 内联输入，`Enter` 提交、`Esc` 取消
- [ ] 选 `SQL` 模板 → 自动补 `.sql` 且文件内有占位内容
- [ ] 切换模板时模板后缀被替换；手写的 `.txt` 后缀不被改写
- [ ] 先选中文件夹再新建 → 文件落在该文件夹内且该文件夹自动展开
- [ ] `Ctrl+N` 等价于 `＋`

### 树与选择
- [ ] 点击行选中：底色 + 左侧珊瑚条；悬停有底色
- [ ] `Ctrl` 点选、`Shift` 范围选、`Ctrl+A` 全选
- [ ] 选中行出现 `↗ ✎ ✕`，未选中行不显示
- [ ] 展开文件夹按需加载；`↑↓` 移动并滚入视口

### 文件与文件夹操作
- [ ] `F2` 重命名（行内输入，空值不提交）
- [ ] `✂` + `📋` 移动到目标文件夹；目标有同名会被拒绝
- [ ] `⧉` + `📋` 复制文件与**文件夹（整棵）**；重名生成 `_copy`
- [ ] 文件夹复制到自身子树被拒绝并给出提示

### 导入与引用
- [ ] `⬇ 导入` 多选文件 → 出现在模块根，磁盘上真实存在
- [ ] `🔗 引用` 选文件或目录 → 可自定义别名
- [ ] 引用行 `↗` 打开位置、`✎` 改别名、`✕` 移除
- [ ] 把引用目标移走 → 该行置灰 + 「（丢失）」+ 出现 `⟲`
- [ ] `⟲` 重新引用后恢复可用，别名不变

### 删除与回收站
- [ ] `Del` 删除 → 底部撤销栏 5 s 内可撤销
- [ ] 撤销栏 5 s 后自动消失；回收站里能看到条目
- [ ] 回收站「还原」回到原路径；原路径被占用时自动改名
- [ ] 「清空」后条目消失且不可恢复

### 搜索与替换
- [ ] 文件名模式实时过滤，命中子树自动展开
- [ ] 内容模式：`.*` 正则、`Aa` 大小写、`⏎` 执行
- [ ] 结果落中央编辑区，命中文本有底色高亮，头部计数正确
- [ ] 点命中标题 → 对应草稿在编辑器里打开（同一个文件再点 → 只激活）
- [ ] 拖草稿文件名到编辑器文本区 → 内容插到光标处，状态栏提示「已插入 …」
- [ ] 「替换为」+「全部替换」生效，结果自动刷新，状态栏有汇总
- [ ] 只读项目下替换被拒绝并提示

### 只读与边界
- [ ] 只读打开时新建/重命名/删除/粘贴/替换均被拒绝并提示
| 手工在磁盘上删掉 `scratchpad/` 里的文件 → `↻` 后树同步 | 无需 `↻`：面板在 ~1.2 s 内自动同步 |
