每个项目自带的草稿区：
看得见、跟项目走、和编辑器与数据源打通

草稿箱不是应用级的临时回收站，而是项目目录里一个看得见的文件夹 （{项目}/scratchpad/）。随手写的 SQL、拉下来的测试数据、待整理的脚本都放这里： 它随项目一起备份、迁移、进版本库；内部元数据与回收站收在 .RSmeta/ 里， 面板永远不必过滤自己的内部文件。

核心特点

每一条都能在代码里指到落点（见文末文档索引）。

📁可见的模块根

草稿就是项目里的普通文件。内容在 {项目}/scratchpad/， 内部态（引用 + 文件元数据）在 .RSmeta/scratchpad/config.json，回收站在 .RSmeta/trash/； 旧版 .scratchpad/ 一次性迁移（幂等、非破坏、同名不覆盖）。

⬇导入 vs 🔗 引用：两种语义分得清

导入＝复制进草稿箱（计入项目体积、随项目迁移）； 引用＝只记绝对路径 + 别名（不复制、可能失效）。 失效项置灰并标「（丢失）」，可 ⟲ 重新指向、改名、在文件管理器里打开。

🗑项目级回收站 + 5 秒撤销

删除进项目回收站（带来源模块与原始相对路径），还原只接受草稿箱自己的条目； 删除后底部出现撤销栏，5 秒后自动消失，点一下即还原。

🔍两种搜索：文件名 / 内容

文件名模式实时过滤并自动展开命中子树；内容模式支持正则与大小写， 命中带前后各 2 行上下文、行内高亮，500 条截断、单文件 30 秒超时。 结果落在中央编辑区，侧栏只承载输入与开关。

🛠批量替换，原子写回

结果面板内嵌替换栏：先给预览计数（「将替换 N 处 · M 个文件」）， 再一次性「匹配 → 逐文件写回 → 重新搜索」，无命中不写盘，正则支持 $1， 字面量模式不解析 $；只读项目直接拒绝。

📝双击就进编辑器

双击 / Enter / 右键「打开」→ 中央编辑器；同路径只激活不重读， 不会冲掉未保存的修改。打开时按草稿记过的连接预选数据源， 在编辑器里跑一次查询后，用过的连接会被回写记住。

●脏点回显

编辑器里有未保存修改的草稿，树上行尾出现圆点（只有文件打点）； Ctrl+S 存回后自动消失，最迟 1.2 秒内刷新——不用切面板也知道谁还没存。

⚖冲突不靠猜：内容说了算

磁盘被外部改了、而编辑器里还改着 → 侧栏出现冲突条： 「差异」把行级对比投到中央编辑区（左=磁盘 / 右=编辑器，行号 + 红绿）， 「重载」照磁盘重来，「忽略」保留手头的改动。判据是内容不是时间戳—— 外部改动其实已被写回时不会误报。

🖱拖进编辑器就插入

抓住草稿文件名拖到编辑器文本区 → 文件内容插到光标处（有选区则替换）。 载荷只带路径，内容在落下那一刻才读——中途放弃不留负担。

⌨键盘与右键都顺手

Ctrl+A 全选 · F2 重命名 · Del 删除（带撤销）· Ctrl+N 新建 · ↑↓ 导航（自动滚入视口）· Esc 取消内联编辑 · 右键菜单：打开 / 打开位置 / 重命名 / 剪切 / 复制 / 删除。多选支持 Ctrl 点选与 Shift 范围。

⚡界面永不发卡

渲染期零 I/O：加载、导入、粘贴、清空回收站、搜索、替换、差异计算全部入队到 单个后台工作线程（tokio 运行时），视图 60 ms 轮询回填，请求序号丢弃过期结果； 树用虚拟列表只画可视区行。

🔒安全与边界写死在代码里

路径防护拒绝 .. 穿越与点前缀内部路径；只读项目全禁写并给原因； 草稿只存连接 ID，凭据始终在凭据库（AES-256-GCM）； 颜色一律取主题 token，尺寸登记在 workbench_shell/src/ui.rs。

三条主流程

从左到右读；标绿的是已落地环节。
① 草稿自身的闭环
＋ 新建（模板：空白/SQL/Python/Markdown/JSON）→ 🗀 落点＝选中文件夹（否则模块根）→ ✂ ⧉ 📋 剪切 / 复制（文件夹递归）→ 🗑 删除 → 项目回收站 + 5s 撤销栏→ ↻ 还原 / 清空（只认草稿来源）
② 与编辑器 / 数据源联动
双击打开（同路径只激活）→ 按 file_meta 预选连接→ 执行查询→ 回写「最近用的连接」→ Ctrl+S 存回→ 脏点随存消失→ 外部改动 → 冲突条 → 差异 / 重载 / 忽略
③ 找东西与批量改
文件名过滤（命中子树自动展开）或 内容搜索（.* 正则 / Aa 大小写 / ⏎）→ 结果落中央编辑区（上下文 + 行内高亮）→ 点命中标题打开该草稿→ 替换栏：预览计数 → 全部替换 → 自动刷新

铁律：scratchpad 不依赖 workbench（宿主能力经 ScratchpadHost 端口注入）· .RSmeta 不经 API 读写（点前缀路径一律拒绝）· 状态不放进程单例（项目态挂在窗口）· render 只读（I/O 走事件路径或后台任务）。

3 分钟上手

1新建

工具栏 ＋，输名字、点模板 chip（自动补后缀），Enter 提交。 想放进某个文件夹就先选中它。

2写与跑

双击打开 → 在中央编辑器里写 SQL → 执行（连接会自动预选上次那个）→ Ctrl+S 存回。

3找与改

搜索行切到「内容」模式，开 .* 或 Aa，⏎ 运行； 点命中标题跳到文件，或在替换栏一次改完。

4出事时

删错了 → 撤销栏点一下；外部改了又冲突 → 冲突条看差异后选「重载」或「忽略」。

怎么验证它没坏

# 类型检查（必须 -j 2：并发链接重型 crate 会耗尽内存）
cargo check -p rds-scratchpad -p rds-workbench -p rds-app --all-targets -j 2

# 模块单测：域逻辑 + 面板纯函数 + 后台任务（36 项）
cargo test -p rds-scratchpad -j 2 --lib

# 宿主侧联动（回执 → 相对路径映射、编辑器插入等）
cargo test -p rds-workbench --lib -j 2
cargo test -p rds-editor -j 2 --lib     # 217 项，含编辑器侧回归
单测不覆盖窗口级交互（多选、剪贴板、虚拟列表、冲突条），那部分按使用手册 §9 的验收清单人工走。
