# RdataStation 设计规范

> 本文档是 RdataStation-v2 的 UI 设计权威规范。技术实现细节见 `gpui-kit-dev` skill，布局结构见 `rds-layout` skill。

---

## 一、设计原则

### 1.1 克制原则

- **一屏之内视觉焦点不超过 2 个**：当前任务 + 当前选中项
- **颜色不超过 3 种主色**：品牌色 + 成功/警告/错误语义色
- **动效只用于解释变化**：不做常驻装饰性动画

### 1.2 一致性原则

- 同类组件样式统一（所有工具栏高度一致、所有 Tab 样式一致）
- 同类间距统一（4px 网格，不允许 6px、10px）
- 同类交互反馈统一（hover/选中/disabled 态的视觉变化幅度一致）

### 1.3 层级原则

视觉层级从高到低：

1. **激活/选中**：品牌色背景或左侧 2px 高亮条
2. **可交互**：hover 时背景色变化 10-15%
3. **静态信息**：普通对比度
4. **辅助/弱化**：`muted_foreground` 颜色

## 二、间距系统（4px 网格）

所有间距必须是 4 的倍数：

| 常量 | Tailwind 类 | 值 | 用途 |
|---|---|---|---|
| `GAP_SM` | `gap_1` | 4px | 最小间距（icon 与文字、紧凑列表） |
| `GAP_MD` | `gap_2` | 8px | 标准间距（控件之间、表单字段） |
| `GAP_LG` | `gap_3` | 12px | 中等间距（分组之间、卡片内边距） |
| — | `gap_4` | 16px | 大间距（区块之间、对话框内边距） |
| — | `gap_6` | 24px | 超大间距（页面级分隔） |

**禁止**：`gap_1p5`（6px）、`gap_2p5`（10px）等非 4 倍数。

**换算规则**：
- `gap_1p5` → `gap_1`（4px）或 `gap_2`（8px）
- `gap_2p5` → `gap_2`（8px）或 `gap_3`（12px）

## 五、交互反馈规范

### 5.1 状态视觉变化

| 状态 | 视觉变化 | 说明 |
|---|---|---|
| hover | 背景色变化 10-15% | 可点击元素才有 |
| 选中 | 背景色变化 20-25% + 左侧 2px 高亮条 | 当前激活项 |
| disabled | 透明度 50% + 禁止点击 | 不可用状态 |
| focus | 1px 外边框（主题色） | 键盘焦点 |
| pressed | 背景色加深 5% | 按压反馈 |

### 5.2 动效规范

**原则**：动效只用于解释变化，不做常驻装饰性动画。

| 场景 | 时长 | 缓动函数 | 说明 |
|---|---|---|---|
| 对话框弹出 | 200ms | ease_out | 淡入 + 轻微上移 |
| 面板展开/收起 | 300ms | ease_in_out | 弹簧效果 |
| 通知弹出 | 150ms | ease_out | 从右侧滑入 |
| 通知消失 | 200ms | ease_in | 淡出 |
| 连接中徽标呼吸 | 1500ms 循环 | bounce | 仅暂态（建连/预热中） |

**禁止**：
- 常驻循环动画（已完成状态还在呼吸）
- 手搓 `request_animation_frame`（用 gpui-kit 的 `Animation` / `with_animation`）
- 超过 300ms 的入场动画（会让用户觉得慢）

## 七、常见反模式（禁止）

1. **手搓间距**：`div().p(7px)` 这种魔法数字，必须用标准 `gap_2` / `gap_3`
2. **字号混乱**：同一个页面出现 4 种以上字号
3. **视觉噪声**：一屏之内 5 个以上"高亮"元素，不知道该看哪个
4. **交互反馈缺失**：列表项 hover 没反应，选中态和普通态一样
5. **组件不一致**：同样是"工具栏"，左边 32px 右边 36px

## 八、可访问性规范

### 8.1 对比度（WCAG AA）

- 正文文字对比度 ≥ 4.5:1
- 大文字（18px+ 或 14px Semibold）对比度 ≥ 3:1
- 交互元素（按钮、输入框）对比度 ≥ 3:1

**检查方法**：
- `foreground` on `background`：必须 ≥ 4.5:1
- `muted_foreground` on `background`：必须 ≥ 4.5:1（不能太淡）

### 8.2 键盘可达性

- 所有可点击元素必须可通过 Tab 键聚焦
- Enter/Space 可激活
- 优先用标准组件（`Button` / `Tab` / `ListItem`），自带键盘可达性
- 禁止用自绘 `div().on_click()` 替代 `Button`

### 8.3 屏幕阅读器

- 图标按钮要有 `label` 描述
- 纯装饰元素要标记为 `aria-hidden`
- 状态变化要通知屏幕阅读器（如"已连接"）

## 九、文案规范（ux-writing）

### 9.1 按钮文案

| 场景 | 推荐 | 避免 |
|---|---|---|
| 主操作 | 「保存」「连接」「执行」 | 「确认」「好」「OK」 |
| 取消操作 | 「取消」 | 「算了」「不」 |
| 危险操作 | 「删除」「断开」 | 「确定删除？」 |
| 辅助操作 | 「应用」「重置」 | 「应用并保存」（太长） |

**原则**：
- 动词开头，说清楚做什么
- 不要用模糊词（「确认」「好」）
- 危险操作要明确（「删除」而不是「确定」）

### 9.2 错误消息

**坏例子**：
```
连接失败：E0061
```

**好例子**：
```
连接失败：无法连接到 localhost:5432，请检查 PostgreSQL 是否运行
```

**原则**：
- 告诉用户发生了什么（人话）
- 告诉用户怎么解决（下一步）
- 技术细节放在详情里（折叠）

### 9.3 空态文案

**坏例子**：
```
暂无数据
```

**好例子**：
```
还没有连接。点击「新建连接」开始。
```

**原则**：
- 说清楚为什么空
- 引导用户下一步做什么
- 给一个按钮（主操作）

### 9.4 通知文案

| 类型 | 语气 | 例子 |
|---|---|---|
| Success | 简洁、正向 | 「已连接到 PostgreSQL」 |
| Warning | 提醒、不恐慌 | 「连接已超时，将在 3 秒后重试」 |
| Error | 明确、给解决方向 | 「连接失败：密码错误」 |
| Info | 中性、说明 | 「正在加载 100 条数据...」 |

## 十、字体系统（typography）

### 10.1 字体选择

- **UI 字体**：系统默认（San Francisco on macOS / Segoe UI on Windows / Roboto on Linux）
- **代码字体**：等宽字体（JetBrains Mono / Fira Code / Cascadia Code）

**避免**：
- Inter（AI 生成的 UI 最爱）
- Arial（太老）
- 花体/装饰性字体（不可读）

### 10.2 字重层级

| 字重 | 用途 |
|---|---|
| Regular（400） | 正文、列表项 |
| Medium（500） | 标题、按钮文字、强调 |
| Semibold（600） | 面板标题、对话框标题 |

**避免**：
- 正文用 Semibold（太重）
- 标题用 Regular（太轻）

### 10.3 行高

| 场景 | 行高 |
|---|---|
| 正文 | 1.5 |
| 标题 | 1.25 |
| 列表项 | 1.4 |

## 十一、AI UI 反模式（额外禁止）

impeccable 专门检测 AI 生成的 UI 特征，我们也加进去：

1. **紫色渐变**——AI 最爱，不要用
2. **卡片嵌套卡片**——所有东西都包卡片，没有层级
3. **bounce/elastic 缓动**——过时，用 ease_out
4. **彩色背景上的灰色文字**——对比度不够
5. **纯黑/纯灰**——应该带色调（偏冷或偏暖）
6. **所有东西都包卡片**——用间距分组，不要用卡片
7. **过度阴影**——用边框区分，不要用大阴影

## 十二、设计审计工作流

参考 impeccable 的 23 个命令，我们建立简化版：

### 12.1 audit（审计）

提交 UI 改动前，跑一遍 Checklist：

- [ ] 间距都是 4 的倍数？
- [ ] 字号层级正确？
- [ ] 颜色用语义 token？
- [ ] 组件用标准组件（Toolbar / ListItem / TabBar）？
- [ ] hover/选中态有反馈？
- [ ] 文案清晰、用户能看懂？

### 12.2 critique（评审）

新功能或大改动时，评审：

- [ ] 视觉层级清晰吗？一屏之内焦点不超过 2 个？
- [ ] 交互反馈明确吗？用户知道点了什么？
- [ ] 空态有引导吗？
- [ ] 错误消息有解决方向吗？

### 12.3 polish（打磨）

发布前最后一遍：

- [ ] 所有间距统一？
- [ ] 所有组件样式统一？
- [ ] 动效一致？
- [ ] 对比度达标？

### 12.4 harden（加固）

边界情况检查：

- [ ] 空数据有提示吗？
- [ ] 加载中有反馈吗？
- [ ] 失败有重试吗？
- [ ] 长文本有截断吗？

## 十三、图标系统规范

### 13.1 图标库

- **图标库**：Lucide Icons（gpui-kit 自带，开源）
- **图标数量**：3000+ 个（完整目录见 `gpui_kit_assets::IconName`）
- **使用方式**：`Icon::new(IconName::Plus).size(px(20.))`

### 13.2 图标尺寸档位

| 档位 | 尺寸 | 用途 | 示例 |
|---|---|---|---|
| XSmall | 12px（`size_3`） | 行内小图标、徽标内图标 | 列表行尾操作 |
| Small | 14px（`size_3p5`） | 工具栏小按钮、状态栏图标 | 状态栏连接状态 |
| Medium | 16px（`size_4`） | 标准按钮图标、列表行内图标 | 工具栏按钮 |
| Large | 24px（`size_6`） | 面板标题图标、空态图标 | 空态大图标 |

### 13.3 图标使用规则

- **图标与文字间距**：4px（`gap_1`）
- **图标颜色**：默认跟随文字色（`foreground`）
- **辅助图标**：用 `muted_foreground`
- **状态图标**：用语义色
  - 成功：`success`（绿色）
  - 警告：`warning`（黄色）
  - 错误：`danger`（红色）
  - 信息：`info`（蓝色）

### 13.4 按类别整理的常用图标

#### 数据库类型
| 数据库 | 图标 |
|---|---|
| MySQL / PostgreSQL / Oracle | `Database` |
| SQLite | `HardDrive` |
| DuckDB / ClickHouse | `DatabaseZap` |
| MongoDB | `Braces` |
| Redis | `MemoryStick` |
| NoSQL 通用 | `Boxes` |

#### 操作按钮
| 操作 | 图标 |
|---|---|
| 新建 / 添加 | `Plus` |
| 删除 | `Delete` |
| 关闭 | `Close` |
| 确认 / 勾选 | `Check` |
| 替换 | `Replace` |
| 刷新 | `RotateCw` / `RefreshCw` |

#### 导航
| 操作 | 图标 |
|---|---|
| 下拉展开 | `ChevronDown` |
| 右箭头 | `ChevronRight` |
| 左箭头 | `ChevronLeft` |
| 查看 / 预览 | `Eye` |
| 外部链接 | `ExternalLink` |

#### 状态提示
| 状态 | 图标 |
|---|---|
| 信息 | `Info` |
| 成功 | `CircleCheck` |
| 警告 | `TriangleAlert` |
| 错误 | `CircleX` |
| 加载中 | `Loader` |

#### 文件/数据
| 类型 | 图标 |
|---|---|
| 文件 | `FileText` |
| 表格 | `Table` |

### 13.5 禁止

- **手搓 SVG 图标**（用 `IconName` 枚举）
- **图标尺寸混用**（同一工具栏 16px，活动栏 20px）
- **图标颜色混乱**（一会儿 `foreground`，一会儿 `muted_foreground`，一会儿自己造色）

## 十五、窗口缩放适配

### 15.1 最小尺寸

| 区域 | 最小值 |
|---|---|
| 左 Dock | 200px |
| 右 Dock | 200px |
| 活动栏 | 48px（不可再缩） |

### 15.2 缩小时的行为

- 窗口宽度 < 800px：右 Dock 自动收起

## 十六、错误状态视觉设计

### 16.1 空态

用 `empty::Empty` 组件：
- 大图标（32px）
- 标题（14px Semibold）
- 描述（12px muted）
- 主操作按钮

### 16.2 加载中

用 `skeleton::Skeleton` 骨架屏：
- 灰色占位块
- 呼吸动画（1.5s 循环）

### 16.3 加载失败

- 错误图标（红色）
- 错误消息（人话）
- 重试按钮

### 16.4 连接失败提示条

- 红色背景（`danger` 10% 透明度）
- 左侧红色竖条
- 错误消息 + 「重试」按钮
