## 8. 选型建议

1. **默认 → 珊瑚石墨**：现役资产就是它的近似版，迁移只需微调，品牌资产零改动。
2. **要「数据库工具」专业感 → 石板深蓝**：与 DataGrip / TablePlus 的心智一致，注意 `info` 已改成青，别和主色蓝混用。
3. **以报表 / EDA / 长文阅读为主 → 暖纸赭石**：暖底对细网格更宽容，但截图、图表色需一并偏暖，否则冷暖打架。
4. **要品牌差异化且偏「洞察」气质 → 松林青绿**：主色与成功色同族，必须保持该套配色表里的明度差，否则在深底上会读成同一个绿。
5. **低光 / OLED / 无障碍 → 近黑墨**：暗色纯黑省电，亮色是高对比版；代价是 chrome 与内容区无灰度差，层级全靠描边。

## 9. 验证与边界

- 对比度：单套单模式 58 项 × 明暗 × 5 套，含正文、次要文字、表头、主色三态、语义四色三态、图表 5 系列、涨跌、产品槽 6 个、选中态合成、语法 6 个代表名。
- 选中底 / 文本选区按 `clamp_alpha` 上限（0.2 / 0.3）给值，超限会被 schema 静默压缩。
- **未做的**：140 键逐项展开（`button.*`、`scrollbar.*`、`base.*` 等由角色推导，尚未生成 JSON）；41 个语法高亮名只核了 6 个代表名；未上真机截图比对。
- 落地某套时的完整步骤：扩 140 键 → `python tools/theme_audit.py`（0 不达标）→ `python tools/gen_theme_preview.py` → 真机明暗切换核对 → 更新 `theme-tokens-complete.md`。
