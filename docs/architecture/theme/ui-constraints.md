> 适用：所有 GPUI 视图代码（`crates/*/src/**` 中的 `Div` / 组件调用）。
> 定位：与 `theme-design.md`（颜色 token）互补——**颜色早已有硬约束，本文件补齐尺寸与排版约束**。
> 代码常量落点：`crates/workbench/src/components/connection_dialog/helpers.rs`（`GAP_*` / `LABEL_W` / `BADGE_*` / …）。

## 1. 字体阶梯（只允许这三档）

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 常规正文 | 组件默认（`Input` / `Select` / `Button` 内建） | 输入内容、按钮文字 |
| 辅助文本 `text_xs` | 0.75rem | 字段标签、提示、分区标题（配 `FontWeight::BOLD`）、徽标、Tab 名 |
| 对话框标题 | gpui-kit `Dialog` 内建 | 仅标题栏 |

规则：
- **禁止任意字号**（如 `px(13.)`、`rems(0.8125)`）；需要更大字号时先补规范再使用。
- 分区标题 = `text_xs` + `FontWeight::BOLD` + `muted_foreground`，与正文区分靠字重与颜色，不靠字号。

## 2. 图标尺寸（三档）

| 档位 | 值 | 用途 |
| --- | --- | --- |
| 小 | 12px | 内联说明图标（如 `reuse_note`） |
| 中 | 14px | 卡片标题、信息条 |
| 大 | 16px | 类型徽标内的 emoji 字号基准 |

## 3. 间距阶梯（只允许这五档）

| 常量 | 值 | 用途 |
| --- | --- | --- |
| `GAP_XS` | 0.25rem | 图标与文字、徽标内部 |
| `GAP_SM` | 0.375rem | 紧密行内元素 |
| `GAP_MD` | 0.5rem | 标签与控件、Header 行间距 |
| `GAP_LG` | 0.75rem | 同一行内的字段之间、侧栏与主区之间 |
| `GAP_XL` | 1.0rem | 卡片之间、区块之间 |

**禁止**：0.4375 / 0.5625 / 0.625 / 0.875 / 1.25（rem）等非阶梯值——存量迁移时归一（0.625 → 0.5、0.875 → 1.0）。

## 4. 控件规格

| 控件 | 高度 | 宽度 | 备注 |
| --- | --- | --- | --- |
| `Input`（单行） | 组件默认 | 弹性或定宽（见下） | 定宽处必须写明理由 |
| `Select` | 组件默认 | 驱动 11rem（`DRIVER_W`） | 类型过滤后的驱动实现 |
| 类型徽标 | 1.5rem（`BADGE_H`） | 1.75rem（`BADGE_W`） | **仅图标**（emoji），不显示文字 |
| 项目栏 | 组件高度 | 17rem（`PROJECT_W`） | **单下拉**（项目名 + 路径双列；末项「＋ 新增项目」），无编辑 / 列表模式切换 |
| 标签列 | — | 1.75rem（`LABEL_W`） | Header 各行标签左对齐；**刚好容纳两字标签**，避免标签与控件间距过大 |
| 暂存条目行 | 1.75rem（`ROW_H`） | 侧栏宽 | 行内：类型徽标 + 名称 + 徽标 + ✕ |
| 作用域分段项 | 1.25rem（`SEG_ITEM_H`） | 内容宽 | 短标签文本 |

## 5. 区域固定尺寸（布局恒定原则）

| 区域 | 尺寸 | 溢出行为 |
| --- | --- | --- |
| 对话框宽 | `font_size × 61.25`（约 980px） | — |
| 侧栏宽 | 12.5rem | — |
| Tab 内容区 | 20.5rem（`TAB_BODY_H`） | 内部纵向滚动 |
| 暂存列表区 | 7.5rem（`STAGING_H`） | 内部纵向滚动 |
| 类型树 | 弹性占满剩余 | 内部纵向滚动 |
| 结果提示行 | 1.125rem（无消息时占位） | 单行 |

**原则**：任何"内容可增长"的区域都必须同时给出**固定高度或弹性上限**与滚动，避免内容撑大对话框（真机反馈过两次）。

## 6. 按钮与可点击元素

| 类型 | 何时用 | 规格 |
| --- | --- | --- |
| gpui-kit `Button`（`primary` / `secondary`） | footer 提交 / 次要动作、管理入口 | 组件默认尺寸；不用 `.size()` 压高度 |
| 自绘文本动作（`+ 添加` / `列表` / `✎`） | 行内轻量动作 | `text_xs` + `cursor_pointer` + hover 变色（`primary` 用于新增类，`muted_foreground` 用于切换类） |
| `tab::TabBar::segmented()` | 三态 / 多态分段（如连接对话框的「作用域」） | 组件自带选中态与键盘；不要自绘分段（旧做法，已于决策 #84 退场） |
| `switch::Switch` | 布尔开关（如「使用 DuckDB 联邦」） | 组件自带；不要自绘轨道 + 滑块 |
| `Checkbox` | 多选（分组） | 组件默认 |

**注意**：RDS 主题至今**未覆盖任何 `button_*` token**（`assets/themes/rds-theme.json` 里一个都没有）——所以用 `Button` 变体（含 `.ghost()`）时**先看一眼对比度**（曾出现“文字不可见仍可点击”）。行内轻量动作可以自绘（走 `theme.colors` 保证对比度）；已有位置换成 `Button::ghost()`（连接对话框侧栏行尾的行删除、资产库面板内多处动作），迁移时同样要过一遍对比度。

**禁用占位规则**（真机反馈）：当控件“暂无数据可选”或“当前不适用”时，**保留控件形态并置为 disabled**（如未选类型时的驱动下拉、仅全局时的项目下拉），而不是换成一行裸文字——避免布局与行高跳变。

**不可用数据项规则**（真机反馈）：列表里的**数据项**因缺少依赖而不可用时，保留整行形态、文字降为 `border` / `muted_foreground` 并降透明，**行尾用 `text_xs` 小字给出原因**（如类型树的「暂无驱动」）；点击**不改变状态**，只在结果行解释原因。下一条可用项与不可用项**行高一致**（不可用项不能变成另一种控件形态）。

**下拉项双列规则**（真机反馈）：当下拉项的“标识”与“区分信息”不同层（如项目名 vs 项目路径、表名 vs 库名）时，选项**一行两列**：左列为主标识（`text_xs` 常态色，`flex_shrink_0`），右列为辅助信息（`flex_1 + min_w(0) + overflow_hidden + text_ellipsis_start`，`opacity(0.6)` 弱化）。辅助信息**从头部省略**（长路径保留尾部目录名）；搜索应同时匹配两列。

**动作项规则**：下拉末位可放一个特殊的动作项（如「＋ 新增项目」）——它与数据项**同一控件形态**（保证可发现性），但选中后**不写入值**：只置位一个宿主请求标记（`Shared::*_request`），由宿主 `render` 消费并打开对应入口；若动作可能丢失未保存内容（如切换项目），必须先走既有未保存确认。

## 7. 颜色与主题

- 一律 `cx.theme().colors.*`（或产品语义角色，见 `docs/architecture/theme/theme-design.md` 与 `gpui-kit-dev` skill）。
- **禁止**裸 hex/rgb；调试用的临时底色必须清理（允许用边框/临时标识排查）。
- 状态色语义：成功 `success`、失败 `danger`、警告 `warning`、提示 `info`、弱化 `muted_foreground`。

## 8. 交互态与可达性

| 状态 | 要求 |
| --- | --- |
| hover | 行用 `list_hover`；文本动作用 `primary` 或保持 `muted_foreground` |
| disabled / 不适用 | `muted_foreground` + 不响应点击（如作用域为「仅全局」时的项目栏） |
| 焦点 | 由组件与 `key_context` 保证；对话框级快捷键见架构文档 §5.5 |
| 提示 | 优先**内联文本**；自绘 tooltip 尚未统一（气泡容易被后续元素遮挡，需谨慎使用） |

### 8.1 动态渲染与单输入源（2026-09-12，连接对话框真机反馈）

- **布局语言：单列分组大纲，不用并排卡片**——卡片靠 `flex_wrap + min_w` 均分宽度，窗口一变窄就换行、卡高参差、长值被挤压；单列分组（可折叠标题 + 标签/控件行）只有一列宽度，顺序即阅读顺序（实例：连接对话框常规 / 高级 Tab）。
- **分组要能“分得开”**：整幅面板（浅底 `group_box` + 圆角）+ 标题栏底部分隔线 + 分组间距；不要“一堆行堆在一个白底上”（真机反馈：区域分辨不清）。
- **标签到控件的距离要短**：标签列定宽（连接对话框为 68px）+ 间距 6px；定宽是为了控件左边缘对齐，但**不得为了对齐把标签推得很远**（真机反馈两轮：距离太远）。
- **只读值用“数据框”而非纯文本**：与可编辑输入同形（白底 + `input` 边框），靠**面板浅底**建立对比；纯文本行只用在真正的说明/摘要（无字段语义）处。
- **控件集合随数据语义动态渲染**：同一页面在不同类型下只展示有意义的控件——如连接对话框的常规 Page 在网络型是「连接设置 + 认证 + SSL + 组织」，文件型（SQLite/DuckDB）只留「连接设置（地址）+ 组织」，认证 / SSL / 网络链不显示（也没有可写的值）。
- **字段的存在性与标签取数据声明**：行应来自后端声明（如 `drivers.config_schema.fields[]`）而非前端写死；未声明就不出该行，声明非法时回退内置字段而不是造“假行”。
- **单输入源**：同一个 `InputState` 只在一处渲染（如地址：网络型在 Header、文件型在分组内）；两处同时可编辑会让人分不清权威值。
- **标签与占位随上下文推导**：如地址列的标签（URI / 地址）与占位（驱动 `url_template` / 文件路径提示）由当前驱动决定，**不得写死某一种类型**的样例。
- **禁用占位 vs 隐藏**：仅在“未来可选 / 数据未就绪”时保留禁用占位；语义上**不适用**的字段直接隐藏（不要用禁用空框填满版面）。
- **未选数据时：显示但禁用**——主体未选（如未选数据库类型）时，表单字段应**正常渲染、整体置灰不可输入**（Input / Select / Checkbox / 按钮统一禁用），不要出现“能打字但存不了”的无效输入。

### 8.2 可编辑控件的可见性（硬约束）

- **输入类控件（Input / Select / Checkbox）必须与所在容器有可辨识的对比**：不允许“白底 + 同色容器 + 极浅边框”（实惨案例：RDS Light 下 `background` 与 `input.border` 都是浅色，输入框在白色卡上几乎看不见）。
- 只读值优先用**数据框**（与可编辑输入同形，靠面板浅底建立对比）；纯文本行只用于无字段语义的说明。
- 调整主题时同步改 `assets/themes/rds-theme.json` 的 `input.border`（当前 Light `#B0B0B0` / Dark `#4F4F4F`），并在 `theme-design.md` 记录取值理由。

### 8.3 行态口径（跨面板单一来源，2026-09-20 起）

树的**行态**曾在导航（M4）、草稿箱（M5）、资产库（M6）各写一遍，于是同一件事长出不同答案（展开指示一个用字符一个用图标、悬停优先级相反、选中底色两种 token）。现在收成**一处口径**，四个消费方（含 Mock M7）共用：

| 事实 | 唯一口径 | 权威落点 |
| --- | --- | --- |
| 展开指示 | 12px chevron **图标**；固定 10px 槽宽，槽宽是缩进算式的一部分（不得改） | `workbench_shell::tree::{disclosure_slot, disclosure_icon}` |
| 悬停 vs 选中 | **悬停只在未选中时生效**（`when(!selected, hover(..))`）；开关态 chip 同理（激活时不换色） | 各面板行渲染 + 本文 §8 上表 |
| 选中底 | `list_active`（不用 `sidebar_accent`：那个角色归侧栏容器） | 同上 |
| 选中激活条 | 左侧 2px `list_active_border`，绝对定位、上下内缩 `TREE_ACTIVE_BAR_INSET` | `tree::active_bar` |
| 缩进 | `base + depth × ui::TREE_INDENT`（导航有基础内距，草稿箱为 0） | `tree::{indent_spacer, indent_rem}` |
| 行高（虚拟列表） | 「基础高 + 附加块」的链式预算，**估算与渲染成对维护** | `tree::{RowHeight, row_sizes}` |
| 定高行的长文案 | 一律 `min_w_0` + `overflow_hidden` + `text_ellipsis`（换行会撺破定高槽位） | `ui-design-spec` §4 + skill `gpui-kit-dev` §布局与滚动陷阱 |
| 行内动作命中区 | ≥ 20px（`ui::NAV_ROW_ACTION_SIZE`）；隐藏用 `invisible()` 而**不是** `opacity(0)`（后者仍能点到） | `ui-design-spec` §2.1 + 本文 §6 |
| 类别 vs 状态 | 图标**形状**承载类别（资产路径），颜色只承载状态（`danger` / `info` / `muted`） | 导航原型 §3 / v8 修订点 |
| 行内动效 | 只挂**暂态**（连接中 / 加载中）；循环缓动首尾同值；id 用业务键 | `ui-design-spec` §4.1 + skill `gpui-kit-dev` §动效 |
| 拖拽 | 载荷带**一批 id**（多选时整选集）、不带动作（落点决定语义）；幽灵**不参与命中测试**、颜色一律中性、形状给类别；落点悬停高亮用 `list_active`（与选中底同 token）；只读场景**不给拖**；落点语义与右键菜单**同一条出口** | 导航 `database/src/nav_view/dnd.rs`、资产库 `analytics_resource/src/dnd.rs`（同一个形态，两处各自定义载荷类型） |

- **不要再在面板里写第二份**：上表任一项要改，就改「权威落点」那一处，四个消费方一起受益；面板文档只留取舍记录与指针。
- 口径来源：导航侧 `docs/architecture/database/database-navigator-prototype-design.md` v8 / v11 修订点（最早落定的一套）、草稿箱 `scratchpad-architecture.md` D14–D16、资产库 `docs/architecture/analytics_resource/analytics-resource-dev-plan.md`。
- 这条规矩本身是为了防「同一件事在两个会话里各拍一次」（曾发生）：改口径就改本表 + 在相关面板文档留痕。

## 9. 提交前检查清单

- [ ] 无裸色值；颜色全部来自 `theme.colors`
- [ ] 间距取自 §3 阶梯；字号取自 §1；图标取自 §2
- [ ] 定宽 / 固定高度处**写清理由**（如"固定宽：类型名长短不移动后续元素"）
- [ ] 可增长区域已配固定高度 + 滚动
- [ ] hover / disabled 态齐全，禁用态不可点击
- [ ] 树 / 列表行：**悬停只在未选中时生效**（不盖选中底），选中 = `list_active` 底 + 左侧 2px `tree::active_bar`（§8.3）
- [ ] 展开指示走 `tree::disclosure_slot()` + `tree::disclosure_icon()`，**槽宽不得改**（它是缩进算式的一部分；§8.3）
- [ ] 拖拽：只读场景不给拖；落点高亮 `list_active`；拖到“原地”不发写入请求（§8.3 末行）
- [ ] 可点元素分两类：**行内轻量动作**（hover 才显的 `+` / `✎` 类）可自绘走 `theme.colors`；**有语义**的（选择器 / 排序 / 分段 / 展开折叠 / 开关）用语义控件（`Button` / `Switch` / `TabBar` / `Collapsible`）并保证键盘可达（§6、§8）
- [ ] 不随上下文变化的标签 / 占位已排查（无写死类型的示例文案）
- [ ] 同一输入只在**一处**渲染；不适用语义的卡片已隐藏（非留空壳）
