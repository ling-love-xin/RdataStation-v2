形态 I 的数据流

1联邦会话上跑取样 SQL远端源各自扫描，DuckDB 归并
2取首批 Arrow batch15s 超时；批次缺失则回退 JSON 打型
3本地建 tmp_i_Arrow 直灌，类型来自 schema
4洞察规则全在本地跑画像 / 直方图 / 相关，引擎零改动

为什么搬结果

  • 洞察的规则、画像、相关全是对本地临时表跑 SQL
  • 整链搬到会话 = 重写洞察引擎，收益只是省一次 Arrow 拷贝
  • 样本落本地后，宿主换源 / 会话重建，样本仍可用

三条硬约束

  • 开关默认关；洞察是「默认进入」，不该每次先选通道
  • 不足 2 个可挂源时开关不出现，只留一行解释
  • 会话内表不进全局临时表名单；rm tmp_i_ 仍在本地单例清
