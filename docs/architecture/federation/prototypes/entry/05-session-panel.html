会话生命周期

  • 取用：按 owner + 源指纹命中就复用，不重复 ATTACH
  • 换主源：只改当前库，不重建（临时对象保住）
  • 源变化：重建，临时对象消失，需提示
  • 断开：连接销毁，表随之释放，不逐张 drop

读数为什么单独算

  • 全局临时表名单只统计本地单例的表
  • 会话内表不进名单，否则「登记」与「删除」指向不同连接
  • 所以会话自己记「表数 / 字节」，显示在这里
