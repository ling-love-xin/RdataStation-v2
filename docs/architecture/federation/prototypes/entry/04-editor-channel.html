源清单为什么只在联邦档

  • 源库 / 本地加速都只有一个源，没有「清单」可管
  • 联邦的清单是全量：所有开了联邦开关的连接，不能增删，只能刷新 / 设主源 / 重挂
  • 这一条是现有代码事实（工具栏按通道挂载源清单）

门控与拒绝

  • 联邦档不可用：<2 个可挂源；菜单项置灰并写原因
  • 驱动不能挂：原因点名「驱动还不能做联邦源」
  • 联邦档写语句：执行前拒绝，不发给远端
切换通道不清空会话：联邦 → 源库再切回来，挂载与临时对象仍在；只有源清单变化才重建。
