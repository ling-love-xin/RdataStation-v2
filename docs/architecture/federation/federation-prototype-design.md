## 1. 入口与总览

联邦不是一个新面板，而是**执行位置的第三档**（`执行位置 ▾ → 联邦查询`，B13 已存在）。
联邦档下多出来的东西只有三样：

1. **源清单**入口（工具栏右侧「执行位置」旁）；
2. **主源**显示（状态栏 + 源清单里都能看到）；
3. 结果区的**代价与一致性**标注。

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [SQL] ▾ │ ▶ 执行 ▾ │ ⇤ 格式化 │ ⋯ 更多 ▾ │   [执行位置：联邦 ▾ ⓘ] [源清单 ▾] [连接 ▾] │
├──────────────────────────────────────────────────────────────────────────┤
│  SELECT o.id, c.name                                                      │
│  FROM mysql_src.orders o                                                  │
│  JOIN oracle_prod.SALES.CUSTOMERS c ON c.id = o.customer_id               │
│  WHERE o.total > 1000;                                                    │
├──────────────────────────────────────────────────────────────────────────┤
│ 结果 1 │ 联邦 · 3 源 · 非事务一致快照                        （结果集标签条）│
```

## 2. 源清单（`源清单 ▾`）

点开是一份**表格化浮层**（不是对话框：它要被反复看，而不是“确认一次”）：

```
┌─ 联邦源 ────────────────────────────────────────────────────────────────┐
│  主源 │ 别名         │ 来源           │ 状态              │ 表   │ 刷新      │
│  ●   │ mysql_src    │ MySQL · orders │ ✅ 可用           │ 42  │ 2 分钟前  │
│      │ pg_warehouse │ PG · warehouse │ ✅ 可用           │ 118 │ 2 分钟前  │
│      │ oracle_prod  │ Oracle · prod  │ ⚠️ 失败：ORA-12541 无监听程序  │  —  │ 1 分钟前  │
│      │              │                │                   │      │           │
│  [＋ 添加源]  [⟳ 刷新全部]  提示：跨源查询请写 别名.schema.表               │
└─────────────────────────────────────────────────────────────────────────┘
```

规矩：

- **失败的行不消失**：保留别名、来源、时间与**原话原因**（`SourceState::Failed(原话)`）；
- 每行可**单独 ⟳ 重新挂载**（刷新表清单；与加速档的“重新挂载源库”完全同语义）；
- 「＋ 添加源」复用**连接对话框**（外部源就是一种连接，见架构 D2 与 dev-plan T1.2）；
- 「● 设为主源」在行尾（点击即切换，状态栏跟随）。

## 3. 主源（未限定名的解析者）

- 状态栏连接段之后显示：`通道 联邦 · 主源 mysql_src`；
- 未限定名（`SELECT * FROM orders`）**只在主源解析**；
- 两源同名表时：**报错**，错误卡片给两个限定名候选，点一下即替换光标处的表名：

```
┌─ 语义错误 ───────────────────────────────────────────────────────────────┐
│ orders 在 2 个源里都存在，未限定名无法解析：                                │
│   · mysql_src.orders_db.orders                                          │
│   · oracle_prod.SALES.ORDERS                                            │
│ [用第一个候选替换]  [用第二个候选替换]                                     │
└─────────────────────────────────────────────────────────────────────────┘
```

（这条是 D3 的落地：不猜，且给出**可执行**的修复动作。）

## 4. 用户写 SQL 的心智模型

| 写法 | 解析 |
| --- | --- |
| `orders` | 只在主源（`mysql_src`）里找 |
| `mysql_src.orders_db.orders` | 限定到 `mysql_src`（推荐写法，**跨源必须**） |
| `ora.ORDERS`（L2 源） | **两段名**：Oracle 的表挂在附加源的 `main` schema 下（真机实测：三段名会报 schema 不存在） |
| `duckdb` 本地表 / 临时表 | 不受影响（本地对象优先，与 DuckDB 一致） |

提示语只出现两处（不做常驻说教）：源清单底部一行、以及同名冲突的错误卡片里。
**按源类型给写法**：L1 源（MySQL / PG / SQLite / DuckDB）三段名，L2 源（Oracle 这类）两段名——
写错时的报错原话里会带 `schema "X" does not exist`，源清单底部那行按已挂源的类型分别列。

## 5. 结果区：代价与一致性

联邦结果与普通结果共用结果区，多两处标注：

| 位置 | 内容 | 依据 |
| --- | --- | --- |
| 结果集标签徽标 | `联邦`（已有） | B13 |
| 工具栏摘要尾 | `联邦 · 3 源 · 非事务一致快照`（悬停给源清单） | 架构 D8 |
| 状态行 | `共 N 行 · 耗时 x`（与普通一致） | —— |
| L3 桥接的结果 | `外部源 mysql_src · 已拉 10,000 行（上限）· 拉取于 14:32` | 架构 D7 |

**不做**“扫描行数”的假数字：拿不到就显示拿得到的（行数 / 耗时 / 拉取量），
第二期再接 DuckDB 的扫描量（架构 §8 #3）。

## 6. 错误呈现（跨源必须点名源）

```
┌─ 执行失败 ───────────────────────────────────────────────────────────────┐
│ 源 oracle_prod 报错：ORA-00942: table or view does not exist             │
│ [复制]  [在源清单里查看该源]                                              │
└─────────────────────────────────────────────────────────────────────────┘
```

- 源侧的错 → 点名源；**本地 SQL 的错**（表名拼错 / 语法）→ 正常诊断定位（B6 已有）；
- 一个源不可用但查询没用到它 → **不打扰**（不弹、不红）；
- 查询用到不可用的源 → 报错 `源 X 不可用：<原因>`，并给「重试该源」动作。

## 7. 门控与空态矩阵

| 状态 | 表现 | 恢复入口 |
| --- | --- | --- |
| 没有开启「DuckDB 本地加速」的连接 | 「执行位置 ▾」里联邦档置灰，行尾写“还没有开启「DuckDB 本地加速」的连接（连接对话框 → 高级）” | 连接对话框里开开关 |
| 只差一个源（开关开着但没连上 / 只有自己） | 置灰 + 行尾点名：“联邦查询至少需要两个已连接且开启「DuckDB 本地加速」的连接（现在只有 X 一个已连接的源；Y 还没连上（先在导航里连接它））” | 连上另一个源 |
| 扩展未装 | 该源行 `⚠️ 失败：扩展 X 未安装`（**不自动联网装**） | 行尾「安装扩展」（显式动作 + 进度 + 失败原话） |
| DuckDB 未就绪 | 联邦档置灰（复用 B13 的门控顺序） | 引擎初始化 |
| 全部源可用但查询为空 | 正常空网格（不特殊处理） | —— |
| 结果被上限截断 | 状态行 `已拉 10,000 行（上限）` | 「提高上限 / 缩小筛选」 |
| 源挂不上（认证 / 网络 / 扩展） | 其余源照常可用；结果区小字写出“源 X 未挂上：<原话>”（原话里的口令已脱敏） | 修好连接后重跑 / 重挂该源 |
