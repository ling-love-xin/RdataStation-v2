# 项目管理模块 · 使用手册（M1）

> 面向使用者：从「打开工作台」到「定位、切换、维护项目」的完整操作路径。
> 设计意图见 `project-prototype-design.md`，实现说明见 `project-view-architecture.md`。
> 状态：与当前实现一致（2026-11-24）。

## 1. 这个模块能做什么

一个应用实例同时只打开**一个项目**（「一实例一项目」）。本模块负责：

- **定位项目**：最近 / 全部 / 已移除三个视图，支持搜索、状态筛选、排序；
- **进出项目**：新建、从示例开始、打开现有目录、切换、关闭（切换与关闭都会保护未保存草稿）；
- **维护项目**：重命名、编辑描述、固定置顶、归档、重新定位（路径失效时）；
- **退出登记**：移出列表（软删，可找回）、删除磁盘数据（只删 `.RSmeta`，输入项目名确认）。

## 2. 入口

| 场景 | 从哪里进 |
| --- | --- |
| 未打开项目 | 工作台中央区直接就是**项目选择器**（左右活动栏、状态栏仍在） |
| 已打开项目 | 标题栏左侧**项目槽**（显示「项目　名称」）点开**项目菜单**：新建 / 打开别的项目、**项目中心…**（= 全局设置的「项目」页）、项目设置…（同页下方的「当前项目设置」块） |
| 键盘 | `Ctrl+Shift+P` 打开**项目中心**（= 全局设置的「项目」页，浏览 / 切换其它项目，不关闭当前项目）；`Ctrl+Shift+W` 关闭当前项目 |

## 3. 界面导览

### 3.1 选择器

```
项目  [最近] [全部] [已移除]                                    12 个项目
┌──────────────────────────────────┐ ┌──────────────────────┐
│ 🔍 搜索名称 / 描述 / 路径（可用 状态:/固定:/锁:） [状态：全部] [排序：最近打开] │ │ ＋ 新建项目           │
├──────────────────────────────────┤ │ 🗀 打开文件夹…         │
│ 名称        状态   📌    [打开] [⋯]│ │ ▦ 从示例项目开始       │
│ 路径                              │ │                      │
│ 描述（有才显示）                    │ │ 快速开始              │
│ 最后打开：… · 状态：active          │ │                      │
└──────────────────────────────────┘ └──────────────────────┘
```

- **Tab**：最近（打开过的，固定项置顶）/ 全部 / 已移除（软删的，可恢复）。
- **搜索**：自由文本按名称 / 描述 / 路径子串过滤（大小写不敏感），并可叠加 facet：

  | 写法 | 含义 |
  | --- | --- |
  | `状态:active` / `archived` / `offline` / `syncing` | 按状态收窄（`状态:全部` = 解除） |
  | `固定:是` / `固定:否` | 只看（不）固定项 |
  | `锁:是` / `锁:否` | 只看（不）已被另一实例占用的项 |

  facet 与自由文本、与「状态：」筛选按钮都是**取交集**；认不出的写法（`描述:报表` / `状态:离` / `C:\data`）算普通文本。
- **状态**：点击轮转 `全部 → Active → Archived → Offline → Syncing`；非「全部」时按钮描边高亮。它只影响当前视图，不写库。
- **排序**：点击轮转 `最近打开 → 名称 → 创建时间`；**跨会话保留**（写入设置）。
- **卡片主操作**是「打开」；其余命令收在 `⋯` 菜单（见 3.2），右键卡片也是同一份。

### 3.2 卡片

一张卡片 = 主操作（「打开」）+ 更多命令（`⋯`）；次级命令也可**右键卡片**直接调出（同一份命令表）：

| 命令 | 说明 |
| --- | --- |
| 打开 | 与卡片上的主按钮同一入口（同样过未保存拦截） |
| 固定 / 取消固定 | 置顶显示，跨会话保留 |
| 在资源管理器中显示 | 打开项目目录 |
| 移出列表 | 软删：从最近/全部隐藏，磁盘不动，可在「已移除」找回 |
| 重新定位… | 仅当路径失效时出现：指向新目录 |
| 恢复 | 仅「已移除」视图出现 |
| 删除数据… | 破坏性：需输入项目名确认，只删 `.RSmeta` |

> 只读打开时，**当前项目自己的**这几条命令置灰（点不动）并会被拦下；同一份列表里**别的项目**的固定 / 恢复 / 移出 / 删除照常可用——只读锁保护的是当前项目的 `.RSmeta`，不牵连名册里别的条目。

### 3.3 项目菜单（标题栏项目槽）

新建项目… / 打开现有目录… / **项目中心…** / 项目设置… / 重命名… / 在资源管理器中显示 / 归档 · 取消归档 / 关闭项目（分隔线把「开新项目 · 项目中心」与「管理当前项目」分成两组）。

只读模式（另一实例持有写锁）下：顶部多一条置灰说明「只读模式：写操作不可用」，「重命名…」与「归档 / 取消归档」置灰；**新建 / 打开目录 / 项目中心 / 设置 / 显示位置 / 关闭项目仍可用**——只读只禁写当前项目，不禁看、不禁走，也不禁去开别的项目。

> 「新建项目…」「打开现有目录…」作用于**别的目录**、不写当前项目，所以只读下也保持可用；确认创建 / 打开时同样先过未保存栅栏。

### 3.4 项目中心 = 全局设置的「项目」页

标题栏菜单 →「项目中心…」，或直接 `Ctrl+Shift+P`。它不关闭当前项目，只是把**全局设置窗口**打开并定位到「项目」页（窗口已开着就直接切到该页，不抢焦点）。和选择器**同一份列表**（搜索 / 状态筛选 / 排序 / 卡片菜单全部可用），区别只有两点——

- **当前项目**的卡片带「当前」标记（点它不会重开，避免白丢一次锁）；
- 点别的项目的「打开」= **切换**：先释放当前项目（锁 + 连接作用域），再打开目标，详见 4.5。

当前项目以**只读**打开时，这里正是区别所在：当前项目那张卡片的写命令置灰，**别的项目**的固定 / 恢复 / 移出 / 删除照样能用（只读锁只锁当前项目的 `.RSmeta`，名册里别的条目不在锁里）。

页面上是两张卡片：先「项目列表」（下方仍是原来的「列表排序」设置行），再「**当前项目设置**」（概览 / 重命名 / 默认连接 / 存储 / 版本 / 危险区，有项目才出现）。卡片里的「新建项目 / 打开文件夹… / 从示例项目开始」与列表后的未保存草稿拦截，都在**主窗口**里发生——设置窗口只负责展示与派发，真正关闭 / 打开项目的是主窗口。无项目时不需要它——工作台中央区本来就是完整选择器。

### 3.5 项目设置（全局设置「项目」页的第二块）

与项目列表同一页、在它下方；只在有项目时出现（没项目时整块不显示），无「关闭」按钮（用设置窗口自己的 ✕ 或 `Esc`）。

概览（名称 / 路径 / 描述 / 状态）→ **基本信息**（名称、描述 + 「保存项目信息」）→ **默认项**（默认连接）→ **存储（`.RSmeta`）**（结构树：树形缩进 + 大小 + 行尾「复制路径」；树头显示「合计」；「打开 `.RSmeta`」用系统文件管理器打开）→ **依赖** → 版本（列表 + 创建快照）→ **危险区**（归档 / 取消归档、移出列表、删除数据…）→ 刷新列表与结构树。

首次进来而快照还没取时，块头会提示「尚未读取项目信息」——点底部「刷新列表与结构树」补齐（从菜单「项目设置…」进来时宿主已经先取过一次）。

只读打开时：基本信息两个输入框与保存、默认连接、「创建版本快照」、危险区三件套全部**置灰**（归档与删除数据这两个不可逆动作同样点不动）。

> 结构树是**只读**的，且窗口里写明：用系统文件管理器打开会暴露内部结构，仅排障用。没写描述时概览显示「—」。

### 3.6 三种状态

| 态 | 表现 |
| --- | --- |
| 无项目 | 中央区是选择器；标题栏槽显示「未打开项目」 |
| 有项目 | 正常五段工作台；标题栏槽显示项目名 |
| 有项目 + 项目中心 | 全局设置窗口（独立窗口）停在「项目」页：顶部「项目列表」卡片 → 当前项目设置卡片（有项目才出现）→「列表排序」；当前项目卡片带「当前」标记 |
| 切换/关闭中 | 未保存草稿 → 拦截对话框；锁竞争 → 逃生口对话框 |

## 4. 典型流程

### 4.1 新建项目

1. 选择器右侧「＋ 新建项目」。
2. 填**名称**（必填，≤64 字，不含 `\ / : * ? " < > |`）。
3. **位置**：可直接输入，或点「浏览…」用系统目录选择器选目录；下方实时显示 `目标：位置/名称` 预览（**位置非空且名称合法**才拼真实路径，否则显示「填写位置与名称后在此预览」）。名称不合法时位置行不报错（先把名称改对，位置提示才有意义）。
4. 可选填描述 → 「创建项目」。成功后项目创建并**直接打开**。

> 「浏览…」打开的是系统原生目录选择器（只能选目录、单选）；取消则保留原值。

### 4.2 从示例项目开始

「▦ 从示例项目开始」→ 在系统数据目录下生成 `samples/示例项目`（含 `.RSmeta` 与示例草稿 `welcome.sql`）并打开。已存在则直接打开。

### 4.3 打开现有目录

「🗀 打开文件夹…」→ 选目录 → 「打开」。选完目录**行内就会先给判断**（非空非项目 / 不存在当场报红，空目录不报错）：

| 目录情况 | 结果 |
| --- | --- |
| 含 `.RSmeta`（有效项目） | 直接打开 |
| 空目录 | 不报错；按「打开」后弹「在空目录创建项目？」确认 → 确认后以**目录名**为项目名在其中创建并打开 |
| 非空且非项目 | 行内即时提示 + 拒绝：「目录不是项目（缺少 .RSmeta），且非空，无法作为项目打开」 |
| 不存在 | 行内即时提示 + 拒绝：「目录不存在：{路径}」 |

### 4.4 打开被其它实例占用的项目

出现逃生口对话框（含占用者 pid）：

- **只读打开**（推荐）：能看不能改；写**当前项目**的命令被置灰（卡片菜单 / 项目菜单 / 设置里都是），真去点了也会被拦下并提示；设置「项目」页里**别的项目**的命令不受影响；
- **仍要打开**：仅在确认对方已退出时使用（会清掉陈旧锁文件后重新抢锁）；
- **取消**：不动作。

### 4.5 切换 / 关闭项目

**切换**：标题栏项目槽 →「项目中心…」（或 `Ctrl+Shift+P`）→ 设置窗口「项目」页里点目标项目的「打开」。当前项目**不会被提前关闭**：你先看列表，选中目标才动手。

切换按固定顺序进行——**先释放当前项目**（还写锁、清掉本项目的连接作用域与导航缓存），**再打开目标**；失败（目标不存在 / 锁被占 / 名册异常）时停在新项目的对话框或选择器报错行，不会留下「半个旧项目」。

**关闭**：标题栏项目槽 →「关闭项目」（或 `Ctrl+Shift+W`）→ 回无项目态的选择器。

两种情况若编辑区有未保存草稿，都先弹拦截对话框：

- **保存并继续**：把编辑区 SQL 另存为项目草稿（`未命名.sql`，重名自动加序号）后继续；
- **放弃更改并继续**：丢弃编辑区内容后继续；
- **取消**：什么都不做（当前项目仍在，草稿还在）。

> 拦截发生在**释放之前**：取消 = 完全没动过当前项目；确认 = 先存 / 丢草稿，再释放，再打开目标（或回选择器）。
> 点当前项目自己的「打开」是 no-op（不重开、不丢锁）。

### 4.6 重命名 / 编辑描述

项目菜单 →「项目设置…」（或「重命名…」）→ 跳到**全局设置窗口的「项目」页**（名称与描述已预填）→ 在「当前项目设置」的**基本信息**里改名称与描述 →「保存项目信息」。

- 只改**显示名**与描述：磁盘目录名不变；
- 名称同样受校验（空 / 超长 / 非法字符会被拒，提示在 `notice` 行）；
- 描述留空表示清空描述。

### 4.7 固定 / 归档

- **固定**：卡片 `⋯` → 固定；固定项在最近/全部置顶，跨会话保留。
- **归档**：项目菜单 →「归档 / 取消归档」；归档不删除、仍在名册，卡片状态显示 `archived`。

### 4.8 路径失效与重新定位

磁盘上的目录被移走或删除后，卡片显示「⚠ 路径已失效，可能已移动或删除」。此时：

- **重新定位…**：选新目录（必须含 `.RSmeta`）→ 更新名册路径；
- **移出列表**：不动磁盘，只从名册移除。

### 4.9 设置默认连接（U3）

全局设置「项目」页 →「当前项目设置」→ **默认项** → 「默认连接」下拉：

| 选项 | 效果 |
| --- | --- |
| （不设默认） | 清掉记录；新建查询 / 打开项目时用系统当前连接 |
| 具体连接 | 写进项目本体的 `.RSmeta/config/settings.json`（`default_connection_id`） |

候选 = 当前作用域可见的连接（全局 + 本项目）；记录指向的连接被删掉时下拉会如实显示 id 并标「已不可用」，不会静默变成「未设置」。

### 4.10 移出列表 / 删除数据 / 找回

| 操作 | 磁盘 | 名册 | 可逆 |
| --- | --- | --- | --- |
| 移出列表（软删） | 保留 | 隐藏，进「已移除」 | ✅「已移除」→ 恢复 |
| 删除数据（硬删） | **删 `.RSmeta`**（用户文件保留） | 移除登记 | ❌ 需输入项目名确认 |

删除当前打开的项目时，会先走未保存拦截并关闭项目，再删数据。

## 5. 状态与提示速览

| 显示 | 含义 |
| --- | --- |
| 状态 `active`（绿） | 正常可用 |
| 状态 `archived`（灰） | 已归档 |
| 状态 `offline`（黄） | 路径不可达或依赖缺失 |
| 状态 `syncing`（蓝） | 同步中（预留） |
| ⚠ 路径已失效 | 目录被移动/删除 → 重定位或移出 |
| ⚠ 缺失驱动 | 项目引用的驱动在本机不可用 |
| ● 已在另一实例打开 | 锁被占用；可用「只读打开」进入 |
| 只读模式 | 当前以只读方式打开，写**当前项目**的操作已置灰 / 被拦下（设置「项目」页里别的项目照常可管理） |
| 当前（卡片标记） | 设置「项目」页的列表里这一条就是正在用的项目；点它不会重开 |

## 6. 快捷键与键盘操作

| 按键 | 动作 |
| --- | --- |
| `Ctrl+Shift+P` | 打开**项目中心**（全局设置窗口的「项目」页；浏览 / 切换其它项目，不关闭当前项目） |
| `Ctrl+Shift+W` | 关闭项目（回无项目态的选择器） |
| `Ctrl+P` / `Ctrl+,` | Quick Open / 设置（工作台通用） |
| `Tab` | 焦点在控件间前进（搜索框 → 最近 / 全部 / 已移除 → 状态 → 排序…）；`Shift+Tab` 反向 |
| `Enter` / `Space` | 激活当前聚焦的控件（切 Tab、换状态筛选、切换排序、开菜单等） |
| `↑↓` / `Enter` / `Esc` | 下拉菜单内导航 / 选中 / 关闭（组件自带） |
| 右键卡片 | 调出该卡片的命令菜单（与 `⋯` 同一份） |

> 卡片本身不参与 Tab（卡片内的「打开」/`⋯` 是按钮，可用 Tab 到达）。

## 7. 数据与安全

- **删除只动 `.RSmeta`**：`project.db` / `analytics.duckdb` / `project.json` / `project.lock` 等内部元数据会被删；项目根下的用户文件（含 `scratchpad/`、`.sql` 等）**保留**。
- **名称 / 描述双写**：名册（全局库 `project_info`）+ 项目内 `project.json` / `project.db`；以名册为准刷新列表，项目本体同步失败只告警不阻断。
- **实例锁**：`{项目}/.RSmeta/project.lock` 用操作系统文件锁，进程退出或崩溃后自动释放（文件会留下，不阻塞下次打开）；`project.lock.owner` 记录占用者 pid 与获取时间，仅用于展示。
- **偏好落点**：排序方式存全局设置 `settings.json`（`projects.sort_mode`）；**新建对话框的默认位置**存同一份全局设置的 `projects.last_create_location`（只在新建成功后写，不在设置页出现）；固定状态存名册 `project_info.is_pinned`；默认连接存**项目本体** `.RSmeta/config/settings.json`（`default_connection_id`）。
- **构建标识**：每次（非只读）打开项目，会把当前构建标识写进项目本体的 `.RSmeta/config/settings.json` → `extensions.rds.build_tag`，用于判断「这个项目最近由哪个构建打开」。它**不在界面展示**，与项目内的「资产版本链」不是一回事。

## 8. 常见问题与排查

**Q：为什么我的项目打不开，提示「已在另一实例打开」？**
另一个进程（可能是上次没退干净的窗口）持有写锁。推荐「只读打开」先查看；确认对方已退出再选「仍要打开」。

**Q：删除数据后我的 SQL 文件还在吗？**
在。删除只清 `.RSmeta`。若想连同文件一起删，请在系统文件管理器里处理。

**Q：为什么「重新定位」不见了？**
只有路径失效的卡片才出现；路径正常时菜单里没有这一项。

**Q：为什么新建项目时「位置」不能直接选到目录？**
可以：点「浏览…」用系统目录选择器；直接输入也支持（用于粘贴路径）。

**Q：能填 URL 开远程项目吗？**
不能。当前版本只支持本地目录；DuckLake 远程项目仅在模型层预留（`ProjectPath::Remote`），UI 不会接受 URL。

**Q：项目名改了，磁盘目录名会变吗？**
不会。重命名只改显示名与名册/项目本体记录。移动目录不在本期范围。

**Q：为什么卡片上有的项目多一行字？**
那是项目的**描述**（写描述就在卡片上显示；空 / 纯空白不占位）。设置·概览也能看到完整描述。

**Q：设置里的 `.RSmeta` 结构树能改吗？**
不能，它只是只读的排障视图（带大小与「复制路径」）。要直接看文件用「打开 `.RSmeta`」——注意会暴露内部结构。

> 搜索框支持 **facet 语法**（与 database 导航面板同一口径）：`状态:archived`、`固定:是`、`锁:否`，可与自由文本混用（`状态:offline 对账`），与「状态：」筛选按钮**取交集**；`状态:全部` 解除约束。
> 认不出的写法（`描述:报表`、`状态:离`、`C:\data`）不会被当成 facet，而是当作普通文本——不会因为输到一半就把列表清空。

**Q：为什么搜索 `状态:离` 没按状态过滤？**
状态值要写全（`active` / `archived` / `offline` / `syncing`），或写 `状态:全部` 解除约束；写不完整的 token 会当作普通文本，这是有意的（否则你还没输完，列表就被清空了）。

**Q：误点了「移出列表」怎么办？**
选择器「已移除」Tab 找到它 → `⋯` →「恢复」。
