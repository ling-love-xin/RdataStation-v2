项目增删改查 CRUD

Create新建空项目 / 打开现有目录（含 .RSmeta）/ 示例项目；目标非空非项目 → 阻止
Read最近 / 全部 / 已移除、搜索（名称/路径）、排序（持久化）、固定置顶、打开、缺失驱动与路径有效性
Update重命名（仅显示名，不改磁盘目录）、描述、默认连接、归档 / 取消归档、重新定位
Delete软删 = 移出名册（磁盘保留，可从「已移除」找回）；硬删 = 输入项目名二次确认，先释放项目锁
提升 / 引用（promote / snapshot）属 M1 双层资产能力，不在项目管理范围。
